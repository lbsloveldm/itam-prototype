## 2. 需求分析

### 2.1 业务背景

盘点任务需要及时触达执行人、协作者与负责人。现有通知仅支持邮箱与内部（Inner）渠道，无法覆盖企业实际使用的即时通讯工具。以赛力斯客户为例，其现状是：提醒任务可通过飞书发送给具体用户，提醒中带任务链接，用户点击「查看详情」进入 H5 详情页查看，并可在飞书 H5 中直接进行盘点。因此需扩展多渠道通知能力，并在通知中携带可点击的任务链接，支持跳转后直接盘点。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **触达及时**：接入企业常用即时通讯渠道，盘点任务提醒实时触达。
- **操作闭环**：通知中带任务链接，点击即可进入 H5 查看并盘点，缩短「收到通知→开始盘点」路径。
- **安全可控**：支持单点登录，用户仅能看到自己的任务详情。

#### 2.2.2 调研结论及竞品分析

赛力斯客户现状：飞书发送提醒 + 带任务链接 + H5 内盘点已跑通。技术侧由 DOUC 提供多渠道消息能力（需按其要求对接及配置），其中 Teams 需 DOUC 升级到 7.0.1 版本。

### 2.3 用户故事

- 作为**盘点执行人**，我希望通过飞书/钉钉等渠道收到带链接的盘点提醒，以便一键进入 H5 开始盘点。
- 作为**任务负责人**，我希望通知链接支持单点登录，以便点击后仅看到自己相关的任务，保证数据安全。
- 作为**系统管理员**，我希望通知渠道可配置（含移动端链接可选配置），以便适配不同客户环境。

## 3. 需求设计

### 3.1 涉及到的表

- `scheduled_task` / `notification_channel`（预设任务 / 通知渠道配置表）
- `audit_task`（盘点任务表，提供任务链接与状态）
- `notification_log`（通知发送记录表）

### 3.2 盘点任务多渠道通知

#### 3.2.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 新增三方渠道 | 除 邮箱、Inner 外，新增支持飞书、钉钉、企业微信、Teams、Slack | 由 DOUC 提供能力，需按其要求对接及配置；Teams 需 DOUC 升级到 7.0.1 |
| 通知带任务链接 | 通知中包含任务链接且可点击 | 链接指向移动端任务 H5 页 |
| 任务链接可配置 | 通知中配置任务移动端链接，支持跳转，也可不配置 | 链接地址为文本输入字段 |
| 单点登录 | 支持单点登录，用户在对应渠道点击链接后仅能看到自己的任务详情 | 凭当前身份鉴权 |
| 未领取跳转 | 执行人、协作者、负责人在移动端可查看任务；任务未领取时跳转到未开始任务列表页 | 默认搜索条件为通知链接中的当前任务 |
| 已领取跳转 | 任务被领取后，点击消息提醒链接可进入 H5 页查看详情并进行盘点 | 复用移动端盘点执行能力 |

#### 3.2.2 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 提醒渠道 | 多选 | - | 通知渠道，新增飞书/钉钉/企业微信/Teams/Slack |
| 任务链接 | VARCHAR | 255 | 任务移动端链接，文本输入，可为空（不配置则不跳转） |
| Recipient | 引用 列表 | - | 通知接收人（执行人/协作者/负责人） |
| SSO enabled | BOOLEAN | - | 是否启用单点登录 |

#### 3.2.3 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 提醒渠道 | 邮箱 | 邮箱（既有） |
| 提醒渠道 | Inner | 内部消息（既有） |
| 提醒渠道 | 飞书（Lark/Feishu） | 新增，DOUC 对接 |
| 提醒渠道 | 钉钉（DingTalk） | 新增，DOUC 对接 |
| 提醒渠道 | 企业微信（WeCom） | 新增，DOUC 对接 |
| 提醒渠道 | Teams | 新增，需 DOUC 升级到 7.0.1 |
| 提醒渠道 | Slack | 新增，DOUC 对接 |

### 3.3 页面功能与交互逻辑

- **渠道配置**：在预设任务/通知模板配置中，通知渠道由单选/多选扩展为含五类三方渠道；选择渠道后可配置任务移动端链接（文本输入，选填）。
- **链接跳转（未领取）**：点击链接进入移动端「未开始任务列表页」，默认按通知链接中的任务作为搜索条件定位该任务。
- **链接跳转（已领取）**：点击链接进入 H5 任务详情页，可查看详情并直接盘点。
- **权限隔离**：单点登录鉴权，用户仅可见自己（执行人/协作者/负责人身份）相关任务。
- **移动端适配**：需考虑移动端 H5 适配。

## 4. 验收标准

- 通知渠道支持 邮箱、Inner 及新增飞书、钉钉、企业微信、Teams、Slack；Teams 依赖 DOUC 7.0.1。
- 通知消息携带可点击任务链接；任务移动端链接为可选文本配置。
- 单点登录生效，用户点击链接后仅能看到自己的任务详情。
- 任务未领取时点击链接跳转到未开始任务列表页且默认搜索条件为当前任务；任务已领取时跳转到 H5 详情页并可盘点。

## 2. 需求分析

### 2.1 业务背景

资产盘点（资产 Inventory）是对组织内所有资产进行物理检查和记录的关键过程，目的与作用包括：准确性（资产记录与实物匹配）、完整性（识别未记录资产）、合规性（审计与税务报告）、安全性（防止丢失被盗）、维护保养（识别需维护资产）、成本控制、资产优化（识别闲置/过剩）、责任分配、风险管理、报告分析。系统需支持以「模板 → 计划 → 任务」为主线组织盘点，并覆盖 PC 端配置与移动端（含离线）执行的完整流程。

### 2.2 需求价值

#### 2.2.1 模块价值点

参考 ServiceNow 资产盘点（Audit）关注的核心内容：资产清单与记录准确性、采购与接收过程、使用与维护、报废与处置、内部控制与合规性、生命周期管理、成本控制、风险管理、保险与风险管理、合规性。系统盘点执行模块聚焦其中「清单准确性 + 生命周期一致性 + 高效执行」三点，通过多种盘点方式（手动/扫码/RFID/离线/自主/精选）覆盖不同客户场景。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow：盘点任务化管理、移动端扫码盘点、盘点差异分类统计。结合本系统实践补充：RFID 批量盘点、离线盘点数据锁与同步比对、模板统一属性设置、自主盘点（按人生成任务）、精选盘点（无位置/库房直接选资产）等本地化能力。

### 2.3 用户故事

#### 2.3.1 盘点对象

- 库房中的资产 —— **在库盘点**。
- 其他地点（如办公室或数据中心）的资产 —— **在用盘点**（某些地点资产不在库房中，需室内定位）。

#### 2.3.2 角色要求

- 角色 资产维护人具备**创建**盘点任务权限；**执行**盘点任务的人需提前被授予执行权限（如 u1 需先被授予执行盘点权限，方可在指派任务时被指定）。
- 需指定**主执行人（执行者）**与**协助执行人（协作者）**；执行者、协作者直接指定，不做角色授权限制。

## 3. 需求设计

### 3.1 业务说明与涉及到的表

盘点执行以「模板 → 计划 → 任务」为主线；复核结果新增功能点为「台账更新」（详见《复核盘点结果》）。

- `audit_template`（盘点模板表）
- `audit_plan`（盘点计划表）
- `audit_task`（盘点任务表）
- `audit_result`（盘点结果/明细表）
- `asset`（资产台账表）
- `规格` / `model_category`（规格 / 规格类别表）
- `stockroom` / `location`（库房 / 位置表）
- `scheduled_task`（预设任务表）

### 3.3 移动端盘点任务列表（四 页签）

> 执行资产盘点-移动端，所有任务支持离线；任务需领取才可被执行。任务分四个 页签：待执行、执行中、已完成、离线。

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 待执行（待处理） | 任务生成后，执行者及协作者可在待执行页看到相关任务 | 未开始的盘点任务不在移动端显示；到达开始时间才可领取 |
| 领取任务（接收） | 任务已达开始时间且未到结束时间，执行者/协作者点击 接收 领取 | 领取成功后，按盘点模板选定条件圈定当前任务盘点资产集合；执行者、协作者的目标资产完全相同（此刻圈定的集合） |
| 执行中 | 展示已领取、执行中及已逾期未完成的任务 | 领取成功进入执行中；可下载任务进入「离线」页签；点击任务名进入盘点详情页 |
| 已完成 | 展示每个已被提交的任务 | 已完成任务无结果检验，执行者/协作者可查看，但所有输入框与操作按钮置灰 |
| 离线任务 | 离线任务可输入，但无网络时不可同步与提交 | 任务成功提交后该离线任务删除 |
| 下载任务 | 执行者/协作者均可下载任务，下载成功后任务图标提示 | 见 3.5 离线盘点 |
| 任务信息展示 | 任务名称、描述、创建人、盘点人、协作者、计划时间（开始-结束） | 计划开始日期后，盘点人与协作者在「执行中」看到该任务 |

#### 3.3.2 列表排序规则

| 页签 | 排序规则 |
| --- | --- |
| 待执行 | 按距离开始时间远近排序，越近越靠前 |
| 执行中 | 按领取任务时间逆序，最近领取的在最上方 |
| 已完成 | 按完成时间逆序，最近完成的在最上方 |
| 离线 | 按下载时间逆序，最近下载的在最上方 |

### 3.4 盘点执行（手动 / 扫码）

#### 3.4.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 盘点详情页 | 显示要盘点资产总量、每个 规格 下资产总量、已盘点数量、待盘点数量 | 按 规格 分别展示待查资产；不显示 attribute 文字及数量 |
| 手动盘点 | 通过选择某个资产进入手动盘点页 | 显示当前台账资产属性值 |
| 扫码盘点 | 通过扫码进入盘点页 | 显示当前台账资产属性值 |
| 确认盘点 | 属性值无误则点「确认」完成该条资产盘点 | 已盘点数量 +1，待盘点数量 −1 |
| 标记有误并修改 | 认为有误可点「有误」进入修改页，每个属性均可编辑 | 点「取消」返回；点「保存」完成该条资产盘点并进入资产详情页；系统记录原台账值及人工填充值 |
| 重复盘点 | 未点击提交前，可对已盘/未盘资产重复盘点及修改 | 以最新盘点结果覆盖 |
| 在线/离线保存 | 在线盘点数据实时保存到系统，离线盘点数据保存到本地 | 见 3.5 |

#### 3.4.2 五类盘点结果与特殊处理

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 目标未找到（C） | 资产所有属性字段人工填写为空 | 计入 Expected and not found |
| 不在范围内且命中 规格（D） | 若可匹配到已有盘点 规格，盘点属性显示该 规格 对应属性 | 计入 Scanned and not expected |
| 不在范围内且未命中 规格 | 需先选择属性再盘点（支持多选），选择后展示属性名称及当前台账值 | 见「选属性」页；避免找不到盘点属性 |
| 扫到已存在台账的范围外资产 | 展示该资产详情页必填项属性，点「保存」计入 Scanned and not expected | 点「取消」则不计入统计 |
| 发现台账不存在的资产 | 点「New 资产」进入资产新增填写页，选择必填字段新增 | 移动端新增仅填必填项（hardware 需填 SN；consumable 仅填 规格 category 及 规格），保存后并不实际写入台账，任务完成后复核员可见此「新增」草稿，进入 PC 资产详情页填写完整信息完成真实新增；新增草稿在当前任务页以模块展示 |

#### 3.4.3 提交规则

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 提交权限 | 盘点人点击提交＝提交整个盘点任务；协作者提交＝提交所完成的盘点数据 | 沿用 DCIM 原有逻辑 |
| 未盘点项拦截 | 存在未盘点项时盘点人提交后弹窗「存在未盘点项，禁止提交」 | 点确定返回盘点任务页 |
| 协作者被抢先提交 | 盘点人提交成功后，协作者点保存弹窗「该盘点任务已被提交，请返回」 | 点确认回到已完成页 |
| 提交二次确认 | 盘点人点提交弹窗「是否确认提交？」 | 确认后提交 |
| 多人盘同一资产 | 多人做同一任务时，以最后一个人提交的结果为准 | 结果覆盖 |

### 3.5 RFID 盘点与离线盘点（盘点优化）

#### 3.5.1 RFID 盘点

> 解决批量盘点问题，适用对象为硬件资产，属性为「资产是否在库或在使用位置」。

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| RFID 入口显隐 | 进入盘点任务时判断该任务所有 规格 盘点属性是否为「使用位置｜所在库房」 | 全部为该字段则显示「RFID 识别」，否则不显示；含非该字段的硬件盘点属性时不展示 RFID |
| 识别结果标题 | 属性为「使用位置」显示 Using 位置；属性为「所在库房」显示 Located stockroom | 按任务盘点属性动态显示 |
| 结果过滤 | 非整库房盘点：过滤掉不在盘点范围内的已绑定 RFID 资产；整库房盘点：显示所有 RFID 识别结果 | 聚焦本次盘点对象 |
| 无未绑定数据 | 结果中若无未绑定资产，在当前页弹出选项供选择，保存可点击 | 保存后进入任务详情页显示盘点结果 |
| 盘点结果判定 | RFID 找到＝账实相符；未找到＝账实不符/盘亏；扫到范围外＝Scanned and not expected | 批量完成已绑定 RFID 对应资产的盘点结果 |
| 有未绑定数据 | 显示未绑定数据，可选择进行资产绑定 | 用选中资产编号值填充绑定页 RFID 字段 |
| 忽略未绑定提示 | 选择位置/库房保存时若存在未绑定资产，提示「保存成功！盘点已忽略所有未绑定资产。如需不忽略可再次 RFID 识别」 | 成功, the audit result excluded all unbound RFID assets! |
| 识别控制 | 增加「暂停、继续」操作，取消 10 秒倒计时识别；展示过程中识别到的数量 | 点「停止识别」时对识别结果去重展示 |
| 多次盘点 | 同一任务未提交前支持多次 RFID 盘点 | 重新识别时仍展示已有盘点结果资产，以最新系统计算结果覆盖 |
| 新增资产 | 在批量盘点结果页点「新增资产」，与当前系统一致 | 复用新增逻辑 |

#### 3.5.2 离线盘点

> 应对仓库网络盲区（地下室、冷库、偏远库房）或网络故障。核心思路：任务下载 → 离线扫描 → 数据同步 → 差异比对与更新。

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 任务下载 | 进行中任务列表每条任务后显示「下载」，下载成功后不再显示下载链接仅显示离线 logo | 有网环境下点下载，将该任务待盘点台账数据保存至本地手机端 |
| 在线转离线 | 在线任务执行未提交前均可下载，下载后原在线盘点结果继承到离线继续盘点 | 提示「您将下载该任务为离线任务，需对所有资产全部进行盘点」 |
| 离线执行 | 有网环境且已下载则仍用离线下载时台账数据；无网环境按保存的台账数据比对 | 完成后可提交并保存在本地手机端 |
| 待同步提示 | 已完成任务列表中未同步的离线任务显示同步操作；搜索框上方显示「有 N 条数据待同步」 | 协作者下载任务且未完成前不能同步 |
| 同步 | 有网时可对某已完成离线任务同步，或直接同步所有数据 | 同步成功后待同步条数更新 |
| 上传结果更新 | 上传时盘点结果需根据当前实际台账更新 | 见下方比对规则 |
| 台账比对规则 | 对比离线下载时手机端台账数据与上传时系统台账数据 | 一致则直接上传用户操作结果；不一致则对比更新不一致的盘点结果 |
| 相符→不符 | 若原结果为账实相符，需改为账实不符，且以原台账属性值作为用户输入值 | — |
| 不符判定 | 若原结果为账实不符，判断每个用户当时输入属性值与最新台账属性值是否相同 | 相同则改为账实相符，否则仍为账实不符 |
| 单人下载锁 | 只允许一个任务被 1 人进行一次离线下载，被下载的任务不再显示下载操作 | 避免多人操作导致提交覆盖不一致 |
| 台账锁定 | 被离线任务下载的台账数据，在离线任务上传完成前不允许任何人/流程修改对应台账详情 | 需锁死直至离线结果上传成功 |
| 协作者同步解锁 | 若协作者下载任务并执行同步，则该任务指派人可对此任务进行修改及提交 | — |

### 3.6 模板统一属性设置与自主盘点

#### 3.6.1 模板中提供统一属性设置

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 两种设置选项 | A. 统一设置（进入系统后默认选中）；B. 按规格单独设置（与当前系统相同） | 解决多规格盘点属性相同时重复设置耗时问题 |
| 属性设置规则 | 选统一设置时，用户选择盘点规格，依据规格所属资产大类显示类别盘点属性字段 | 如选硬件规格+耗材规格则显示「硬件盘点属性、耗材盘点属性」；可选值拉取当前台账属性数据 |
| 保存生效 | 保存后该模板盘点规格对应的盘点资产属性全部生效为统一设置的属性 | — |
| 按规格单独设置 | 选按规格单独设置则功能与当前系统相同 | — |

#### 3.6.2 自主盘点（Self-Audit）

> 资产所有者自行盘点名下资产。主线：A. 模板确定盘点对象及属性；B. 计划确定盘点人；C. 生成任务完成盘点。

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 自主盘点模板 | 类型中增加「自主盘点（Self-Audit）」 | 选择后属性设置规则默认「统一设置」且不可改；不显示盘点位置字段，不展示盘点规格选项（每人名下资产规格不同）；仅提供硬件盘点属性字段（只盘硬件） |
| 自主盘点计划 | 新建默认进入当前系统页面；选自主盘点类型时字段更新 | 只盘名下硬件 |
| X1 部门全体人员 | 支持多选；选部门后拉取该部门及嵌套部门所有员工及其名下资产（取硬件资产「资产所有者」对应的硬件） | 仅该部门下有资产的员工生成任务 |
| X2 其他人员 | 可选择某人执行其名下资产盘点，可多选 | 应对跨部门调动、部门信息未更新 |
| X3 非参与人员 | 可选择某些人不参与盘点 | 应对离职交接期；系统为 X1、X2 生成任务，不为 X3 生成 |
| Y1 执行者校验 | 执行者字段无数据时计划无法保存 | 执行者字段显示计算得到的任务盘点人员 |
| Y2 名下无资产提示 | 执行者名下全部无资产时保存提示「所选执行者名下无资产，无需盘点，不自动生成任务」 | — |
| 生成任务 | 按计划自动生成任务，执行者进入任务仅展示自己名下硬件资产 | 责任人以 user 维度展示所有用户及要盘点资产，可盘点/修改所有未提交结果 |
| 执行者字段展示 | 详情页 Collaborators 改为执行者（Executor） | 个人看到的执行者值为自己；责任人看到的执行者值随机显示一个名称加省略号（如 管理员……） |
| 能力限制 | 自主盘点不支持离线盘点、RFID 盘点，支持手动、扫码 | — |

### 3.7 精选盘点（直接选定固定资产）

> 香港 POC 场景：客户不关注资产所在位置/库房，由几个固定的人对企业所有资产进行盘点。

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 精选盘点类型 | 模板类型字段新增下拉选项「精选盘点（Selected-资产）」 | 解决对资产无位置、库房的盘点 |

| 设置盘点属性 | 基于已选资产按类型设置盘点属性（Attributes） | 软件资产盘点属性去除设备授权&用户授权的「分配条件」，且不需要「父资产」属性 |
| 中英文对照 | 精选盘点＝Selected-资产；盘点范围＝Audit Scope；盘点属性＝Attributes | — |

| 离线阈值 | 离线盘点可下载任务；若资产数到达预设阈值 X，不支持离线下载 | 提示「您的资产盘点数量超过 X，目前无法进行离线盘点」 |
| 扫码/RFID/新增限制 | 扫码仅支持硬件、耗材；RFID 适用硬件；新建仅支持新建硬件、耗材 | 与其他类型盘点一致 |

### 3.8 预设任务（Scheduled Task，一个页面完成配置）

> 定时任务帮助企业发现资产管理中的潜在风险与合规问题。入口：Setting 中增加菜单「Set Scheduled Task」。配置分五步：A. 选任务类型与目标字段/优先级；B. 设通知人；C. 选通知渠道；D. 定执行周期与时间；E. 完成配置并创建。

#### 3.8.1 创建预设任务字段说明

## 4. 验收标准

- 盘点任务四 待执行/执行中/已完成/离线展示与排序规则符合本文定义；任务需领取后方可执行。
- 手动/扫码盘点可正确记录原台账值与人工填充值，已盘/待盘计数准确；五类盘点结果（A/B/C/D/E）分类正确。
- RFID 盘点入口显隐、结果过滤、账实判定、暂停/继续与去重逻辑正确。
- 离线盘点的下载锁、台账锁定、同步比对更新（相符↔不符转换）逻辑正确。
- 模板统一属性设置生效正确；自主盘点按人/部门生成任务、执行者字段展示规则正确；精选盘点可无位置/库房选定资产并支持离线阈值限制。
- 预设任务可通过一个页面完成五步配置，六种 类型 默认内容/默认通知人正确，列表启用/禁用/删除与触发条件符合定义。

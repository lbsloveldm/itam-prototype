## 2. 需求分析

### 2.1 业务背景

资产盘点（资产 Inventory）是对组织内所有资产进行物理检查与记录的关键过程，用于保证资产记录准确性、识别缺失/多出资产、满足合规审计。盘点执行分散在多个库房、多个任务中，管理者缺乏一个全局视角来快速回答「哪些库房盘完了、盘得准不准、任务执行效率如何」。因此需要一个**盘点总览（Overview）看板**，基于独立库房维度对盘点进度、数据准确性、任务效率进行可视化汇总，支撑库房管理员与资产负责人的日常监督与决策。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **进度可视**：按独立库房维度展示已盘/未盘数量及占比，快速定位盘点滞后的库房。
- **质量可视**：展示数据准确性占比，衡量台账与实物一致程度，及时暴露数据质量问题。
- **多维洞察**：支持按 cost center、资产负责人维度查看盘点准确性，定位责任归属。
- **效率洞察**：基于盘点任务统计任务超时率、平均耗时、耗时偏差，评估盘点执行效率。
- **趋势回溯**：可查看近 3 个月的盘点结果，观察库房数据质量的变化趋势。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow：按独立库房维度、分时间展示库房数据准确性，并分库房展示数据修复率，其目标是「库房数据准确性要高、有问题修复要快」。结论：ServiceNow 以整个库房为准确性统计单元的方案不完全适用本系统——本系统盘点可基于整个库房，也可基于库房中的某个 shelf，存在单个库房未盘完的情况，不能简单以整库房维度衡量准确性，需支持「已盘范围内」的准确性统计。

### 2.3 用户故事

- 作为**库房管理员**，我希望在一个看板上看到各库房的已盘/未盘占比，以便优先推进盘点滞后的库房。
- 作为**资产负责人**，我希望按资产负责人/成本中心查看盘点准确性，以便定位数据质量问题的责任归属。
- 作为**盘点管理者**，我希望查看任务超时率与平均耗时，以便评估并优化盘点任务的执行安排。

## 3. 需求设计

### 3.1 盘点总览看板

> 角色：库房管理员（asset）。

#### 3.1.1 涉及到的表

- `audit_task`（盘点任务表，提供任务状态、耗时、超时信息）
- `audit_result`（盘点结果表，提供已盘/未盘、账实相符统计）
- `stockroom`（库房表，提供库房维度分组）
- `asset`（资产表，提供 cost center、资产负责人维度）
- `audit_plan`（盘点计划表，区分一次性/周期性任务）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 库房盘点进度总览 | 基于独立库房，查看所有库房已盘/未盘数量及占比 | 汇总各库房范围内资产总数与已盘数量，计算已盘占比，以饼图展示所有库房的整体已盘/未盘比例 |
| 单库房盘点进度 | 查看单个库房已盘及未盘数量 | 按库房分组统计已盘/未盘数量，以柱状图展示；每个独立库房单独占一行，若库房较多则依次在下一行展示 |
| 数据准确性占比 | 基于独立库房，查看已盘数据的准确性占比 | 在已盘资产范围内，统计「账实相符」数量占已盘总数比例，以饼图展示（仅统计已盘范围，避免因未盘完导致准确性失真） |
| 近 3 个月趋势 | 可查看近 3 个月的盘点结果 | 按月聚合盘点结果，展示单个独立库房近三个月的进度/准确性数据（可根据实际情况调整时间跨度） |
| 多维准确性 | 基于不同 cost center、资产负责人提供盘点准确性 | 按 cost center、资产负责人分组统计准确性占比 |
| 任务效率统计 | 基于盘点任务统计任务超时率、平均耗时、耗时偏差 | 区分一次性任务、周期性任务分别统计：超时率＝超时任务数/任务总数；平均耗时＝完成任务耗时均值；耗时偏差＝实际耗时与预计耗时（预计耗时字段）的差值 |
| 完整页面入口 | 盘点总览作为资产盘点模块首页入口 | 从左侧导航「资产盘点」进入默认展示总览页，可下钻至库房/任务详情 |

#### 3.1.3 字段说明（统计指标）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 库房 | 引用 | 32 | 统计维度：独立库房 |
| 已盘数量 | INTEGER | 20 | 已盘数量（库房范围内已完成盘点的资产数） |
| 未盘数量 | INTEGER | 20 | 未盘数量（库房范围内尚未盘点的资产数） |
| 已盘比例 | DECIMAL | - | 已盘占比＝已盘数量 /（已盘＋未盘） |
| 准确率 | DECIMAL | - | 数据准确性占比＝账实相符数量 / 已盘数量 |
| 成本中心 | 引用 | 32 | 准确性统计维度：成本中心 |
| 资产 owner | 引用 | 32 | 准确性统计维度：资产负责人 |
| 超时率 | DECIMAL | - | 任务超时率＝超时任务数 / 任务总数 |
| 平均耗时 | INTEGER | 20 | 平均耗时（分钟），区分一次性/周期性任务 |
| 耗时偏差 | INTEGER | 20 | 耗时偏差＝实际耗时 − 预计耗时 |
| 统计周期 | VARCHAR | 20 | 统计周期（近 3 个月，按月聚合） |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 任务类型（统计维度） | 一次性任务 / 周期性任务 | 效率指标区分统计口径 |
| 准确性维度 | 库房 / 成本中心 / 资产负责人 | 数据准确性支持的三种统计分组维度 |
| 图表类型 | 饼图 / 柱状图 | 已盘占比与准确性用饼图；单库房已盘/未盘用柱状图 |

### 3.2 页面功能与交互逻辑

- **看板布局**：顶部为「全部库房已盘/未盘占比」饼图 + 「数据准确性占比」饼图；中部为「单库房已盘/未盘数量」柱状图（每库房一行，超出换行）；底部为「任务效率指标」卡片（超时率、平均耗时、耗时偏差，区分一次性/周期性）。
- **时间范围**：默认展示近 3 个月数据，可根据实际情况调整；趋势按月聚合。
- **维度切换**：数据准确性区域支持按库房 / cost center / 资产负责人切换统计维度。
- **下钻**：点击库房卡片可下钻至该库房相关的盘点任务列表；点击任务效率指标可跳转任务列表筛选对应类型。
- **移动端适配**：需考虑移动端适配（看板在小屏下按卡片纵向排列）。

## 4. 验收标准

- 总览页按独立库房维度正确展示已盘/未盘数量与占比（饼图），单库房以柱状图展示，库房较多时正确换行。
- 数据准确性占比仅基于「已盘范围」统计，支持库房 / cost center / 资产负责人三种维度切换。
- 任务效率指标（超时率、平均耗时、耗时偏差）区分一次性/周期性任务分别统计且数值准确。
- 可查看近 3 个月盘点结果，趋势按月聚合。
- 统计数据与盘点任务/结果的实际执行数据一致，复核后准确性以复核结果为准。

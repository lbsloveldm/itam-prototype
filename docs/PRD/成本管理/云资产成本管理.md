## 2. 需求分析

### 2.1 业务背景

云服务成本管理需解决四个核心问题：A. 花了多少钱；B. 钱花在哪里（计算/存储等资源）；C. 为什么花（成本带来的业务价值）；D. 如何优化（使用量/使用率）。结合系统已有云资源台账功能，当前仅能解决 A 与 B。本期基于台账的总成本、开通时间、结束时间计算每日/每月成本，并通过定时任务按月累计，提供多维度（时间、规格分类、部门、成本中心）的成本统计报表。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **成本可视**：解决「花了多少钱、钱花在哪里」，按月/季/年统计总成本，含同比与环比。
- **趋势分析**：最近一年月成本趋势、最近 30 天成本趋势、今年 VS 去年成本对比。
- **结构分析**：按规格分类（计算/存储/网络/数据库/安全）、按部门、按成本中心统计成本。
- **TOP 排名**：本月云资产成本 TOP10，快速定位高耗成本资源。

#### 2.2.2 调研结论及竞品分析

参考主流云成本管理（FinOps）方案：以资源计费周期计算每日/每月摊销成本，多维度聚合展示。本期基于台账字段实现单价推导与按月累计，不依赖外部账单接口即可给出成本视图（更细粒度账单见《费用条目-云资产账单费用》）。

### 2.3 用户故事

- 作为**成本管理员**，我希望看到云资产的月/季/年总成本及同比环比，以便掌握云支出走势。
- 作为**IT 经理**，我希望按规格分类、部门、成本中心查看成本分布，以便定位高耗方向。
- 作为**财务人员**，我希望看到本月成本 TOP10 与月度明细，以便优化预算分配。

## 3. 需求设计

### 3.1 成本计算与定时任务

#### 3.1.1 涉及到的表

- `cloud_resource_instance`（云资源实例/台账表，含总成本、开通时间、结束时间、所属部门、成本中心、规格分类）
- `cloud_cost_monthly`（按月累计成本统计表，定时任务写入）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 单价计算 | 根据台账总成本、开始时间、结束时间计算单价/天 | 单价 = 成本 /（终止时间 − 开通时间） |
| 按月累计任务 | 跑定时任务，按月统计累计成本 | 定时任务周期性汇总有效期内实例成本 |
| 有效期判定 | 终止时间不在上月（统计周期之前）的实例，本月均为有效期内 | 累加有效期内实例每月成本作为当月成本 |

#### 3.1.3 字段说明（成本计算相关）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 总成本 | 币种 | 20 | 台账中云资源实例的总成本 |
| 开通时间 | DATE | - | 实例开通/开始时间 |
| 终止时间 | DATE | - | 实例结束时间 |
| 单价/天 | 币种 | 20 | 成本 /（终止时间 − 开通时间），派生值 |
| 所属部门 | VARCHAR | 100 | 云资源实例所属部门，用于按部门统计 |
| 成本中心 | VARCHAR | 100 | 云资源实例成本中心，用于按成本中心统计 |
| 规格分类 | VARCHAR | 40 | 计算/存储/网络/数据库/安全资源 |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 规格分类 | 计算资源 / 存储资源 / 网络资源 / 数据库资源 / 安全资源 | 云资源五大规格类别，按类别柱状图展示成本 |

### 3.2 成本统计报表

#### 3.2.1 报表清单

| 报表名称 | 样式 | 描述/计算口径 |
| --- | --- | --- |
| 总成本（按月/季/年） | 概要数字 | 按月、季度、年统计总成本，包含同比与环比 |
| 最近一年月成本变化趋势 | 折线/柱状 | 最近一年每月成本展示（如 10 月查看时可见去年 11 月至今年 10 月）；每实例每月成本 = cost/月（结束时间 − 开通时间）；终止时间不在上月的实例本月均为有效期内，累加有效期内实例每月成本作为当月成本 |
| 最近 30 天成本趋势 | 折线图 | 计算实例每天费用 = cost /【天数（结束时间 − 开始时间）+ 1】；最近 30 天内终止时间不在昨天的实例当天均为有效期内，累加有效期内实例每天成本作为当天成本 |
| 成本对比（今年 VS 去年） | 双序列图 | 横轴为月份，纵轴为成本值；展示今年每月成本与去年每月成本 |
| 按规格分类统计每种云资源成本 | 柱状图 | 每种规格对应有效期内（未到结束时间）实例成本累加；规格五大类，柱状图展示 |
| 本月云资产成本 TOP10 | 排行 | 计算实例本月 cost 费用；仅统计结束日期不为上月（处于有效期）的实例 |
| 月度成本明细 | 明细表 | 本月不同规格分类云资产成本（本月有效期内实例按每月费用按规格类别累加） |
| 本月成本明细环比 | 明细/对比 | 月度成本明细的环比对比 |
| 按部门统计本月云资源成本 | 图表 | 按实例「所属部门」统计本月未过期云资源成本，右上方显示更新时间 |
| 按成本中心统计本月云资源成本 | 图表 | 按实例「成本中心」统计本月未过期成本，右上方显示更新时间 |

#### 3.2.2 关键计算口径说明

| 口径 | 说明 |
| --- | --- |
| 每月成本 | 每实例每月成本 = 结束时间 − 开通时间，按月 |
| 每天成本 | 每实例每天成本 = cost /【（结束时间 − 开始时间）天数 + 1】 |
| 有效期内累加（月） | 终止时间不在上月的实例，本月视为有效期内，累加其每月成本为当月成本 |
| 有效期内累加（天） | 最近 30 天内终止时间不在昨天的实例，当天视为有效期内，累加其每天成本为当天成本 |
| TOP10/月度明细范围 | 仅统计结束日期不为上月（处于有效期）的实例 |

### 3.3 页面功能与交互逻辑

#### 3.3.1 云资产成本报表页

- 顶部：总成本（可切换月/季/年）及同比、环比。
- 趋势区：最近一年月成本趋势、最近 30 天成本趋势、今年 VS 去年对比。
- 结构区：按规格分类成本（柱状图）、按部门成本、按成本中心成本（右上角显示更新时间）。
- 排名区：本月云资产成本 TOP10；月度成本明细及环比。

### 3.4 校验与约束

- 单价/天严格按「成本 /（终止时间 − 开通时间）」计算；每天成本分母为「天数 + 1」。
- 有效期判定：仅统计终止时间未早于统计周期（月/天）的实例。
- 按部门/成本中心统计仅计入本月未过期的实例。

## 4. 验收标准

- 定时任务按月正确累计有效期内实例成本；单价/天、每月/每天成本口径符合本文定义。
- 总成本支持按月/季/年统计并展示同比、环比。
- 趋势（最近一年月度、最近 30 天、今年 VS 去年）、规格分类、TOP10、月度明细、按部门/成本中心报表口径准确。
- 有效期内实例判定正确，过期实例不计入当期统计。

## 2. 需求分析

### 2.1 业务背景

现有系统仅有「一次性」与「周期性」两种费用类型，颗粒度过粗。在星宇车灯等项目中，客户对费用类型有更细的分类与记录要求（如采购费、实施费、维保服务费、许可证 费、订阅费、流量费等），需要通过扩展「子类型」属性实现更精细的费用管理与成本归集。同时，云资源账单需要以费用条目形式接入，作为云资产成本分析的数据来源。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **精细化费用分类**：在类型（一次性/周期性）之下新增子类型，满足客户对费用来源的细分记录。
- **自动化归集**：新建资产、流程节点完成时自动生成费用条目并挂载资产，减少人工登记。
- **流程直填费用**：支持在流程节点中直接输入费用，覆盖费率卡计算之外的实际支出。
- **云账单接入**：云账单费用按多维度归集，支撑云成本可视化与优化。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 的费用行（Expense line）模型：费用与资产/成本中心关联，区分 recurring 与 one-time，并支持来源追溯。本期在此基础上扩展子类型，并对齐云账单的产品/资源/账号多维明细。

### 2.3 用户故事

- 作为**财务人员**，我希望费用条目能按采购费/维修费/订阅费等子类型分类，以便精细核算与报表分析。
- 作为**运维工程师**，我希望在流程节点里直接填写实际发生的费用，系统据此生成费用条目并挂到资产，以便真实反映成本。
- 作为**成本管理员**，我希望云厂商账单能作为费用条目接入，并可按产品/账号维度查询成本明细。

## 3. 需求设计

### 3.1 费用条目子类型扩展

#### 3.1.1 涉及到的表

- `expense_line`（费用条目表，新增 子类型 字段）
- `asset`（资产主表，费用挂载对象）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 新增子类型字段 | 费用条目对象增加子类型（子类型）字段 | 子类型下拉选项随所选 一次性/周期性联动 |
| 新建资产默认子类型 | 新建资产时依据成本自动生成的费用条目，类型=一次性，子类型 默认「采购费」 | 历史数据不做处理 |
| 维修流程默认子类型 | 标品中流程产生费用仅维修流程，维修流程生成费用条目时默认 类型=一次性、子类型=维修费 | 触发条件：维修流程节点完成 |
| 流程增加子类型选项 | 流程节点产生费用时可选择/记录子类型 | 生成费用条目时记录子类型 |

#### 3.1.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 类型 | VARCHAR | 40 | 费用类型，字典：一次性 / 周期性 |
| 子类型 | VARCHAR | 40 | 费用子类型，选项随 类型 联动，见 3.1.4 |
| Amount | 币种 | 20 | 费用金额 |
| 父级 | VARCHAR | 32 | 费用条目父级引用，为空的条目参与 资产 TCO 汇总 |
| 资产 | VARCHAR | 32 | 关联资产（费用挂载对象） |
| Task | VARCHAR | 200 | 流程生成时展示「任务名称+节点名称」，可点击跳转 DOSM 工单 |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 类型 | 一次性（One-time） | 一次性费用 |
| 类型 | 周期性（Recurring） | 周期性费用 |
| 一次性 | 采购费 / 实施费 / 培训费 / 维修费 / 维保服务费 / 二次开发费 / 许可证 费 / 其他一次性费用 | 一次性类型下的子类型选项 |
| 周期性 | 维护费 / 维保费 / 许可证费 / 支持费 / 订阅费 / 流量费 / 云服务器费 / 其他周期性费用 | 周期性类型下的子类型选项 |

> 说明：子类型下拉项支持按项目灵活配置增删；星宇车灯等项目可在此基础上叠加专属选项。

### 3.2 流程中直接输入费用生成费用条目

#### 3.2.1 涉及到的表

- `expense_line`（费用条目表）
- `labor_rate_card` / `task_rate_card`（费率卡表，未直填时的兜底计算）
- `asset`（资产主表）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 判定是否直填 | 节点中先判定用户是否已直接输入费用 | 已输入则按用户输入金额生成费用条目并挂对应资产，需记录费用子类型 |
| 未直填走原逻辑 | 若用户未输入节点费用，则继续走原有费率卡计算流程 | 见 3.2.3 原有费用条目生成逻辑 |
| TCO 统计不变 | TCO 展示仍按 类型 统计 | 父资产 One-time = 父资产一次性费用 + 所有子资产一次性费用；父资产 Recurring = 父资产 Recurring + 所有子资产 Recurring |

#### 3.2.3 原有费用条目生成逻辑（费率卡兜底）

| 需求点 | 逻辑描述 |
| --- | --- |
| 节点费用生成 | 资产涉及的流程节点被完成时，计算该节点费用并挂在对应资产下 |
| 多资产分摊 | 一个节点费用涉及多资产时，按「总费用/资产数量」得到单资产费用 |
| 人工费率优先级 | 执行人关联的单小时费用有多条时，以人工费率卡 排序 小的为准 |
| 人工费率兜底 | 执行人未定义人工费率卡时，以任务节点费率卡的 默认 rate card 为准 |
| 固定费用优先级 | 关联到的固定节点费用有多条时，以任务定义中 排序 小的为准 |
| 时长取整 | DOSM 时长向上取整（如 3.12 小时取整为 4 小时）计算消耗小时数 |
| 类型 归类 | 由 cost 生成 类型=One-time，其他 类型=Recurring；TCO 柱状图按颜色区分 |

### 3.3 云资产账单费用（费用来源接入）

#### 3.3.1 涉及到的表

- `cloud_bill`（云账单费用表，采集侧接入）
- `cloud_resource_instance`（云资源实例表，六类标签属性）
- `expense_line`（费用条目表，归集接口）

#### 3.3.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 账单采集接入 | 采集云厂商账单数据，按自然月/资源/产品/账号归集 | 云厂商接口提供累计数据，可获取累计或按天累加 |
| 实际成本计算 | 实际成本 = 应付金额 - 现金券 - 代金券 | 优惠金额/代金券抵扣取决于 API 是否可获取 |
| 成本明细搜索 | 成本明细放在报表中展示，提供可搜索能力 | 支持按资源名称/ID、产品、产品类型、账号搜索；支持按时间范围（精确到年月日） |
| 分组汇总下钻 | 按分组维度逐级下钻 | 分组维度层级：资源名称/ID < 产品 < 产品类型 < 账号 < 项目 |
| 筛选后总成本 | 在选定时间范围内，按筛选条件筛出的所有数据产生的总成本 | 筛选后聚合 |

#### 3.3.3 字段说明（云账单成本明细）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 资源名称 / 资源 ID | VARCHAR | 100 | 云资源唯一标识，按独立资源 ID 统计资源数量 |
| 产品（Product） | VARCHAR | 100 | 云产品名称（如 EC2、RDS、S3） |
| 产品类型（产品类型） | VARCHAR | 100 | 服务类型（计算/存储/网络/数据库/AI/安全等） |
| 账号（Account） | VARCHAR | 100 | 云账号 |
| 项目（Project） | VARCHAR | 100 | 归属项目（分组最高层级维度之一） |
| 计费类型 | VARCHAR | 40 | 云计费类型（按量/包年包月等） |
| 应付金额 | 币种 | 20 | 账单应付金额 |
| 现金券 | 币种 | 20 | 现金券抵扣金额（取决于 API 可得） |
| 代金券 | 币种 | 20 | 代金券抵扣金额（取决于 API 可得） |
| 实际成本 | 币种 | 20 | 实际成本 = 应付金额 - 现金券 - 代金券 |
| consumer_date | DATE | - | 消费日期（明细统计维度） |
| component | VARCHAR | 100 | 计费组件（分组汇总的最细维度） |

#### 3.3.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 分组维度层级 | 资源名称/ID < 产品 < 产品类型 < 账号 < 项目 | 从项目视角逐级下钻，查看每个项目下各账号、各类产品的资源明细 |
| 搜索统计维度 | 按资源名称/ID / 按产品 / 按产品类型 / 按账号 | 成本明细报表的四种统计维度，各维度字段集不同（详见设计稿电子表格） |

### 3.4 页面功能与交互逻辑

#### 3.4.1 费用条目列表页

- 展示费用条目记录，支持按 类型、子类型、资产、Task 筛选；子类型随类型联动。
- 支持新建、编辑费用条目；自动生成的条目 Task 字段可点击跳转 DOSM 工单。

#### 3.4.2 资产详情-Expense line 页签

- 展示挂载在该资产下的所有费用条目；父级 为空的条目参与 资产 TCO 汇总。
- 自动生成条目的 类型/子类型 按 3.1 规则填充。

#### 3.4.3 云资产账单费用页

- 提供成本明细可搜索报表，支持按资源/产品/产品类型/账号 + 时间范围搜索与分组汇总下钻。

### 3.5 校验与约束

- 子类型 选项必须与所选 类型 匹配（一次性/周期性各自的子类型集）。
- 新建资产、维修流程自动生成的费用条目按默认子类型规则填充，历史数据不回溯处理。
- 云账单实际成本严格按「应付金额 - 现金券 - 代金券」口径计算。

## 4. 验收标准

- 费用条目支持子类型字段，子类型选项随 类型 联动且可按项目配置。
- 新建资产自动生成费用条目默认 类型=一次性、子类型=采购费；维修流程默认 子类型=维修费。
- 流程节点支持直接输入费用生成条目并记录子类型；未直填时走费率卡兜底逻辑。
- 云账单费用可按资源/产品/产品类型/账号 + 时间范围搜索并逐级下钻；实际成本口径正确。

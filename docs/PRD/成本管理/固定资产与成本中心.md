## 2. 需求分析

### 2.1 业务背景

企业对资产的财务管理诉求，核心是「资产价值随生命周期变化的可核算性」与「成本可归属到组织单元」。资产入账后成为固定资产（已资本化），需要按折旧方案计提折旧、维护原值/累计折旧/净值；同时企业需要以成本中心为组织维度，将折旧、费用条目等成本归集到对应部门/组织，支撑预算与成本分析。

原型 `cost/` 模块已实现固定资产台账与成本中心的增删改查骨架，本 PRD 在此基础上，结合折旧方案、费用条目（含《费用条目属性扩展》子类型）、TCO 上下文，明确固定资产台账字段、成本中心字段与成本归集逻辑。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **资产价值可核算**：以原值/累计折旧/净值三要素维护资产账面价值，净值随折旧自动回算，保证账实一致。
- **折旧自动化**：固定资产引用折旧方案，按方法（直线法/余额递减法/自定义）与周期计提，减少手工核算。
- **成本可归属**：以成本中心为组织单元归集折旧与费用，支持父子层级的成本汇总与下钻。
- **费用精细化**：结合费用条目子类型（采购费/维修费/订阅费等），实现成本的精细分类与 TCO 统计。
- **财务对齐**：入账日期、币种、成本中心等字段对齐财务核算口径，为报表与预算提供数据基础。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 成本 Management / 固定资产管理：资产与折旧方案关联，按成本中心归集成本；成本中心支持层级结构用于成本汇总与分摊。结论：固定资产台账以「原值/累计折旧/净值 + 折旧方案 + 成本中心 + 入账日期」为核心；成本中心以「名称/编码/负责人/父级/描述」为核心并支持父子层级，父级下拉需排除自身避免自引用。

### 2.3 用户故事

- 作为**财务人员**，我希望为已资本化资产建立固定资产台账并维护原值/累计折旧/净值，以便进行资产价值核算。
- 作为**财务人员**，我希望为固定资产选择折旧方案并让净值随原值/累计折旧自动回算，以便账面价值准确一致。
- 作为**成本管理员**，我希望以成本中心为组织单元归集资产成本，并支持父子层级，以便按组织维度统计与下钻成本。
- 作为**成本管理员**，我希望新建成本中心时选择父级且不能选到自身，以便维护正确的成本中心树。

## 3. 需求设计

### 3.1 固定资产台账

#### 3.1.1 涉及到的表

- `fixed_asset`（固定资产主表）
- `asset`（资产台账，引用 `assetTag`）
- `depreciation_schema`（折旧方案，引用 `名称`）
- `cost_center`（成本中心，引用 `名称`）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 新建固定资产 | 支持新建固定资产台账（资产/名称/原值/累计折旧/币种/折旧方案/成本中心/入账日期） | 分「基本信息」「成本与折旧」两组表单；`createdBy`/`createdTime` 系统写入 |
| 净值自动回算 | 保存时净值 = 原值 − 累计折旧 | 保存时自动计算并回写 `netValue`，保留两位小数，避免手工不一致 |
| 关联资产 | `assetTag` 引用资产台账中的资产（如 P000000204） | 固定资产由已资本化资产实例化，`assetTag` 与资产台账对齐 |
| 关联折旧方案 | 选择折旧方案驱动累计折旧计提 | `depreciationSchema` 引用折旧方案 `名称`；可为空（未启用折旧） |
| 关联成本中心 | 选择成本中心作为成本归属单元 | `costCenter` 必填，引用成本中心 `名称` |
| 列表查看 | 展示资产、名称、原值、累计折旧、净值、折旧方案、成本中心、入账日期 | 支持按资产/名称搜索；资产列点击进详情；原值随币种展示（`原值 币种`） |
| 编辑/删除 | 详情可编辑保存；列表/详情支持删除（二次确认） | 删除采用 Popconfirm 二次确认 |
| 深链守卫 | 访问不存在的固定资产 ID 展示 404 结果页与返回入口 | 复用统一 404 结果页 |

#### 3.1.3 字段说明（固定资产台账）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| id | VARCHAR | 32 | 主键 |
| 资产 | VARCHAR | 40 | 必填，引用资产台账 资产.资产标识，如 P000000204 |
| 名称 | VARCHAR | 100 | 必填，固定资产名称，showCount 计数 |
| 原值 | DECIMAL | 20,2 | 必填，入账初始价值，最小值 0 |
| 累计折旧 | DECIMAL | 20,2 | 必填，已计提折旧总额，最小值 0 |
| 净值 | DECIMAL | 20,2 | 系统回算 = 原值 − 累计折旧，保留两位小数，只读 |
| 币种 | VARCHAR | 10 | 必填，见字典值（默认 USD($)） |
| 折旧方案 | VARCHAR | 40 | 可空，引用折旧方案 直线法/余额递减法/自定义 |
| 成本中心 | VARCHAR | 100 | 必填，引用成本中心 名称 |
| 入账日期 | DATE | - | 必填，如 2025-02-20 |
| 创建人 | VARCHAR | 40 | 系统写入 |
| 创建时间 | TIMESTAMP | - | 系统写入 |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 币种 | CNY(¥) | 人民币 |
| 币种 | USD($) | 美元（新建默认值） |
| 币种 | EUR(€) | 欧元 |
| 折旧方案-类别 | 直线法 / 余额递减法 / 自定义 | 引用折旧方案的折旧方法类别（详见《折旧方案》） |
| netValue 计算规则 | 净值 = 原值 − 累计折旧 | 保存时自动回算，保留两位小数 |

### 3.2 成本中心

#### 3.2.1 涉及到的表

- `cost_center`（成本中心主表，父级自引用 `parent → cost_center.名称`）
- `fixed_asset` / `expense_line`（引用成本中心进行成本归集）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 新建成本中心 | 支持新建成本中心（名称/编码/负责人/父级/描述） | `createdBy`/`createdTime` 系统写入 |
| 父子层级 | 支持通过 `parent` 建立成本中心树 | 父级下拉引用其他成本中心 名称，排除自身避免自引用 |
| 列表查看 | 展示名称、编码、负责人、父级、描述、创建人、创建时间 | 支持按名称/编码搜索；名称点击进详情；父级为空展示「-」 |
| 编辑/删除 | 详情可编辑保存；列表/详情支持删除（二次确认） | 删除采用 Popconfirm 二次确认 |
| 深链守卫 | 访问不存在的成本中心 ID 展示 404 结果页与返回入口 | 复用统一 404 结果页 |
| 成本归集入口 | 成本中心作为固定资产折旧与费用条目的成本归属单元 | 详见 3.3 成本归集逻辑 |

#### 3.2.3 字段说明（成本中心）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |

| 负责人 | VARCHAR | 60 | 必填，如 客服经理 - 周主任(Demo User1) |
| 父级 | VARCHAR | 100 | 可空，引用其他成本中心 名称，排除自身 |
| 描述 | VARCHAR | 255 | 可空，多行文本，showCount 计数 |
| 创建人 | VARCHAR | 40 | 系统写入 |
| 创建时间 | TIMESTAMP | - | 系统写入 |

#### 3.2.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 父级 | 引用其他成本中心 名称 | 下拉候选为除自身外的全部成本中心，避免自引用 |

### 3.3 成本归集逻辑

#### 3.3.1 涉及到的表

- `fixed_asset`（原值/累计折旧/净值来源）
- `expense_line`（费用条目，一次性/周期性 + 子类型）
- `cost_center`（成本归属单元）
- `depreciation_schema`（折旧计提规则）

#### 3.3.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 折旧计提 | 固定资产按引用的折旧方案计提折旧，更新累计折旧与净值 | 依折旧方案类别（直线法/余额递减法/自定义）与周期（天/月/年）计算；净值=原值−累计折旧 |
| 成本按中心归集 | 折旧、费用条目按资产所属成本中心汇总归属 | 固定资产/费用条目携带 `costCenter`，按成本中心（含父子层级）汇总成本 |
| 费用条目子类型归集 | 费用条目区分一次性/周期性及子类型，参与成本分类统计 | 新建资产依据成本自动生成「一次性-采购费」费用条目；维修流程生成「一次性-维修费」（详见《费用条目属性扩展》） |
| TCO 汇总 | 资产原值 + 折旧 + 费用条目进入 TCO 统计 | 父资产 One-time =（父资产一次性费用 + 所有子资产一次性费用）；Recurring 同理累加（详见《资产总拥有成本TCO》《费用条目属性扩展》） |
| 层级下钻 | 成本可按成本中心父子层级下钻/上卷 | 子成本中心成本汇总到父成本中心 |

#### 3.3.3 字段说明（成本归集关联字段）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| fixed_asset.costCenter | VARCHAR | 100 | 折旧/原值归集到的成本中心 |
| fixed_asset.depreciationSchema | VARCHAR | 40 | 决定折旧计提方式 |
| expense_line.费用类型 | VARCHAR | 20 | 一次性 / 周期性（详见字典值） |
| expense_line.费用子类型 | VARCHAR | 40 | 采购费/维修费/订阅费等（详见字典值，源自《费用条目属性扩展》） |
| 成本中心.parent | VARCHAR | 100 | 支持父子层级的成本上卷/下钻 |

#### 3.3.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| expense_line.费用类型 | 一次性（One-time） / 周期性（Recurring） | TCO 柱状图按类型不同颜色表征 |
| expense_line.一次性子类型 | 采购费 / 实施费 / 培训费 / 维修费 / 维保服务费 / 二次开发费 / License费 / 其他一次性费用 | 源自《费用条目属性扩展》，一次性费用子类型 |
| expense_line.周期性子类型 | 维护费 / 维保费 / 许可证费 / 支持费 / 订阅费 / 流量费 / 云服务器费 / 其他周期性费用 | 源自《费用条目属性扩展》，周期性费用子类型 |
| 自动生成子类型规则 | 新建资产→一次性/采购费；维修流程→一次性/维修费 | 依据成本/流程自动生成费用条目时的默认子类型（历史数据不处理） |

> 备注：费用条目完整字段与生成逻辑以《费用条目》《费用条目属性扩展》为准；TCO 统计口径以《资产总拥有成本TCO》为准；折旧计算细节以《折旧方案》为准。本 PRD 聚焦固定资产台账、成本中心与成本归集入口。

## 4. 验收标准

- 固定资产可完成新建/查看/编辑/删除，字段与字典值符合本文定义；净值在保存时按「原值 − 累计折旧」自动回算并保留两位小数。
- 固定资产可关联资产（资产标识）、折旧方案、成本中心；币种支持 CNY(¥)/USD($)/EUR(€)，新建默认 USD($)。
- 成本中心可完成新建/查看/编辑/删除，支持父子层级；父级下拉排除自身，无自引用。
- 列表搜索、详情分组（基本信息/成本与折旧）、404 守卫、删除二次确认均生效。
- 折旧、费用条目（含一次性/周期性及子类型）可按成本中心归集，并支持父子层级上卷/下钻；TCO 汇总口径与《资产总拥有成本TCO》《费用条目属性扩展》一致。

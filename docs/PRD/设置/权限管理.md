## 2. 需求分析

### 2.1 业务背景

菜单权限（角色管理）解决「能否访问某功能」的问题，但企业还需控制「能看到哪些数据」。权限管理提供数据权限能力：为「数据表 + 角色」配置数据权限范围（如本部门/仅本人），并以权限标签分类、可启用/禁用。这是资产、盘点、合同等敏感数据在多部门/多角色环境下合规访问的基础。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **数据可见性管控**：按数据表+角色配置可见范围，落实最小权限与数据合规。
- **标签化管理**：以权限标签分类规则，便于批量识别与维护。
- **可启停**：规则可启用/禁用，支持灰度与临时收权。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 的 ACL / Data Policy 与常见 RBAC 的数据范围（Data Scope）机制：以「表 + 角色 + 条件」控制行/列级访问。本原型简化：真实产品含行配置/列配置的条件构造器（page_281/282），此处以单选的「数据权限范围」作为替代（见第 6 节）。

### 2.3 用户故事

- 作为**权限管理员**，我希望为某角色在某数据表上设置数据可见范围，以便控制敏感数据访问。
- 作为**审计人员**，我希望权限规则可启停并带标签，以便审查与临时收权。

## 3. 需求设计

### 3.1 权限管理（数据权限）

#### 3.1.1 涉及到的表

- `assetPermissions`（权限规则表，`PermissionRule`）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 权限列表 | 展示全部权限规则，支持搜索 | 搜索字段 `dataTable / role / permissionTag`；是否启用以彩色 启用=绿/禁用=默认 |
| 新建权限 | 进入详情页新建 | 跳转 `/asset/settings/permission/new`；默认 数据权限范围=本部门、启用=true |
| 编辑权限 | 修改权限规则 | 保存更新 |
| 删除权限 | 列表/详情删除，二次确认 | 列表行内 Popconfirm「确定删除该权限配置？」 |
| 数据表下拉 | 数据表可选内置表 | 选项：软件资产/软件授权/硬件资产规格/硬件资产/盘点任务/合同审批 |
| 权限标签下拉 | 权限标签可选，允许清空 | 选项：开发/运维/资产规格/财务/审计/只读（allowClear） |
| 数据权限范围下拉 | 配置可见范围 | 选项：全部数据/本部门/本部门及下级/仅本人/自定义 |

#### 3.1.3 字段说明

字段来源：`assetPermissions.ts` 的 `PermissionRule`。

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| id | VARCHAR | - | 主键（系统生成，如 `perm_sw_asset`） |
| 数据表 | VARCHAR | - | 必填，下拉选择作用的数据表 |
| 角色 | VARCHAR | - | 必填，文本输入，如「资产管理组/开发」 |
| 权限标签 | VARCHAR | - | 下拉选择，可清空，空显示 `-` |
| 数据权限范围 | VARCHAR | - | 必填，下拉选择 |
| 是否启用 | BOOLEAN | - | 启用/禁用，列表 标签 |
| 备注 | VARCHAR | 200 | 多行文本，`maxLength=200` |
| 创建人 | VARCHAR | - | 创建人（新建默认 `管理员`） |
| 创建时间 | TIMESTAMP | - | 创建时间 |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 数据表 | 软件资产 / 软件授权 / 硬件资产规格 / 硬件资产 / 盘点任务 / 合同审批 | 权限作用的对象表（`DATA_TABLES`） |
| 权限标签 | 开发 / 运维 / 资产规格 / 财务 / 审计 / 只读 | 权限标签池（`PERMISSION_TAGS`），可清空 |
| 数据权限范围 | 全部数据 | 可见全部数据 |
| 数据权限范围 | 本部门 | 仅本部门数据（新建默认） |
| 数据权限范围 | 本部门及下级 | 本部门及其下级部门数据 |
| 数据权限范围 | 仅本人 | 仅本人相关数据 |
| 数据权限范围 | 自定义 | 自定义范围（原型为占位，见简化说明） |
| 是否启用 | 启用 / 禁用 | 规则是否生效（列表 标签：启用=绿/禁用=默认） |

### 3.2 页面功能与交互逻辑

#### 3.2.1 列表页（`/asset/settings/permission`）

- **列表列**：数据表（可点击进详情）、角色、权限标签（蓝色 标签，空显示 `-`）、数据权限范围、是否启用（标签）、操作（删除）。
- **搜索**：按 数据表 / 角色 / 权限标签（`dataTable / role / permissionTag`）。
- **操作**：新建（跳详情）、删除（行内 Popconfirm）。

#### 3.2.2 详情/新建页（`/asset/settings/permission/:id`）

- **基本信息卡片**：数据表（下拉）、角色（文本，如「资产管理组/开发」）、权限标签（下拉，可清空）、数据权限范围（下拉）、是否启用（Switch）、备注（多行文本 ≤200）。
- **校验**：数据表、角色、数据权限范围必填。
- **新建默认值**：数据权限范围=本部门、是否启用=true；创建人默认 `管理员`。
- **404 守卫**：访问不存在的权限 ID 展示「未找到该权限配置」结果页与「返回权限管理」入口。

## 4. 验收标准

- 权限列表可搜索；权限标签/是否启用以正确 标签 展示，空标签显示 `-`。
- 详情页可完成新建/编辑/删除；数据表/权限标签/数据权限范围下拉选项符合本文清单。
- 数据表/角色/数据权限范围必填校验、404 守卫生效；新建默认 范围=本部门、启用=true。
- 各字段与字典值符合本文定义。

## 6. 简化说明（原型范围）

- **数据权限范围简化**：真实产品含行配置/列配置的条件构造器（page_281/282），本原型以单选的「数据权限范围」作为替代。
- **自定义范围占位**：`自定义` 选项在原型中为占位，未提供条件构造 以原型为准。
- **角色为自由文本**：本页角色为文本输入（如「资产管理组/开发」），与用户中心角色清单未做强引用（以原型为准）。

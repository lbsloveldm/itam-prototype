## 2. 需求分析

### 2.1 业务背景

不同行业、规模、组织的资产类型和管理重点各异，采用固定编码难以普适。系统需要提供「自定义资产唯一编码规则」能力，使各部门可协商制定公司统一的编码规范，避免各自为政造成的编码混乱，并为新员工提供清晰的资产识别指引。资产标识作为资产的唯一身份，贯穿资产创建、盘点、维护、处置全生命周期。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **统一编码规范**：以公司维度统一各类资产的编码格式，消除编码冲突与歧义。
- **灵活可配置**：采用「分段组合」模式，管理员可按资产类型/规格分类自由定义，适配不同管理颗粒度。
- **唯一性保障**：通过启用校验与流水号自增机制，保证同一覆盖范围内编码全局唯一。
- **可识别性**：清晰的前缀与分段结构便于人工识别与快速定位资产。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow HAM：资产标签（资产标识）按前缀规则自动生成（如硬件 `P` 前缀 + 递增序号）；支持按资产类别配置不同前缀。本方案在此基础上增强为「分段组合」的可视化规则构建器，并支持覆盖范围的细颗粒度优先级生效。

### 2.3 用户故事

- 作为**资产管理员**，我希望自定义各资产类型的编码规则，以便公司资产编码统一规范。
- 作为**IT 运维**，我希望某一细分类别（如空调）拥有专属编码规则，以便按更细颗粒度识别资产。
- 作为**新员工**，我希望通过资产标识前缀快速判断资产类型，以便高效开展盘点与维护。

## 3. 需求设计

### 3.1 设计思路

编码规则采用「分段组合」模式，由管理员在系统中自由定义。一个完整的编码由若干「段」顺序构成，每段可从以下三种类型中选择和配置：**固定字符、公共属性、流水号**（另支持创建日期段）。允许创建多个规则，但同一覆盖范围仅允许一个规则处于启用状态。

### 3.2 入口

在「设置」中，增加「资产标识配置规则」菜单，点击后进入列表页可查看当前已有规则。其中「规则名称」字段可点击，点击后进入规则详情页。

### 3.3 列表页字段说明

#### 3.3.1 涉及到的表

- `asset_identifier_rule`（资产标识规则主表）
- `asset_identifier_rule_segment`（规则分段配置表）
- `model_category`（资产规格分类表，引用）

#### 3.3.2 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 规则名称 | VARCHAR | 128 | 规则的显示名称，列表页可点击进入详情 |
| 资产类型 | VARCHAR | 32 | 规则覆盖的资产类型（硬件/软件/耗材/云/捆绑/托盘），配置项中不包括合同 |
| 资产规格分类 | VARCHAR | 32 | 规则覆盖的规格分类，非必填；无则展示「无」 |
| 唯一性属性 | VARCHAR | 128 | 保证唯一的属性组合，如「固定字符、流水号」 |
| 状态 | VARCHAR | 8 | 启用 / 禁用 |
| 固定字符（前缀） | VARCHAR | 10 | 编码前缀，如硬件为「P」 |
| 流水号位数 | INTEGER | - | 流水号位数，下拉可选 5/6/7/8/9 位 |
| 流水号起始值 | INTEGER | - | 流水号起始值，可不填，最小为 1 |
| 连接符 | VARCHAR | 8 | 段间分隔符（短横线/下划线/无） |
| 创建人 | VARCHAR | 64 | 规则创建人（姓名+用户名） |
| 创建时间 | TIMESTAMP | - | 规则创建时间 |

### 3.5 新增配置规则

#### 3.5.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 第一步：选择覆盖范围 | 选择资产类型与资产规格分类 | 资产类型展示当前已有的所有类型及「全选」；配置项中不包括合同 |
| 资产规格分类联动 | 分类下拉随资产类型联动 | 资产类型未选或选「全选」时，分类下拉显示：系统已有全部规格分类 + 「全选」，非必填；选择部分资产类型时，分类下拉仅显示该类型下已有分类 + 「全选」 |
| 覆盖范围校验 | 至少选一个规格才可保存 | 资产类型/资产规格分类至少选择一个，否则无法保存 |
| 第二步：设定规则（添加规则模块） | 规则可为多个或 1 个 | 支持添加多段规则并排序 |
| 段类型-公共属性 | 选中覆盖范围对应实例表已有属性 | 下拉展示可选属性 |
| 段类型-流水号 | 可选位数 | 下拉显示 5/6/7/8/9 位 |
| 段类型-创建日期 | 可选粒度 | 下拉显示年、年月、年月日，并基于当前年份给出示例（如 202511） |
| 段排序（拖动） | 调整规则顺序 | 选择某行规则时可上下拖动调整顺序 |
| 第三步：基础设置-连接符 | 段间连接符 | 下拉选择连接符 |
| 第三步：基础设置-流水号起始值 | 起始值 | 可不填，最小值 1；不填时系统默认从当前已有流水号+1 开始生成并自增；流水号不随日期或公共属性重置，全部自动自增 |
| 是否启用 | 规则生成后状态 | 默认启用；否则为禁用 |
| 预览 | 展示编码示例 | 根据设置的规则实时展示编码示例 |
| 单一日期与流水号约束 | 一个规则内唯一 | 新建规则时只允许有一个创建日期段及一个流水号段，不可在一个规则中创建多个「创建日期/流水号」 |

#### 3.5.2 段类型字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 段类型 | 固定字符 | 人工输入的固定字符串，如前缀「P」 |
| 段类型 | 公共属性 | 覆盖范围对应实例表中已有的属性，下拉选择 |
| 段类型 | 流水号 | 自增数字段，可选位数 5/6/7/8/9 位 |
| 段类型 | 创建日期 | 日期段，粒度可选：年 / 年月 / 年月日 |
| 流水号位数 | 5 / 6 / 7 / 8 / 9 | 流水号占位数 |
| 创建日期粒度 | 年 / 年月 / 年月日 | 示例基于当前年份，如 202511 |
| 连接符 | 短横线(-) / 下划线(_) / 无 | 段与段之间的分隔符 |
| 状态 | 启用 / 禁用 | 规则生效状态 |

### 3.6 启用、禁用、编辑、删除操作

| 操作 | 规则描述 |
| --- | --- |
| 删除 | 对于状态为「启用」的规则不可删除，必须先禁用再删除 |
| 编辑 | 可对已禁用的规则进行编辑；启用中的规则不可编辑 |
| 启用 | 启用时需校验：系统已启用规则对同一「资产类型」或「资产类型+资产规格分类」的唯一性属性不相同，才可启用；否则启用失败，提示「当前已有启用规则{规则名称}对于{资产类型}/{资产类型+资产规格分类}生成资产标识，请先禁用，再启用当前规则」。允许创建多个规则，但同一覆盖范围仅允许一个启用 |
| 禁用 | 可对已启用的配置规则进行禁用 |

#### 3.6.1 细颗粒度优先级生效

启用规则时，若覆盖范围有更细颗粒度的规则，则按细颗粒度来生成。例如：硬件资产有规则 A，硬件资产→空调有规则 B，则 A、B 可同时生效；生成空调实例时以 B 为准，其他硬件资产实例以 A 规则为准。

### 3.7 生成异常与提示

| 场景 | 系统行为 |
| --- | --- |
| 编号资源耗尽 | 新增资产时若无法再生成资产标识，则增加资产失败，提示「无法生成新的资产标识！当前类型的资产标识编号资源已耗尽，需要新建规则。」 |
| 无对应规则 | 新增资产时若系统找不到对应类型的规则，则增加资产失败，提示「无法生成新的资产标识！当前类型的资产标识不存在生成规则，需要新建规则。」 |

### 3.8 页面功能与交互逻辑

#### 3.8.1 列表页

- 展示全部规则，列：规则名称（可点击）、资产类型、资产规格分类、唯一性属性、状态。
- 操作：新建、编辑（仅禁用态）、启用/禁用、删除（仅禁用态，二次确认）。

#### 3.8.2 详情/新建页

- 分区：**基本信息**（规则名称、资产类型、状态开关）、**规则配置**（固定字符前缀 + 流水号位数 + 起始值 + 连接符）、**预览**（实时示例）。
- 深链访问不存在的规则 ID 时展示 404 结果页与「返回资产标识配置规则」入口。
- 保存时做必填与唯一性校验。

### 3.9 日志审计

规则的新增、编辑、启用、禁用、删除操作按统一日志规范记录，格式示例：【操作人】于【时间】对模块【设置/资产标识配置规则】执行了【操作】操作，操作内容为【规则名称】，操作结果为【成功/失败】。

## 4. 验收标准

- 「设置」下存在「资产标识配置规则」入口，列表可查看六种系统默认规则且默认启用。
- 可完成规则的新建、编辑（仅禁用态）、启用/禁用、删除（仅禁用态）全流程。
- 启用校验生效：同一覆盖范围仅允许一个启用规则，冲突时给出规定提示文案。
- 细颗粒度规则优先生效：类型级与「类型+分类」级规则可同时启用，实例生成以细颗粒度为准。
- 编码资源耗尽/无规则时按规定文案阻断资产创建。
- 新建页可实时预览编码示例，深链 404 守卫生效。

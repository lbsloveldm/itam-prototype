## 2. 需求分析

### 2.1 业务背景

ITAM 中不同资产类型（硬件规格、耗材、硬件台账、软件授权等）拥有不同的属性集合与列表列。Class管理提供元模型能力：为每类实体定义其表单字段（核心属性）与表格显示列，从而在不改代码的前提下扩展属性、调整展示。内置 Class 保障核心实体稳定，自定义 Class 支持业务扩展。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **元模型可配置**：以 Class 定义实体的字段与列，支撑属性扩展与展示定制。
- **内置保护**：内置 Class 不可删除、类别编码 不可改，保障核心数据结构稳定。
- **表单/表格解耦**：表单字段与显示列分别配置，兼顾录入与浏览两类场景。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 的 Table/Dictionary 与 Form/列表 Layout：以表定义字段字典，以 Form Layout / 列表 Layout 配置录入表单与列表列。本原型简化：真实产品为拖拽式表单/表格设计器（page_289/295），此处简化为可增删的字段行列表（见第 6 节）。

### 2.3 用户故事

- 作为**系统配置管理员**，我希望为一类资产定义表单字段与显示列，以便快速扩展属性。
- 作为**管理员**，我希望内置 Class 受保护，以免误删破坏核心数据结构。

## 3. 需求设计

### 3.1 Class管理

#### 3.1.1 涉及到的表

- `assetClasses`（Class 主表，`AssetClass`）
- 嵌套结构 `ClassField`（表单字段/显示列的字段行）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| Class 列表 | 展示全部 Class，支持搜索 | 搜索字段 `名称 / classCode / tableName`；是否内置、Class类型以彩色 标签 展示 |
| 新建 Class | 进入详情页新建 | 跳转 `/asset/settings/class/new`；新建 `builtIn=false`，默认 Class类型=table |
| 编辑 Class | 修改基本信息与字段 | 保存更新表单字段与显示列；类别编码 编辑态不可改（`disabled={!isNew}`） |
| 删除 Class | 删除非内置 Class | 内置 Class 的删除按钮禁用（列表与详情均如此） |
| 表单字段设计 | 「表单管理」配置核心属性 | 增删字段行（字段标识/显示名称/字段类型/必填/显示） |
| 表格列设计 | 「表格管理」配置显示列 | 增删列行，字段结构同表单字段 |

#### 3.1.3 字段说明（Class 主表）

字段来源：`assetClasses.ts` 的 `AssetClass`。

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| id | VARCHAR | - | 主键（系统生成，如 `cls_hw_model`） |
| 名称 | VARCHAR | 100 | 必填，`maxLength=100`，showCount |
| classCode（类别编码） | VARCHAR | 100 | 必填，`maxLength=100`，新建后不可改 |
| 表名 | VARCHAR | 100 | 必填，`maxLength=100` |
| 是否内置 | BOOLEAN | - | true=内置（不可删除），列表 是=蓝/否=默认 |
| Class类型 | VARCHAR | - | table / view，列表 标签（table=geekblue/view=purple） |
| 标签 | VARCHAR | 100 | `maxLength=100`，如 规格/consumable/asset/license；空显示 `-` |
| 表单字段 | ARRAY(ClassField) | - | 表单管理配置的字段行集合 |
| 显示列 | ARRAY(ClassField) | - | 表格管理配置的列行集合 |
| 创建人 | VARCHAR | - | 创建人（新建默认 `kaka`） |
| 创建时间 | TIMESTAMP | - | 创建时间 |

#### 3.1.4 字段说明（字段行 ClassField）

字段来源：`assetClasses.ts` 的 `ClassField`（表单字段与显示列共用）。

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 字段标识 | VARCHAR | - | 字段唯一标识，如 `category_id` |
| 显示名称 | VARCHAR | - | 字段展示名，如「规格类别」 |
| 字段类型 | VARCHAR | - | 单行文本/多行文本/数字/开关/下拉/日期/附件 |
| 必填 | BOOLEAN | - | 是否必填（复选） |
| 显示 | BOOLEAN | - | 是否显示（复选） |

#### 3.1.5 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| Class类型 | table | 物理表（列表 标签=geekblue） |
| Class类型 | view | 视图（列表 标签=purple） |
| 是否内置 | 是 / 否 | 内置 Class 不可删除（列表 标签：是=蓝/否=默认） |
| ClassField.字段类型 | 单行文本 / 多行文本 / 数字 / 开关 / 下拉 / 日期 / 附件 | 字段设计器可选类型（`FIELD_TYPES`） |
| 标签，示例 | 规格 / consumable / asset / license | 内置 Class 的业务标签示例 |

### 3.2 页面功能与交互逻辑

#### 3.2.1 列表页（`/asset/settings/class`）

- **列表列**：名称（可点击进详情）、类别编码、表名、是否内置（标签）、Class类型（标签）、标签、操作（删除）。
- **搜索**：按 名称 / 类别编码 / 表名（`名称 / classCode / tableName`）。
- **删除保护**：内置 Class 删除按钮禁用（`disabled={r.builtIn}`）。

#### 3.2.2 详情/新建页（`/asset/settings/class/:id`）

- **页签**：
  - 表单管理：上部基本信息（名称/类别编码/Class类型 Radio/表名/标签），下部「核心属性 / 表单字段」字段设计器。
  - 表格管理：「显示列设置」字段设计器。
- **字段设计器**：表格化增删字段行；每行可编辑 字段标识/显示名称/字段类型（下拉）/必填（复选）/显示（复选）；底部「+ 添加字段」新增一行（默认「新字段/单行文本/非必填/显示」）。
- **校验**：名称、类别编码、表名必填；类别编码 编辑态禁用不可改。
- **删除保护**：非内置 Class 详情页展示删除按钮；内置 Class 不展示。
- **404 守卫**：访问不存在的 Class ID 展示「未找到该 Class」结果页与「返回 Class管理」入口。

## 4. 验收标准

- Class 列表可搜索，是否内置/Class类型以正确 标签 展示；内置 Class 删除按钮禁用。
- 详情页两个页签（表单管理/表格管理）字段设计器可增删字段行并保存；类别编码 编辑态不可改。
- 名称/类别编码/表名必填校验、404 守卫生效；新建默认 Class类型=table、builtIn=false。
- 各字段与字典值符合本文定义。

## 6. 简化说明（原型范围）

- **字段设计器简化**：真实产品为拖拽式表单/表格设计器（page_289/295），本原型简化为可增删的字段行列表。
- **字段属性精简**：字段行仅含 标识/显示名/类型/必填/显示，未含默认值、校验规则、下拉选项来源等高级属性（以原型为准）。

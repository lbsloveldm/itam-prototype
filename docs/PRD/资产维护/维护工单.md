## 2. 需求分析

### 2.1 业务背景

企业需对资产开展周期性维护（维修、保养、巡检、升级）以预防故障、延长寿命、保障合规。系统通过「维护项」定义标准检查内容，「维护模版」组合维护项并绑定资产范围与物料，「维护计划」按频率自动生成周期性「维护任务」，任务经领取、执行、结果录入形成闭环。维护工单是承载一次具体维护活动的核心单据，串联上述配置与执行。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **标准化**：维护项/模板建立统一检查标准，提升执行规范性与数据准确性。
- **自动化**：维护计划按频率自动生成任务，保障维护及时性与连续性。
- **可追溯**：任务领取、执行、结果与异常全程留痕，支撑健康评估、故障溯源与合规审计。
- **闭环管理**：从计划到执行到结果核验贯通，避免维护流于形式。

#### 2.2.2 调研结论及竞品分析

对标 ServiceNow 的计划维护（Planned Maintenance）：以模板与计划驱动周期任务生成，任务分配至组并跟踪执行。本方案对齐「项→模板→计划→任务」四级结构，并以维护工单承载执行单据。

### 2.3 用户故事

- 作为**资产管理员**，我希望定义维护项与模板并配置计划，以便系统自动生成周期维护任务。
- 作为**维护人员**，我希望在 PC/移动端领取并执行维护任务，逐项记录结果，以便闭环维护。
- 作为**IT 运维**，我希望对突发故障资产直接创建维护工单，以便快速处置。

## 3. 需求设计

### 3.1 维护项

#### 3.1.1 涉及到的表

- `maintenance_item`（维护项主表）
- `maintenance_item_checklist`（检查清单/检查项与量化标准）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 新建维护项 | 定义检查内容与标准 | 进入【资产维护】→【维护项】列表页，点击【新建】，填写维护项名称，在检查清单模块新增检查项及量化标准，点击【保存】 |
| 编辑检查清单 | 可编辑/删除检查项 | 点击维护项进入详情页，在检查清单操作中点击【编辑】完成对检查清单的编辑；支持删除 |
| 适用角色 | 权限 | 系统管理员、资产管理员 |

#### 3.1.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 维护项名称 | VARCHAR | 128 | 维护项显示名称 |
| 检查项 | VARCHAR | 200 | 检查清单中的单条检查内容 |
| 检查类型 | VARCHAR | 32 | 检查维度（外观/功能/状态/合规性等，可自定义） |
| 量化标准 | VARCHAR | 200 | 检查项的量化判定标准 |

### 3.2 维护模版

#### 3.2.1 涉及到的表

- `maintenance_template`（维护模版主表）
- `maintenance_template_item`（模版-维护项关联）
- `maintenance_template_material`（模版-物料关联）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |

| 关联维护项 | 维护项信息页卡 | 在维护模版的【维护项信息】页卡下，新建关联已有维护项并保存 |
| 关联物料 | 物料信息页卡 | 在【物料信息】页卡新建关联物料，填写规格及所需数量并保存 |
| 前提条件 | 数据完备 | 已完成维护项标准化定义；已完成物料信息基础管理（备件/耗材台账完整） |

#### 3.2.3 字段说明

### 3.4 维护任务

#### 3.4.1 涉及到的表

- `maintenance_task`（维护任务主表）
- `maintenance_task_result`（任务-维护项执行结果）

#### 3.4.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 任务自动生成 | 计划触发 | 维护计划首个任务生成时间到达后，系统按计划自动生成维护任务 |
| 任务领取 | PC/移动端领取 | PC 端可查看已生成任务；移动端 App 登录后可领取；列表页【领取】或详情页【领取任务】完成领取，进入【进行中】页卡 |
| 任务执行 | 逐项维护 | 在【进行中】页卡选择任务，详情页点【去维护】，逐项执行维护项并保存；【仅看异常】页卡查看异常维护项并支持重新维护；全部完成后点【提交】完成执行 |
| 更换待维护资产 | 备件替换 | 执行时支持更换待维护资产：主资产关联子资产故障时可快速替换为完好备件，保障主资产稳定运行 |
| 查看结果 | 结果查询 | 系统管理员、资产管理员、维护人员均可在 PC 端查看结果；进入【维护任务】点击已完成的维护单号进入详情，查看【维护项】及执行结果 |
| 适用角色 | 权限 | 系统管理员、资产管理员、维护人员（属于维护组）；维护组内成员获得执行对应任务的权限 |

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 任务页卡 | 进行中 / 仅看异常 / 已完成 | 任务状态分组页卡 |
| 维护项执行结果 | 正常 / 异常 | 单项维护结果；异常项支持重新维护 |

### 3.5 维护工单（原型单据）

> 说明：原型将资产维护落地为「维护工单」单据（`/maintenance/order`）。工单承载对某资产的一次维护活动，字段与字典如下。

#### 3.5.1 涉及到的表

- `maintenance_order`（维护工单主表）
- `asset`（资产主表，引用）

#### 3.5.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 新建维护工单 | 创建单据 | 列表页点击新建进入表单，填写工单号、资产、维护类型、负责人、状态、描述，保存后回列表 |
| 编辑维护工单 | 修改单据 | 详情页可编辑并保存 |
| 删除维护工单 | 删除单据 | 详情页可删除 |
| 状态流转 | 生命周期 | 状态在待处理→处理中→已完成→已关闭之间流转 |
| 深链守卫 | 404 | 访问不存在的工单 ID 时展示 404 结果页与「返回维护工单列表」入口 |

#### 3.5.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 工单号 | VARCHAR | 50 | 维护工单唯一编号（必填），如 WX-2026-0001 |
| 资产 | VARCHAR | 100 | 关联的资产（必填） |
| 维护类型 | VARCHAR | 8 | 维修/保养/巡检/升级（必填） |
| 负责人 | VARCHAR | 50 | 工单负责人（必填） |
| 状态 | VARCHAR | 8 | 待处理/处理中/已完成/已关闭（必填） |
| 描述 | VARCHAR | 500 | 维护内容描述 |
| 创建人 | VARCHAR | 64 | 工单创建人 |
| 创建时间 | TIMESTAMP | - | 工单创建时间 |

#### 3.5.4 字段字典值说明（状态机）

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 维护类型 | 维修 | 故障维修（如更换风扇模块） |
| 维护类型 | 保养 | 定期保养（如清洁、电池健康检查） |
| 维护类型 | 巡检 | 例行巡检（如耗材巡检） |
| 维护类型 | 升级 | 硬件/配置升级（如内存扩容） |
| 状态 | 待处理 | 工单已创建，尚未处理（默认状态） |
| 状态 | 处理中 | 维护进行中 |
| 状态 | 已完成 | 维护执行完成 |
| 状态 | 已关闭 | 工单闭环关闭 |

### 3.6 页面功能与交互逻辑

#### 3.6.1 列表页（维护工单）

- 展示全部维护工单，列：工单号、资产、维护类型、负责人、状态、创建时间。
- 操作：新建、编辑、删除；支持搜索/筛选。

#### 3.6.2 详情/新建页

- 表单分区展示工单号、资产、维护类型、负责人、状态、描述，默认「维护类型=维修、状态=待处理」。
- 保存做必填校验；深链 404 守卫生效。

### 3.7 与其他模块联动

| 联动模块 | 说明 |
| --- | --- |
| 资产台账 | 工单关联资产；资产关联页卡【关联任务】展示盘点、维护任务，【关联工单】展示关联工单，点击工单编号查看详情 |
| 成本管理 | 维护任务执行产生费用条目，按人工/任务费率卡计费并挂到对应资产 |
| 库存管理 | 维护所需物料（备件/耗材）从库房领用，执行时可替换备件 |
| AI 能力 | 支持一句话生成维护任务（匹配/创建维护项、模板、计划并生成任务） |

### 3.8 日志审计

维护项/模板/计划/任务/工单的新增、编辑、删除、状态流转按统一日志规范记录，格式示例：【操作人】于【时间】对模块【资产维护/维护工单】执行了【操作】操作，操作内容为【工单号】，操作结果为【成功/失败】。

## 4. 验收标准

- 维护项可新建并编辑检查清单（检查项+量化标准）；维护模版可关联维护项与物料；维护计划可配置频率并关联模版自动生成任务。
- 维护任务支持 PC/移动端领取、逐项执行、异常重维、提交完成与结果查看；支持执行中更换待维护资产（备件替换）。
- 维护工单可完成创建、编辑、删除全流程，字段与字典（维护类型、状态机）符合本文定义。
- 工单状态在待处理→处理中→已完成→已关闭之间正确流转；深链 404 守卫生效。
- 与资产台账（关联任务/关联工单）、成本、库存、AI 能力的联动符合定义。

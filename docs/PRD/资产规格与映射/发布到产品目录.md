## 2. 需求分析

### 2.1 业务背景

ITAM 中涉及的采购、领用、分配资产等流程按现有沟通方案需通过 DOSM 实现。因此需要将资产规格数据发布至 DOSM 的服务目录形成服务项，以便在发起资产领用/调拨/采购等流程时选中资产规格。发布到目录可增强规格可见性、支撑自助服务与流程自动化、便于合规审计与资源优化。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **流程打通**：规格发布为 DOSM 服务项，支撑领用/调拨/采购选品。
- **增强可见性**：提升规格在组织内可发现性，支撑自助服务。
- **流程自动化**：服务项可触发审批/采购/部署工作流。
- **合规与优化**：目录集中管理便于审计与资源分配优化。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow「Publish to Catalog」：将 Product 规格 发布到 Service Catalog 形成 Catalog Item，供请求流程选用。本方案将 ITAM 规格通过接口同步至 DOSM 提供的表与服务目录，目录路径可固定。

### 2.3 用户故事

- 作为**规格管理员（model_manager）**，我希望将资产规格一键发布到 DOSM 服务目录，以便领用/采购流程可直接选中该规格。

### 3.3 将规格发布到 DOSM 服务目录（Publish to catalog）

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 发布入口 | 各类型规格详情页显示入口 | 入口：硬件/耗材/软件/Bundled models 列表页点名称进详情页 → 各类型路径相同 |
| 发布弹窗 | 当前页弹窗确认 | 标题格式「Publish "名称" to Catalog」；规格 字段取进入规格的 名称，不可改；分类 为 DOSM 提供的服务目录名 |
| 发布执行 | 点 OK 同步 | 点「OK」后规格发布成功，系统执行两件事：a. 将 规格 同步字段写入 DOSM 提供的表；b. 将 规格 的 名称 写入 DOSM 提供的服务目录 |
| 规格 id 唯一 | 唯一性校验 | 同步时 规格 id 需做唯一性校验，不可重复 |
| 资产 Class 获取 | 计算 asset class | 通过 规格 所属 规格 category 找到 asset class 一并同步 |

#### 3.3.2 字段说明（规格 同步字段）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 规格 id | VARCHAR | 32 | 规格唯一标识，需唯一性校验，不可重复 |
| 名称 | VARCHAR | 40 | 规格名称 |
| 制造商 | VARCHAR | 32 | 生产厂商 |
| 成本 | DECIMAL | 20,2 | 规格费用 |
| 资产 Class | VARCHAR | 40 | 通过 规格 所属 规格 category 找到 asset class |

#### 3.3.3 发布弹窗字段

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 规格 | VARCHAR | 40 | 取进入规格的 名称，不可修改 |
| 分类 | VARCHAR | 32 | DOSM 提供的服务目录名 |

### 3.4 页面功能与交互逻辑

- **入口**：规格详情页 Publish to Catalog 操作项（硬件/消耗品/软件/捆绑路径一致）。
- **弹窗**：标题「Publish "名称" to Catalog」，展示 只读与 分类；点 OK 发布、取消关闭。
- **结果**：发布成功后同步字段写入 DOSM 表、规格 名称 写入 DOSM 服务目录。

> 备注：DOSM 提供的表与服务目录后续由 DOSM 确定后提供，接口方式同步。

## 4. 验收标准

- 各类型规格详情页均有 Publish to Catalog 入口，弹窗标题与 规格 只读字段正确。
- 点 OK 后同步字段（规格 id/名称/制造商/成本/资产 Class）写入 DOSM 表，规格 名称 写入服务目录。
- 规格 id 唯一性校验生效；资产 Class 通过 规格 category 正确计算。

## 2. 需求分析

### 2.1 业务背景

资产与配置项之间的关系管理很重要：资产通过 ITAM 跟踪（侧重财务），配置项存储在 侧重可用性与依赖。二者建立映射可实现同步更新、支撑变更管理、事故/问题根因分析、合规审计、维护支持与资源优化，并借助自动化发现工具防止数据过时。映射分为**字段映射（字段映射）**与**状态映射（状态映射）**。

此外，软件台账规格与软件发现（自动采集）规格之间原需人工手动配置映射，工作量大。需通过自动化（强规则直接匹配 + 模糊匹配人工确认）降低人工工作量。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **数据一致**：资产与 CI 记录同步更新，保证准确性与完整性。
- **变更与风险**：了解资产-CI 关系，评估变更影响、加速根因分析。
- **合规审计**：追踪资产使用与配置历史，支撑合规检查。
- **降本增效**：软件发现自动映射减少人工配置工作量。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 资产与 CI 关系管理：字段一对一映射保持同步；状态映射为非一对一（资产 state/substate 对应 CI stage/status）；变更由发起方推送/消费同步。本方案对齐：ITAM 变更调用 CMDB 接口推送；CMDB 变更经 kafka 发消息，ITAM 消费轮询同步（部分后续实现）。

### 2.3 用户故事

- 作为**资产管理员（asset）/管理员（admin）**，我希望配置资产字段与 CMDB CI 字段的映射，以便二者数据实时同步一致。
- 作为**资产管理员**，我希望配置资产状态与 CI stage/status 的映射并设优先级，以便状态跨系统一致流转。
- 作为**资产管理员**，我希望软件发现规格与台账规格自动映射，仅对无法自动匹配的进行人工确认，以便降低映射工作量。

## 3. 需求设计

### 3.1 角色与权限

| 角色 | 权限说明 |
| --- | --- |
| admin | 创建/编辑/删除 Field/状态映射 |
| asset | 创建/编辑/删除 Field/状态映射 |
| 资产管理员 | 软件发现规格映射（仅限资产管理员） |

### 3.2 字段映射（字段映射）

#### 3.2.1 涉及到的表

- ITAM 资产表（硬件）、CMDB CI class 属性（由 CMDB 提供接口）、映射关系表

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 映射入口 | Setting 中 资产&CI Mapping | 点名称默认进 字段映射 列表页，显示已创建映射 |
| 列表展示 | 已有数量+字段 | 显示 资产 field、配置项 field、是/否 是否生效 |
| 新增映射 | 一对一映射 | 点 New 进创建页；目前仅做硬件映射；一对一 |
| ITAM→CMDB 同步 | 实时同步 | ITAM 字段变更时调用 CMDB 提供的接口同步给 实时 |
| CMDB→ITAM 同步 | 后续实现 | CMDB 变更经 kafka 发消息，ITAM 消费轮询查询同步（后续实现，1 月后 CMDB 完全提供） |
| 特别映射-Acquisition | 字典值映射 | 获取方式 字典值映射 CMDB 为 device source |
| 特别映射-Depreciation | 单向映射 | Depreciation 字典值映射 CMDB 为 Depreciation 类型 & Depreciation Cycle；折旧只能单向从 ITAM 映射到 CMDB |

#### 3.2.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 规格分类 | VARCHAR | 32 | 必填，ITAM 与硬件有关的 规格 category 列表（当前 CMDB 仅支持硬件） |
| 启用 | BOOLEAN | - | 勾选为 True 否则 False，指该映射是否生效 |
| 资产 field | VARCHAR | 40 | 必填，下拉+搜索，显示 hardware 除 state/substate 外的所有属性字段 |
| 配置项 field | VARCHAR | 40 | 必填，显示 CMDB 中与该 category 关联 CI class 的所有属性（CMDB 接口提供） |
| 同步 direction | VARCHAR | 40 | 下拉：Both / 资产 to configuration item / 配置项 to asset，默认 Both |

#### 3.2.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 启用 | 是 / 否 | 映射是否生效 |
| 同步 direction | Both | 双向同步（默认） |
| 同步 direction | 资产 to configuration item | 仅资产→CI |
| 同步 direction | 配置项 to asset | 仅 CI→资产 |
| 映射 | → device source | 字典值映射 CMDB 的 device source |
| 映射 | → Depreciation 类型 & Depreciation Cycle | 单向 ITAM→CMDB |

> 接口说明：CMDB 提供接口为「表单视图数据字段 + 5 个系统默认字段（创建人、创建时间、修改人、修改时间、ci_id）」，ci_id 为 CI 唯一标识。

### 3.3 状态映射（状态映射）

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 映射入口 | Setting 中 资产&CI Mapping | 点名称进 状态映射 列表页，显示已创建映射 |
| 列表展示 | 已有数量+字段 | 资产 status、资产 substate、配置项 Stage、配置项 状态、同步 direction、启用 |
| 新增映射 | 非一对一映射 | 点 New 进创建页；目前仅做硬件映射；资产状态与 CI 状态非一对一（如「库存-待处置」对应 CI「处置中」无子状态） |
| Operating status 分支 | 状态来源分支 | 若 CI 状态 名称 选 Operating status，显示 CMDB 字典值下拉；否则显示 CMDB status 属性（引用，与 stage 关联） |
| ITAM→CMDB 同步 | 双向/单向 | 选 Both 或 资产 to configuration item 时，ITAM 字段变更调 CMDB 接口同步 |
| CMDB→ITAM 同步 | 本期暂不实现 | 选 配置项 to asset 时，ITAM 轮询 CMDB 消息通知同步（本期暂不实现） |
| 优先级 排序 | 冲突排序 | CMDB 同步至 ITAM 时若多字段映射，按 排序 升序取最小生效；排序 相同取同步字段排序第一位 |
| 一对多写值 | 业务规则写死 | CI→ITAM 存在一对多写值，后续业务规则写死（如 CMDB「处置中」写 ITAM「库存-待处置」，不可写「库存-***」其他） |

#### 3.3.2 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 启用 | BOOLEAN | - | 勾选为 True 否则 False，指该映射是否生效 |
| 资产 state | VARCHAR | 40 | 下拉+搜索，显示硬件 state 字段所有值 |
| 资产 substate | VARCHAR | 40 | 下拉+搜索，显示硬件 substate 值，与所选 state 关联 |
| 配置项 Stage 名称 | VARCHAR | 40 | CMDB stage 名称（CMDB 接口提供） |
| 配置项 Stage | VARCHAR | 40 | CMDB stage 属性（CMDB 接口提供） |
| 配置项 状态 名称 | VARCHAR | 40 | CMDB status 名称（引用，CMDB 提供）；另含 Operating status 选项（CMDB 运行状态） |
| 配置项 状态 | VARCHAR | 40 | 未选 Operating status 时显示 CMDB status 属性（引用，与 stage 关联） |
| 值 | VARCHAR | 40 | 选 Operating status 时显示，下拉展示 CMDB 字典值 |
| 同步 direction | VARCHAR | 40 | Both / 资产 to configuration item / 配置项 to asset |
| 排序 | INTEGER | - | 整型默认 1，CMDB→ITAM 同步优先级，越小优先级越高 |

#### 3.3.3 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 启用 | 是 / 否 | 映射是否生效 |
| 同步 direction | Both | 双向同步 |
| 同步 direction | 资产 to configuration item | 仅资产→CI |
| 同步 direction | 配置项 to asset | 仅 CI→资产（本期暂不实现同步） |
| 配置项 状态 名称 | Operating status | 选择后按 CMDB 运行状态字典值（值）映射 |

### 3.4 软件发现规格与台账规格映射

> 角色：仅限资产管理员。软件规格名称必须配置为唯一。设计思路：A. 完全匹配（强规则直接匹配并写入最终映射表）；B. 模糊匹配（人工确认后写入）。

#### 3.4.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| ISO 序列号直接匹配 | 强规则 | 软件发现采集 iso_serial_number 与台账规格「ISO 序列号」相同时，系统自动在「软件资产发现映射」表创建映射记录（发现规格取采集 software_model_id，台账规格取该 ISO 对应规格全称） |
| 规格全名匹配 A | 强规则 | ITAM 规格名称匹配采集 software_model_id，不区分大小写、除空格外相同即匹配成功，自动插入映射 |
| 规格全名匹配 B | 强规则 | A 未匹配时，按（ITAM 规格名称+版本号）匹配 software_model_id，除空格外相同即匹配（不区分大小写） |
| 制造商映射匹配 C | 强规则 | 若制造商有映射（采集 publisher_id 与 ITAM 制造商已建映射），用映射值匹配（交付初始化时做） |
| 人工映射 | 模糊匹配 | 自动映射未成功的采集数据展示在「待处理映射」，人工可映射或点「不处理」 |
| 不处理 | 人工操作 | 点不处理弹窗提示后续无需再处理；数据转入「无需处理软件规格」列表 |
| 无需处理回撤 | 后悔机会 | 无需处理列表仍可点发现软件规格手动映射，映射后转入「软件资产发现映射」列表 |
| 待处理完成 | 状态流转 | 待处理映射完成映射后进入「软件资产发现映射」，不再展示在待处理 |
| 映射数据流 | 每日采集 | 每天采集到的规格给到 ITAM 进行处理 |

#### 3.4.2 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 发现软件规格 | VARCHAR | 100 | 采集 software_model_display_name+版本 组合 |
| 台账规格（规格全称） | VARCHAR | 100 | ITAM 台账规格全名，人工命名（发布商+产品名称+版本号） |
| iso_serial_number / ISO 序列号 | VARCHAR | 40 | 软件全球唯一激活代码，用于强规则直接匹配 |
| 版本号 | VARCHAR | 40 | 软件版本，参与全名匹配 B |
| publisher_id | VARCHAR | 32 | 采集制造商标识，参与制造商映射匹配 C |
| 发现软件制造商 | VARCHAR | 40 | 采集 名称，与 ITAM 制造商建立映射（全称字段值） |

#### 3.4.3 字段字典值说明（映射处理状态）

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 匹配方式 | 完全匹配 | 强规则符合，直接写入最终映射表 |
| 匹配方式 | 模糊匹配 | 部分匹配，需人工确认后写入 |
| 处理状态 | 待处理映射 | 自动映射未成功，待人工处理 |
| 处理状态 | 已映射（软件资产发现映射） | 已完成映射 |
| 处理状态 | 无需处理软件规格 | 人工点「不处理」后归入 |

### 3.5 页面功能与交互逻辑

#### 3.5.1 Field / 状态映射 列表页

- **入口**：Setting → 资产&CI Mapping 目录，分别进入 字段映射、状态映射 列表页。
- **列表**：显示已有数量与关键字段（含 启用）；点 New 进创建页。
- **约束**：目前仅做硬件映射；Field 为一对一，状态 为非一对一。

#### 3.5.2 软件发现映射页

- **三列表**：待处理映射、软件资产发现映射（已映射）、无需处理软件规格。
- **操作**：点发现软件规格进新建映射页；待处理支持「不处理」，无需处理不含「不处理」但可继续手动映射。

## 4. 验收标准

- 字段映射 可创建一对一映射，资产 field 排除 state/substate，ITAM 变更实时同步 CMDB；Acquisition/Depreciation 特别映射规则生效（Depreciation 单向）。
- 状态映射 支持非一对一映射，Operating status 分支展示 值；排序 优先级排序生效；一对多写值按业务规则。
- 同步 direction 三值可选，默认 Both；启用 控制映射生效。
- 软件发现映射：ISO 序列号/规格全名 A/B/制造商映射 C 四类强规则自动匹配并写入映射表；未匹配进入待处理，可人工映射或不处理，状态流转正确。

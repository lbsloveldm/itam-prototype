## 2. 需求分析

### 2.1 业务背景

规格分类（规格分类）的核心目的是**把资产类别（资产 class）和 CI 类别（CI class）关联起来**。三者关系为：资产分类，固定枚举→ 规格归属类别，如 Computer→ 具体规格，如 MacBook Pro 15。规格必须挂在 category 下，category 决定其下资产的 asset class，并通过关联 CI class 打通与 CMDB 的对接。因此规格类别是规格与资产管理的组织基础。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **组织基础**：为规格与资产提供统一分类目录，规范资产归类。
- **CMDB 打通**：category 关联 CI class，是字段/状态映射的前提。
- **层级化管理**：支持父子 category，构建多级分类体系。
- **标准化编码**：UNSPSC code 支撑标准化产品服务分类。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow `cmdb_model_category`：category 定义 asset class 与关联 CI class，允许多个 CI class 对应一个 asset class；category 支持父子层级与 UNSPSC 编码。本方案对齐该模型，CI class 取自 CMDB 数据，允许多 CI class 映射到一个 asset class。

### 2.3 用户故事

- 作为**规格管理员（model_manager）**，我希望创建规格类别并关联 asset class 与 CI class，以便规格与资产有统一归类且能对接 CMDB。
- 作为**资产管理员**，我希望通过父子 category 组织分类层级，以便按类别检索与管理规格。

### 3.3 创建规格类别（Create 规格分类）

> 说明：暂不做自动生成资产功能，需在已生成的 规格 category 中添加资产。

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建 规格分类 | 为资产管理创建目录，将资产挂在 category 下 | 入口：列表页右侧「New」；填写字段点「提交」新增成功回列表页，最新记录置顶（按创建时间逆序）；点「取消」不新增 |
| 名称唯一 | 名称 保持唯一 | 名称不可重复 |
| 父子层级 | 父级 category | 下拉，所有已有 规格 category 均可作为父级 |
| CI class 关联 | 关联 CMDB class | 支持下拉及模糊搜索，选项取 CMDB 数据；允许多个 CI class 对应一个 asset class |
| 资产 class | 资产分类 | 下拉，默认 None，枚举见字典 |
| 列表搜索 | 组合模糊搜索 | 按 名称、CI class、资产 class、父级 category 单条件或组合搜索；回车触发；空结果不显示数据；筛选条件展示在漏斗中且统计正确 |
| 列表操作 | 复选与列设置 | 复选支持批量删除（More→删除）；列表展示字段可通过列设置 |
| 页签 异常处理 | 最多 10 个 tab | 超过提示：标题「Max 页签 Reached」，内容「You have reached maximum tabs, please close some tabs if you want open a new one.」 |

#### 3.3.2 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 名称 | VARCHAR | 40 | 名称，保持唯一，不可重复 |
| 父级 category | VARCHAR | 32 | 父级类别，下拉选所有已有 规格 category |
| UNSPSC code | VARCHAR | 40 | 联合国标准产品与服务分类代码，暂仅做输入（生成规则后定） |
| CI class | VARCHAR | 32 | 实物分类，下拉+模糊搜索，取 CMDB 数据，允许多 CI class 对应一个 asset class |
| 资产 class | VARCHAR | 40 | 资产分类，下拉，默认 None |

#### 3.5.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 删除 | 删除未被使用的 category | 没有在任何地方被使用过的 category 才可删除，否则不能删除 |
| 删除结果 | 目录移除 | 删除后 category 不再存在，曾挂在其下的 asset class 及 asset 全部从该目录路径移走 |
| 二次确认 | 删除需确认 | 标题「Confirmation」，内容「Are you sure you want to delete this record?」 |

### 3.6 页面功能与交互逻辑

#### 3.6.1 列表页

- **默认列**：名称、父级 category、UNSPSC code、CI class、资产 class；新增记录置顶（创建时间逆序）。
- **搜索**：名称、CI class、资产 class、父级 category 组合模糊搜索，空结果不显示数据。
- **操作**：New、复选批量删除（二次确认）、列设置。
- **页签 限制**：最多 10 个 tab，超出提示「Max 页签 Reached」。

#### 3.6.2 详情页

- 点 名称 进入，展示全部字段当前值；未实例化时可编辑/删除。
- 合同 category 不可修改；被使用的 category 不可删除。

## 4. 验收标准

- 规格类别可完成创建、编辑、删除，字段与字典值符合本文定义，名称 唯一校验生效。
- 父级 category 可选所有已有类别；CI class 取 CMDB 数据且允许多对一 asset class。
- 未实例化/未被使用的 category 才可编辑/删除；合同 category 不可修改。
- 删除有二次确认；删除后其下 asset class 与 asset 从目录移走。
- 列表搜索组合生效、空结果不显示、页签 超 10 提示。

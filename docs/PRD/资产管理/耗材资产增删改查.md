## 2. 需求分析

### 2.1 业务背景

当企业建立了规格模型（规格）之后，需要对与规格对应的实物耗材进行创建与管理。耗材资产通常是指那些在一次使用后价值会完全消耗的资产，如墨盒、碳粉盒、打印纸、网线等。与硬件资产不同，耗材资产以 **数量** 为核心管理对象，不需要为每个耗材单独创建 CMDB CI，支持通过消费（Consume）将耗材分配给硬件或用户并递减数量，支持处置（处置）与分割（Split）等操作。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **资产价值跟踪**：跟踪耗材生命周期流转对企业财务管理的影响，围绕财务价值管理诉求，联动合同、费用/成本、厂商/组织、运营管理。
- **透明度提升**：建立耗材可见性，遏制未知资产扩散，解决费用分配问题。
- **成本控制**：控制资本支出与运营支出，提升已有耗材利用率，提供库存监督。
- **风险缓解**：减少重复采购，最小化风险，支持合规，快速定位耗材、跟踪转移、明确责任人。
- **流程优化**：在规划、获取、接收、替换、转移、退役、处置各环节提升效率、减少错误。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow HAM 消耗品资产管理：`alm_consumable` 为 `alm_asset` 的扩展表；耗材以数量管理，支持 消费到设备或用户、分割、标记处置；列表页支持树形分类与多字段筛选，预留 Overview、资产 tasks 页签。

### 2.3 用户故事

- 作为**资产管理员**，我希望通过选择 category 与 规格 快速创建耗材并录入数量，以便高效建立耗材台账。
- 作为**IT 运维**，我希望将耗材消费给某台硬件或某个用户并自动递减库存，以便准确掌握耗材消耗情况。
- 作为**库管**，我希望对库房中可用耗材进行分割，以便按实际需求拆分数量并分别管理。
- 作为**财务人员**，我希望耗材记录完整承载采购、成本、折旧信息，以便进行资产价值核算。

## 3. 需求设计

### 3.1 资产实例化模块

在系统中创建耗材资产的目的，是实现对企业耗材全面、系统、科学的管理。通过创建耗材记录，可存储序列化设备/消耗品的详细信息，并捕捉复杂关系、保修、服务合同与租赁条款。耗材资产表 `alm_consumable` 是 `asset` 表的扩展表，其字段比 asset 更多，但在页面功能字段上展示较少。

### 3.2 创建耗材资产

#### 3.2.1 涉及到的表

- `alm_consumable`（耗材资产表，`asset` 扩展表）
- `规格`（规格模型表，引用；category=耗材）
- `location` / `department` / `company` / `vendor` / `cost_center`（组织与位置引用表）
- `stockroom`（库房表，含 货架 / 货位）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建耗材资产 | 对资产进行创建，关注数量（数量） | 不需要为耗材创建对应 CI；通过选定 category 及 规格 来创建；提交后在耗材列表页可见，资产数量 +1；同时在 耗材 规格 对应的 Consumables 二级 页签 下可查看且数量 +1 |
| 资产标识 生成 | 系统按规则生成资产唯一编码 | 耗材资产 `C+9位数字`，全局唯一，详见《资产标识配置规则》 |
| 状态驱动字段联动 | 新增页字段随 状态 变化 | 新增资产页面字段并不固定，若干字段随 状态 值变化显示/隐藏（详见 3.2.5） |
| 创建成功关联展示 | 创建成功后详情页展示关联 页签 | 详情页关联显示 数据为空，计算逻辑后续补充 |
| 修改耗材资产 | 对填错或未填字段进行修改 | 已有资产数量未被全部使用时可修改；不可修改字段：名称、规格分类、规格；修改成功后列表页字段值正确显示 |
| 删除耗材资产 | 删除单条或批量删除 | 入口1：列表页点击具体资产进入修改页，提交 右侧提供 删除；入口2：列表页勾选多条，在 More 操作中选择 删除 批量删除；删除二次确认（标题 Confirmation，内容 "Are you sure you want to delete this record？"），删除成功后列表页不再展示且数量 -1 |

#### 3.2.5 新增页字段的 状态 联动规则

- **通用**：显示 库房 字段时，同时显示 货架 & 树形结构下拉框，展示已有货架、货位列表值，以下不再重复描述。
- **已下单**：新增页字段见对应截图（预留字段，无 库房）。
- **在库、Build**：显示 库房 字段；选择 库房 后，位置 由系统取 库房 的 位置 值自动填充，不可修改。
- **在途**：新增页字段与 已下单 相同。
- **已消耗、维护中、已退役、丢失**：显示 分配给 字段。

#### 3.2.6 新增页字段说明（交互）

- **规格分类**：必填，下拉框，默认为 耗材；支持模糊搜索，展示已有 category 供选择。
- **规格**：必填，下拉框，支持模糊搜索，关联显示所选 规格分类 下已有的所有 规格 display 名称 供选择。
- **子状态**：与 状态 关联，除数据字典显示值外，增加 "None" 选项。
- **位置**：下拉框，选项为合同功能部分创建的所有位置列表，显示位置名称。
- **父级**：父级资产，显示当前已有的所有耗材资产（业务用途待明确）。
- **成本中心**：取维护好的费用中心列表，显示 名称 名称供筛选。
- **获取方式、支出类型**：下拉框，可选项除数据字典外增加 "None"。
- **受益人**：取维护好的个人/中心/组织列表，显示 名称 供筛选。
- **数量**：数量，代表耗材数量，正整数。

### 3.3 消费耗材资产（Consume）

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 消费耗材 | 通过关联耗材与硬件资产/用户来完成消费 | 资产 状态 必须为 在库、子状态 必须为 可用 才可被消费；消费时 数量 为必填项 |
| 消费入口 | 详情页发起消费 | 通过选择具体耗材进入详情页，右上方显示 "Consume" 按钮，点击进入消费弹窗 |
| 消费校验（数量） | 校验消费数量 M 与剩余 数量（N） | M ≤ N 时消费成功，详情页 数量 显示为 N-M；M > N 时消费失败，点击 OK 在当前页给出提示 |
| 资产/用户 互斥 | 消费时 资产、用户 只能二选一 | 选择其中一个时，另一个不可选 |
| 消费结果 | 生成已消费资产实例记录 | 消费成功后生成一条 状态=已消耗 的资产实例记录，可在列表页查看；分配给 取值规则见下 |
| 分配给 取值 | 已消费记录责任归属 | 仅填 用户 时 分配给 取 用户；只要 资产 有值，分配给 取 资产 的 分配给 值 |
| 全量消费 | 消费数量=剩余数量 | 若消费数量与剩余数量相同，则将当前实体状态改为 已消耗，不再生成新实体 |

#### 3.3.2 消费弹窗字段说明

- **标题**：固定文字 `Consume：` + 名称(consume assets)。
- **库房**：默认显示该耗材创建时选择的库房名称（显示 名称 字段值）。
- **资产**：下拉选择，展示所有已有硬件资产，显示对应 display 名称，支持模糊搜索。
- **用户**：下拉选择，支持模糊搜索，显示用户 名称。
- **数量**：消费数量，必填。
- **提交**：点击 "OK" 提交。

> 举例：原耗材总数 20，消费 5 条 → 剩余 15；新增 状态=已消耗、子状态 为空的实体记录，其 分配给 显示所指派 资产 的 分配给 属性值。若消费数量=剩余数量，则原实体改为 已消耗，不再生成新实体。

### 3.4 处置耗材资产（处置）

#### 3.4.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 处置耗材 | 对耗材进行处置，处置后不能再被消费 | 当耗材 数量 不为 0 时，可进行处置 |
| 处置入口 | 详情页发起处置 | 通过选择固定耗材进入详情页，点击 "Mark for disposal" 按钮进入处置弹窗 |
| 处置校验（数量） | 校验处置数量 A 与剩余可用数量 B | A < B 处置成功，剩余可授权数量为 B-A 填入 数量；若剩余可消费数量为 0，则 子状态=待处理 disposal。A=B 处置成功，剩余为 0，数量=A，子状态=待处理 disposal。A>B 处置失败，点击 OK 在当前页给出提示 |
| 取消处置 | 取消处置后可被重新使用 | 可对 子状态=待处理 disposal 的资产取消处置；入口：详情页右上方 "取消 for disposal"；取消成功后可继续被消费 |
| 取消处置弹窗 | 取消处置的默认值 | 弹窗默认显示 库房、与详情页相同；子状态 默认 可用，可选其它状态；点击 OK 后取消处置成功，数量 与详情页完全相同 |

#### 3.4.2 处置弹窗字段说明

- **标题**：固定文字 `Mark for disposal：` + 名称(consume assets)。
- **数量**：要处置的资产数量。
- **提交**：点击 "OK" 提交。

### 3.5 分割耗材资产（Split）

> 来源：《Split 耗材资产》。Split 涉及两种资产：耗材 asset、Pre-allocated asset。本节聚焦耗材分割。

#### 3.5.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| Split 耗材 Assets | 对处于库房中的可用耗材进行分割 | 分割条件：a. 耗材数量>1；b. 状态=在库；c. 子状态=可用 |
| Split 入口 | 详情页发起分割 | 详情页显示 "Split" 按钮；当被分配资产数量为 1 时，详情页不显示 Split 按钮 |
| 分割弹窗与校验 | 填写分割数量并生成新记录 | 点击 Split 后弹出页面，填写分割数量（数量 < 被拆分对象数量）；状态 默认 In Stock 且不可修改；子状态 可选值与创建耗材 在库 时的 子状态 选项列表相同；资产用途 见下 |
| 分割结果 | 生成新耗材记录并更新原记录 | 点击 OK 分割成功，生成一条新耗材记录；新记录分割字段以用户输入为准，其余字段与原耗材保持一致；原资产数量对应减少 |
| 成本 更新 | 被分割/新生成资产成本重算 | 被分割资产、新生成资产的 成本 需更新，计算方式为：（被分割资产原 cost / quantity）× 新 quantity |

#### 3.5.2 分割相关字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 数量 | INTEGER | - | 分割数量，必须小于被拆分对象数量 |
| 状态 | VARCHAR | 40 | 默认 In Stock 且不可修改 |
| 子状态 | VARCHAR | 40 | 可选值与创建耗材 在库 时 子状态 选项列表相同 |
| 资产用途 | VARCHAR | 40 | 表示资产的具体功能或用途 |

#### 3.5.3 资产用途 字典值

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 资产用途 | 共享 | 共享使用 |
| 资产用途 | 主要 | 主要功能 |
| 资产用途 | Loaner | 借用 |
| 资产用途 | 次要 | 次要/备用功能 |
| 资产用途 | None | 无 |

## 4. 验收标准

- 耗材资产可完成创建、查看、编辑、删除全流程，字段与字典值符合本文定义；不可修改字段（名称、规格分类、规格）生效。
- 资产标识 唯一且符合 `C+9位数字` 规则；状态机切换符合约束。
- 新增页字段随 状态（已下单/在库/在途/已消耗/维护中/已退役/丢失/Build）正确联动。
- 消费功能：在库+可用 才可消费；数量 校验（M≤N 成功、M>N 失败）；资产/用户 互斥；生成 已消耗 实例记录且 分配给 取值正确；全量消费不生成新实体。
- 处置功能：A<B / A=B / A>B 三类校验正确；剩余为 0 时 子状态=待处理 disposal；取消处置后可继续消费。
- 分割功能：仅数量>1 且 在库+可用 显示 Split；新记录生成正确；成本 按 `(原cost/quantity)*新quantity` 重算。
- 耗材消费给硬件后，在硬件资产的 资产 关联页卡可见，且 父级 指定为该硬件。
- 列表左侧类型分类面板计数准确，默认列与筛选可用，导出功能可用。

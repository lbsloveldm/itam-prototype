## 2. 需求分析

### 2.1 业务背景

使用 托盘 资产类将库存中的资产作为一个组进行跟踪和管理。可以轻松地在不同位置之间移动一组资产，也可以将它们作为一个组进行处置。托盘资产与捆绑资产的区别在于：捆绑资产是逻辑上的资产组合（component），而托盘更侧重库房内一组资产的物理归集与整组移动。

用转移单可将库存中的托盘及其中包含的资产从一个库房移动到另一个库房；若仅移动托盘中包含的资产，则任务结束后这些资产将从托盘中删除；也可以使用转移单移动空托盘。作为转移单工作流程的一部分，在托盘上执行的更新适用于其中包含的资产。若收到的全部或部分资产出现问题，可退回托盘及其资产（无法退回托盘中包含的单个资产）。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **整组跟踪**：将库存中一组资产作为单一托盘实体跟踪与管理。
- **高效移动**：通过转移单在库房间整组移动托盘及资产，托盘上的更新自动适用于包含的资产。
- **整组处置**：可将托盘作为一个组进行处置。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 托盘 资产：托盘作为资产组容器，资产添加/删除受状态与父资产约束；资产添加后其状态、子状态、位置、库房与托盘同步（预分配资产子状态除外）；托盘可通过转移单移动。

### 2.3 用户故事

- 作为**库管**，我希望创建托盘规格与托盘资产，以便将库存资产整组管理。
- 作为**库管**，我希望将符合条件的硬件/耗材/捆绑资产添加到托盘并整组移动，以便提升库房作业效率。
- 作为**资产管理员**，我希望在托盘为空时才能删除托盘，以便避免误删仍有资产关联的托盘。

| 字段名 | 字典值 | 说明 |

### 3.3 向托盘添加资产 新增 assets to a pallet

将硬件、捆绑、耗材和其他托盘资产添加到托盘中，以作为一个组跟踪和管理库房中的资产。托盘 资产不能成为 资产 捆绑 的一部分。

> 说明：因捆绑资产没有 parent 字段且 component 状态不可修改，源文档标注暂时不考虑将捆绑资产添加到托盘中；本节忠实记录源文档描述的可添加类型（硬件、捆绑包、消耗品及其他托盘资产）。

#### 3.3.1 被添加资产需满足的条件

| 条件 | 要求 |
| --- | --- |
| A. 资产位置要求 | 资产与托盘属于同一库房，或资产在库存位置字段中没有设置值 |
| B. 托盘状态要求 | 托盘状态字段值为 "在库"，只有托盘处于在库状态才允许关联操作 |
| C. 资产状态要求 | 资产状态字段值可以是 已下单、在库、在途 或 已退役 |
| D. 资产与父资产关联限制 | 该资产没有父资产；若已与某父资产关联，需先解除父子关联再添加到托盘 |
| E. 特殊关联情况（针对父资产） | 作为其他资产父资产的资产被添加时，其所有子资产也会一并添加；但子资产的父字段不会被托盘替代（子资产仍知道原父资产），保留原有结构关系同时与托盘关联 |

#### 3.3.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 新增 Assets to pallet | 为托盘添加资产 | 在托盘关联页卡 Assets 下点击 "新增"；托盘状态不符合时提示 "You can't add asset to the pallet which is not in stock."；点击 新增 后显示可添加资产（满足条件 A & C & D） |
| 添加弹窗 | 显示可添加资产并多选 | 新增 assets 弹窗显示字段：资产、默认当前 pallet 名称且不可修改；资产 支持多选且可设置筛选条件；勾选后点击 "提交" 展示在 资产 中，点击 "保存" 成功添加至托盘。（Moving Pallets 版本弹窗显示字段：名称、序列号、规格分类、状态、子状态、库房，可按字段筛选） |
| 添加后字段变更 | 资产字段与托盘同步 | a. 资产的状态、子状态、位置、库房详细信息与托盘同步（仅预分配资产的子状态不与托盘同步）；b. 资产的 父级 字段设置为该托盘；c. 只将直接与托盘关联的资产 父级 设为该托盘，其下子资产 父级 不变；d. 资产下关联子资产的状态、子状态、位置、库房与托盘同步；e. 托盘的 已预留 for 有值时，以其值更新添加到的资产 已预留 for |
| 托盘 不可入 捆绑 | 限制 | 托盘 不能被添加到 捆绑 中 |

### 3.4 从托盘删除资产 删除 assets

#### 3.4.1 功能描述

| --- | --- | --- |

## 4. 验收标准

- 托盘规格 托盘 规格 可创建，规格分类 默认 托盘 且不可修改，其余字段与 捆绑 规格 一致。
- 托盘资产可创建，资产标识 唯一且符合 `PAL+7位数字`；名称 由 资产标识+规格 生成正确。
- 托盘资产字段随 状态（在库/在途/已退役/丢失）正确联动（已预留 for/库房/位置/分配给）。
- 向托盘添加资产满足条件 位置、托盘 在库、资产状态、无父资产、父资产带子资产；添加后资产状态/子状态/位置/库房与托盘同步、父级 设为托盘、已预留 for 同步。
- 托盘状态不符合时添加提示准确；托盘 不能被添加到 捆绑。
- 从托盘删除资产后 父级 置空、其余字段不变；父资产删除时子资产一并删除；托盘为空才可删除，否则提示。
- 转移单可移动托盘及资产、移动空托盘、仅移动资产（结束后从托盘删除）、退回托盘及资产。

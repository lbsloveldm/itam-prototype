## 2. 需求分析

### 2.1 业务背景

云资产台账管理用于对企业云资源（计算、存储、网络、安全、数据库、应用集群、服务实例、中间件、容器等）进行台账化管理。

**当前现状**：
- **已有采集**：当前公司采集已覆盖上述类别，国内几朵云均已包含，但每朵云中不是所有云资产都有采集；采集侧暂不做所有云资产采集，主要按项目需求完成。
- **新采集任务**：若碰到未覆盖的云资产或云平台，采集侧可通过新任务完成，与云平台接口联调，每个接口约 2 天完成；需客户提供 AK、SK、云资源范围。
- **CMDB**：已有内置模型且分类明确；已知问题为 CMDB 内置模型字段目前与采集侧可匹配的较少，但 CMDB 灵活，可在模型中新增字段并与采集侧关联调整（CMDB 调整可随时发生）。

**ITAM 云资源台账方案（数据流程）**：采集数据给到 CMDB，通过与 CMDB 映射（Mapping）将相应字段同步给 ITAM。ITAM 中定义对象：
- A. 通过创建实例，支持手动录入云资产台账数据。
- B. 资产实例字段本需求给出的仅为默认字段，后续可根据项目实际情况在 Class 中新增或删除。
- C. 通过 规格 category 实现与 CI 的关联；通过 Mapping 实现与 CMDB 的字段映射。
- D. 通过 规格 定义规格。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **统一台账**：将云资源属性信息放在实例中，形成统一的云资产台账视图。
- **灵活扩展**：不同类型实例字段不同，支持随时新增属性字段。
- **数据同步**：通过 CMDB Mapping 自动同步采集数据，减少人工录入。
- **成本可见**：承载 月度成本、供应商、成本中心 等财务信息，支撑云成本管理。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 云资产/CSDM：云资源以 CI 为基础，通过发现（Discovery）采集属性；ITAM 通过 规格 category 与 CI 关联、通过字段映射同步；云资产以实例形式管理，支持手动录入与自动同步。

### 2.3 用户故事

- 作为**云资产管理员**，我希望基于 CMDB 创建云资产 规格 与实例，以便建立云资源台账。
- 作为**云资产管理员**，我希望手动录入或通过 Mapping 自动同步云资产属性，以便灵活管理不同类型云资源。
- 作为**财务人员**，我希望云资产承载月费用、供应商、成本中心信息，以便进行云成本核算。

## 3. 需求设计

### 3.1 云资产类别

云资产包括以下几大类：**计算资源、存储资源、网络资源、安全资源、数据库资源、应用集群资源、服务实例资源、中间件资源、容器资源**（共 9 大类）。这 9 大类资源对应的 规格、实例均采用同样的属性字段（见下）。

### 3.6 页面功能与交互逻辑

#### 3.6.1 云资产 规格（云资产 资产 Models）

- 入口：云资产 资产 Models。
- 字段分组：基本信息。

#### 3.6.2 云资产实例（云资产 asset）

- **菜单入口**：在软件实例下新增 云资产 asset 菜单，可在此菜单下实现实例的新增。
- 字段分组：基本信息、财务信息。
- **左侧类型分类面板**：按资产类型（硬件/耗材/捆绑/托盘/软件许可/云资产）分类，树形结构，展示各类型实时数量。
- 名称 由系统按 `CL+9位随机数字+Model名称` 自动生成，不展示在创建实例属性字段中。
- 补充：图标在设计稿中提取，其他不需要关注设计稿。

## 4. 验收标准

- 云资产覆盖 9 大类资源（计算/存储/网络/安全/数据库/应用集群/服务实例/中间件/容器），规格 与实例采用同样属性字段。
- 云资产 规格 可创建，名称/规格分类 必填，简短描述 非必填。
- 云资产实例可手动新增，规格分类、规格 必填；名称 由系统按 `CL+9位随机数字+Model名称` 自动生成且不展示在创建字段。
- 状态 字典值（In Service/Idle/待处理 Allocation/Deactivated/Decommissioned）可选；Auto Create CI 生效并可关联 CMDB CI。
- 财务信息（月度成本/供应商/成本中心/Start 时间/End 时间）正确录入与展示。
- 通过 规格 category 与 CI 关联、通过 Mapping 与 CMDB 字段映射同步生效（Mapping 依赖映射管理需求）。
- 实例字段支持后续在 Class 中新增或删除。

## 2. 需求分析

### 2.1 业务背景

企业初始化与日常维护中，需要批量录入/更新资产、规格、组织、合同等数据，并将系统数据导出用于报表、盘点、审计。手工逐条维护效率低、易出错。导入导出提供统一的批量能力，覆盖系统主要对象，配合模版与数据质量校验，保证批量操作的准确性与一致性。软件资产管理最具挑战的是完整收集软件权利，通过 许可证 导入 可一次性批量导入软件 license，利用拖放界面并自动进行导入前后数据质量检查。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **效率提升**：批量导入/导出替代逐条维护，显著降低初始化与运维成本。
- **数据质量**：导入前后自动质量检查（唯一性、必填、类型），错误报告定位问题行。
- **权限安全**：导出遵循可见性权限，不可见的行/列不被导出；默认仅可查看/操作自己创建的任务。
- **通用一致**：统一入口（More → 导入/导出）与统一任务管理（Setting）。

#### 2.2.2 调研结论及竞品分析

- **DCIM**：导出直接导出当前所选内容，无交互，文件名可能乱码；导入=导入模版+当前页查看错误详情。
- **CMDB**：导出时增加筛选目标范围+任务列表；导入=导入模版+导入任务列表（历史任务回看）。
- **ITAM 方案**：导出可选择导出目标范围与导出列；导入每个对象单独定义模版；**本期暂不实现导入/导出任务列表功能**，导入仅在当前页显示结果及错误详情。

### 2.3 用户故事

- 作为**资产管理员**，我希望按筛选范围与列导出台账数据，以便报表与盘点。
- 作为**SAM/规格管理员**，我希望用模版批量导入软件 license 与规格，以便快速完成权利收集。
- 作为**系统管理员**，我希望查看导入导出历史任务与错误报告，以便排查数据问题（后续能力）。

## 3. 需求设计

### 3.1 角色与通用说明

- 相关角色：`model_manager`、`sam`、`category_manager`、`asset`。
- 导出支持格式：CSV、Excel；导出过程目前不可取消；导出结果分为成功、失败。
- 导入支持类型：xls、xlsx；文件大小不超过 100M；对不同对象可定义不同模版；导入过程中可取消；导入结果分为成功、失败。

### 3.2 导出功能

#### 3.2.1 涉及到的表

- 各对象表：`asset`、`规格`、`resource`（location/cost center）、`organization`、`fixed_asset`、`contract`
- `import_export_task`（导入导出任务表，任务列表后续实现）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 批量导出 | 为 资产、规格、Resource、Organization、Fixed 资产、合同 增加批量导出 | 入口在上述页面有 More 按钮处增加 导出；点击进入导出页面，选择筛选范围后批量导出至文件；导出成功可直接看到下载结果文档，失败在当前页弹窗提示 |
| 文件命名 | 导出文件名规则 | `表对象名称_年月日`（表对象为 class 中配置的表名称） |
| 导出列选择 | 按当前用户选择导出列 | 两个选项：a. 当前列表视图可见列；b. class 中 table 配置的 display columns 列；默认 a |
| 导出行范围 | 包含过滤条件与排序 | 列表默认筛选与高级筛选配置的条件生效；按用户自定义排序导出 |
| 权限控制 | 遵循可查看权限 | 不可见的行/列导出后也不可见，用户必须有可查看权限才能导出对应数据 |
| 格式自动转换 | 大数据量格式转换 | 默认 Excel 导出；数据超过 10 万条自动将 Excel 转为 CSV 导出（后续增加超 50W 条数据提醒） |
| 数据上限 | 无上限 | 导出任务数据上限：无上限 |
| 任务权限 | 任务可见性 | 默认所有人仅可查看自己创建的导出任务，系统管理员可查看所有导出任务 |

### 3.3 导入功能

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 批量导入 | 为 资产、规格、Resource、Organization、Fixed 资产、合同 增加批量导入 | 规范模版 → 下载模版 → 依据模版数据批量导入到对应表；bundled asset 过于复杂，暂不支持批量导入；入口在上述页面 More 按钮处增加 导入 |
| 关联 页签 导入 | 关联页卡也支持导入 | 包括 Fixed asset 的 Covered asset、软/硬件关联 合同、software asset 关联 用户/Device Entitlements、库房 关联 service location |
| 导入模版选择 | 分类别展示对象模版 | 在固定对象下导入时默认下载该对象模版。资产：All/硬件/耗材/Bundled Assets、软件 Licenses、Fixed 资产；规格：All/硬件/耗材/Bundled/合同/软件 Models；Resource：位置/成本 Center；Organization：公司/供应商/制造商/Customer；合同 仅一个模版 |
| 导入模式 | 两种模式 | 仅新增、仅更新 |
| 校验与结果 | 导入校验、进度与结果 | 校验成功提示 `验证 successful, import ** records`，对全量通过数据创建新增记录；若有不通过数据则整个事务失败、不生效任何数据；All 资产/All Models 批量添加需额外字段 后续实现；失败提示 `验证 failure. 查看 error information` |
| 错误报告 | 生成可下载错误报告 | 下载文件在原 Excel 基础上增加一列 `No-compliant Data Reason`，在不满足校验的行最后一列显示原因；一条数据命中多个规则时，将所有原因写在同一记录中以分隔符间隔 |

#### 3.3.2 数据校验规则

- Excel 中满足唯一性要求（ITAM 系统 table 中定义的字段）。
- 必填字段必须有值，且值的类型满足 ITAM 系统中固定对象 form 的要求。
- Template 模版字段暂定为 table 中 display columns 字段，除 创建人、创建时间、更新人、更新时间。

#### 3.3.3 错误提示

- 批量新增/覆盖时，Excel 中存在重复数据：`行 M 列名称 data already exists with row N 列名称`。
- 批量新增/覆盖时，Excel 中存在不唯一：`行 M 列名称 data already exists with row N 列名称`。
- 批量覆盖时，Excel 中唯一标识一行的数据在系统中不存在：`行 M 列名称 data already exists in the system`。

### 3.7 页面功能与交互逻辑

- **导出交互**：点击 导出 进入导出页，选择导出范围与导出列（默认当前视图可见列），确定即创建导出任务；成功可下载结果，失败当前页弹窗提示。
- **导入交互**：点击 导入 进入导入页，选择/下载对象模版 → 选择导入模式 → 上传文件 → 显示进度与结果；校验失败点击「查看 error information」弹窗展示并可下载错误报告。
- **事务性**：导入采取全量事务，存在不通过数据则整体失败、不生效任何数据。

## 4. 验收标准

- 资产/规格/Resource/Organization/Fixed 资产/合同 及关联页卡的 More 中均可 导入/导出。
- 导出可选择范围与列（默认当前视图可见列），遵循可见权限；文件名为 `表对象名称_年月日`；超 10 万条自动转 CSV。
- 导入支持 xls/xlsx（≤100M）、新增/Update 两种模式；各对象按唯一性字段校验；错误报告含 No-compliant Data Reason 列并按提示语报错；存在不通过数据整体事务失败。
- 各对象唯一性字段与模版分类与本文一致；任务列表（Setting）作为后续能力预留。

## 2. 需求分析

### 2.1 业务背景

当企业建立了规格模型（规格）之后，需要对与规格对应的软件许可资产进行创建与管理。软件许可资产用于管理软件的许可证（许可证）及其授权关系，围绕财务价值管理诉求，联动合同、费用/成本、厂商/组织。软件许可以 **许可数量** 为核心，支持为用户与设备分别授权，并可关联合同、设置升降级关系。

> 特别说明：软件资产没有 CI 项，CMDB 当前不管理 software license。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **资产价值跟踪**：跟踪软件许可生命周期流转对企业财务管理的影响，围绕财务价值管理诉求，联动合同、费用/成本、厂商/组织、运营管理。
- **合规与授权管理**：通过 授权数 与授权数量比较，控制授权不超额；通过条件设置控制授权对象合规。
- **成本控制**：控制软件采购与订阅支出，提升许可利用率。
- **风险缓解**：减少重复采购，支持合规审计，明确许可归属。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 许可证/SW Entitlements：`alm_license` 记录许可资产；支持 用户 Entitlements、Device Entitlements 分别授权；授权受 授权数 上限与 设置条件 约束；许可可关联合同（Assets Covered）与升降级关系。

### 2.3 用户故事

- 作为**软件资产管理员**，我希望创建软件许可并录入 授权数，以便管理可授权总量。
- 作为**IT 运维**，我希望将 许可证 授权给满足条件的用户或设备，以便合规地分发许可。
- 作为**合规专员**，我希望授权受 授权数 与条件约束，超额或不满足条件时授权失败，以便避免违规。
- 作为**采购/合同人员**，我希望将许可与合同关联，以便统一管理许可的合同覆盖。

## 3. 需求设计

### 3.1 资产实例化模块

在系统中创建软件许可资产的目的，是实现对企业软件许可全面、系统、科学的管理。软件许可资产表为 `alm_license`。

### 3.2 创建软件许可资产（两种模式）

#### 3.2.1 涉及到的表

- `alm_license`（软件许可资产表）
- `规格`（规格模型表，引用；category=软件 许可证）
- `cmdb_ci`（配置项表，引用；模式1 手动关联/自动创建，模式2 依赖 mapping）
- `location` / `department` / `company` / `vendor` / `cost_center`（组织与位置引用表）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建软件资产-模式1A | 手动创建，创建资产时同步自动创建 CI 并关联 | 发起创建时调用 CMDB API 创建 CI，获得 ciId 回填 资产 引用字段 |
| 创建软件资产-模式1B | 手动创建，创建资产时手动选择已有 CI 并关联 | 选入单条 CI 获取 ciId 回填 资产 引用字段 |
| 创建软件资产-模式2 | 周期性后台任务自动创建 | ITAM 设定固定任务每日执行一次，由 CMDB 开查询接口，读取 CMDB CI 库，根据当日新增 CI 自动创建 资产；通过 规格 category 找到 资产 class 分类，通过 CMDB 与 ITAM 的 规格 mapping 找到对应 规格；可 mapping 关联的字段直接用 CI 值填充（mapping 后续完成） |
| 资产标识 生成 | 系统按规则生成资产唯一编码 | 软件许可资产 `SW+8位数字`，全局唯一，详见《资产标识配置规则》 |
| 状态驱动字段联动 | 新增页字段随 状态 变化 | 状态 值不同时新增资产页面字段不同（详见 3.2.5） |
| 关联文件 | 资产可添加关联文件 | 选择文件后可展示文件并提供删除功能 |
| 修改软件资产 | 对填错或未填字段进行修改 | 已有资产未被引用（未分配给用户/设备）时可修改；不可修改字段：名称、规格分类、规格 |
| 删除软件资产 | 删除单条或批量删除 | 入口1：列表页点击具体资产进入修改页，提交 右侧提供 删除；入口2：列表页勾选多条，在 More 操作中选择 删除 批量删除；删除二次确认（标题 Confirmation，内容 "Are you sure you want to delete this record？"），删除成功后列表页不再展示且数量 -1 |

#### 3.2.5 新增页字段的 状态 联动规则

- **通用**：显示 库房 字段时，同时显示 货架 & 树形结构下拉框。
- **已下单**：显示 已预留 for 字段，不显示 分配给 与 库房 字段。
- **在库**：显示 库房 和 已预留 for 字段，不显示 分配给；位置 不可改，由系统取 库房 的 位置 值自动填充。
- **在途**：新增页字段见对应截图。
- **使用中、维护中、已退役、丢失、Build**：显示 分配给 字段，不显示 库房 及 已预留 for 字段。

#### 3.2.6 新增页字段说明（交互）

- **规格分类**：必填，下拉框，默认 软件 许可证；支持模糊搜索。
- **规格**：必填，下拉框，支持模糊搜索，展示已有 规格 display 名称。
- **CI**：下拉框，可选择当前 CMDB 中已有 CI，显示 CI 名称，支持模糊搜索；选定 规格分类 后 CI 下拉框才可操作；先选 规格分类 时，CI 选项为该 category 关联 CI class 下的 CI 集合（缩小范围）。
- **子状态**：与 状态 关联，除数据字典值外增加 "None"。
- **已预留 for、管理人、归属人**：取维护好的人员名单，显示人名供筛选。
- **位置**：下拉框，选项为合同功能部分创建的所有位置列表。
- **部门、公司**：取维护好的部门/公司名单，显示 名称 供筛选。
- **父级**：父级资产，显示当前所有软件资产。
- **申请行**：显示所有请求记录（弹窗显示 编号、Short 描述，后续提供）；选中后以请求记录时间默认填充 创建时间，可修改。
- **成本中心、供应商**：取维护好的费用中心/供应商名单，显示 名称 供筛选。
- **获取方式、支出类型**：下拉框，可选项除数据字典外增加 "None"。
- **受益人**：取维护好的组织列表。
- **Depreciation**：取维护好的折旧时间周期列表。
- **剩余日期**：自 折旧生效日期 生效以来的天数（如折旧从 1/1 开始，今天 1/5，则 剩余日期=4 天）。
- **剩余价值**：根据折旧方法计算得到（后续补充）。
- **折旧金额**：资产已折旧金额，值为 cost - 剩余价值。
- **Supported group / 支持人**：取维护好的名单，显示 名称 供筛选。
- **用户 Entitlements → 设置条件**：对获取 许可证 的用户进行条件设置。Select field 包含用户表所有字段属性；当属性字段引用其他表时，展开该引用对象的所有属性（引用表可持续向右扩展）；Select operator 下拉选项见截图；可添加多个筛选条件，支持模糊搜索。条件添加成功后，为用户授权时会校验是否符合，不符合则添加失败。
- **Device Entitlements → 设置条件**：对获取 许可证 的设备进行条件设置，交互与用户条件相同。条件筛选包括：左侧第一级（所有 category、所有 asset class 列表），列表中条件有引用时可向右扩展（asset 所有属性）。

### 3.3 将软件 许可证 授权给用户（用户 Entitlements）

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建用户授权 | 对资产进行用户授权 | 当 许可证 的 授权数 数量 > 已授权设备数+用户数之和时可继续授权，否则失败；软件 许可证 可为设备、用户分别授权；仅可对满足 许可证 中设置的 user condition 的用户授权 |
| 授权入口 | 详情页发起授权 | 通过选择具体 软件 license 进入详情页（页签 标题显示 名称），点击 "用户 Entitlements" 页签 下 "New" 按钮进入新增用户授权页；保留 暂不展示数据 |
| 授权校验 | 校验授权数量与条件 | 已授权设备数+用户数 < 授权数 且满足用户筛选条件 → 授权成功，用户 entitlements 数量 +1，剩余可授权数量 -1；< 授权数 但不满足条件 → 失败，提示 "Cannot allocate licenses to the user because of set conditions"；= 授权数 → 失败并提示 |
| 删除用户授权 | 收回用户权限 | 可删除已授权用户，权限收回，可分配 许可证 数量 +1；不可修改已分配用户（重新选择用户会当作新用户新增授权）；入口：用户授权列表页点击具体记录，提交 右侧提供 删除 |

#### 3.3.2 用户授权字段说明

- **名称**：系统自动生成，规则 "用户名 组合 名称(软件 Licenses)"，格式 "名称(名称)"。
- **分配给**：下拉选择，展示所有用户名，支持模糊搜索。
- **Licensed by**：默认由系统填充为所选 软件 许可证 的 名称，也可下拉选择所有已有 software 许可证。
- **提交**：点击 "提交"。

### 3.4 将软件 许可证 授权给设备（Device Entitlements）

#### 3.4.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建设备授权 | 对资产进行设备授权 | 当 授权数 数量 > 已授权设备数+用户数之和时可继续授权，否则失败；软件 许可证 可为设备、用户分别授权 |
| 授权入口 | 详情页发起授权 | 通过选择具体 软件 license 进入详情页，选择 Device Entitlements 页签，点击 "New" 进入新增设备授权页 |
| 授权校验 | 校验授权数量与条件 | 已授权设备数+用户数 < 授权数 且满足设备条件筛选 → 授权成功，Device entitlements 数量 +1，剩余可授权数量 -1；< 授权数 但不满足 → 失败，提示 "Cannot allocate licenses to the device because of set conditions"；= 授权数 → 失败并提示 |
| 删除设备授权 | 收回设备权限 | 可删除已授权设备，权限收回，可分配 许可证 数量 +1；不可修改已分配设备；入口：设备授权列表页点击具体记录，提交 右侧提供 删除 |
| 硬件删除自动回收 | 设备删除时自动回收 许可证 | 用户删除硬件设备时，若设备绑定了 许可证，则删除成功时解绑并回收 许可证 权限，许可证 可分配数量 +1；入口：hardware assets 选择固定资产删除 |

#### 3.4.2 设备授权字段说明

- **名称**：系统自动生成，规则 "设备名 组合 名称(软件 Licenses)"，格式 "名称-(名称)"。
- **分配给**：下拉选择，展示所有设备名，支持模糊搜索。
- **Licensed by**：默认由系统填充为所选 软件 许可证 的 名称，也可下拉选择。
- 新增页面不显示 "删除"，仅点击已授权设备进入详情页才有 删除。
- **提交**：点击 "提交"。

### 3.5 将软件 许可证 与合同关联（Contracts）

#### 3.5.1 关联合同字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 合同 | - | - | 指定与资产相关的合同，将资产与覆盖其使用/维护/支持的合同关联 |
| 资产 | - | - | 指定被合同覆盖的资产 |
| 日期 added | DATE | - | 资产被添加到合同覆盖下的日期 |
| 日期 removed | DATE | - | 资产从合同中移除的日期（不再受合同覆盖时记录） |

#### 3.5.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建软件关联合同 | 选择已有合同，将资产与合同关联 | 通过选择具体 软件 license 进入详情页，选择 Contracts 页签 点击 "New" 进入新增合同关联页；提交后资产与合同关联成功，关联合同 页签 页数量正确；通过合同管理模块进入该合同时，Assets Covered 列表数量 +1 |

#### 3.5.3 合同关联字段交互

- **合同**：下拉框，支持模糊搜索，显示当前所有合同 名称。
- **资产**：下拉选择，默认显示当前软件资产 许可证 的 display 名称，支持模糊搜索。
- **日期 added、日期 removed**：日期选项。

### 3.6 为软件 许可证 创建升降级（Upgrade & Downgrades）

> 说明：源文档标注 hold，个人理解应为 规格 级别关联软件升降级版本，不应为实例级别关联。此处忠实记录源文档字段与功能。

#### 3.6.1 升降级字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 许可证 | - | - | 指定要升级或降级的软件许可证 |
| 降级子级 | - | - | 降级后的子许可证（原始许可证被替换为的较低版本） |
| 升级父级规格 | - | - | 升级后的父许可证（原始许可证被替换为的较高版本） |
| 开始日期 | DATE | - | 升级或降级开始日期 |
| 结束日期 | DATE | - | 升级或降级结束日期（新许可证生效或旧许可证失效日期） |

#### 3.6.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建软件升降级许可 | 对软件许可证进行升降级设置 | 选择已有资产，增加 软件 Upgrade and Downgrades；用户被授予某许可证后，持该许可证可使用已添加过的升降级软件 |
| 升降级入口 | 详情页发起 | 通过选择具体 软件 license 进入详情页，选择 软件 Upgrade and Downgrades 页签 点击 "New" 进入新增升降级软件页 |
| 提交与展示 | 关联成功后展示 | 提交后 许可证 与升降级软件关联成功，该 页签 下数量正确、默认字段展示 |
| 删除升降级关联 | 删除填错记录 | 入口：关联 页签 列表页点击具体记录，提交 右侧提供 删除 |

#### 3.6.3 升降级字段交互

- **许可证**：下拉框，支持模糊搜索，显示当前选中 许可证 的 display 名称。
- **降级子级**：弹窗显示所有已有 软件规格，选择后显示值为 "制造商 + 名称"。
- **升级父级规格**：弹窗显示所有已有 软件规格，选择后显示值为 "制造商 + 名称"。
- **开始日期、结束日期**：日期选项。

### 3.7 页面功能与交互逻辑

#### 3.7.1 列表页（资产台账-软件许可资产）

- **左侧类型分类面板**：按资产类型（硬件/耗材/捆绑/托盘/软件许可/云资产）分类，树形结构，展示各类型实时数量；点击切换筛选。
- **默认展示列**：名称、规格分类、资产标识、序列号、分配给、公司、状态、子状态、授权数；可筛选字段包括「软件许可资产字段说明」表中所有字段。
- **展示数量**：显示软件资产总数。
- **列表页交互**：复选框、筛选条件、列筛选、批量删除等，与其他页面风格一致。
- **导出**：支持当前页面配置列、所有列、当前页、所有页、指定页/页范围导出，格式为 Excel。
- **预留 页签**：参考 ServiceNow，预留 Overview 页、资产 tasks 页（暂不展示数据）。
- **手动创建入口**：通过左侧 资产 Estate 打开 软件 licenses 列表，点击 "New" 进入创建资产详情页。

#### 3.7.2 详情页（新建/编辑）

- 页签 标题显示 名称；关联 页签：用户 Entitlements、Device Entitlements、Contracts、软件 Upgrade and Downgrades、暂不展示数据。
- 字段随 状态 联动显示（详见 3.2.5）。
- 保存时做字段校验（必填/类型/长度），资产标识 按 `SW+8位数字` 规则只读生成或校验唯一。

## 4. 验收标准

- 软件许可资产可完成创建（模式1A/1B/模式2）、查看、编辑、删除全流程，字段与字典值符合本文定义；不可修改字段（名称、规格分类、规格）生效。
- 资产标识 唯一且符合 `SW+8位数字` 规则；状态机切换符合约束。
- 新增页字段随 状态（已下单/在库/在途/使用中/维护中/已退役/丢失/Build）正确联动。
- 用户授权：授权数 上限与 user condition 校验正确（成功/失败提示准确）；删除授权后可分配数量 +1。
- 设备授权：授权数 上限与 device condition 校验正确；删除硬件设备时自动回收绑定 许可证。
- 合同关联：关联/删除后合同 Assets Covered 列表数量同步。
- 升降级：可创建/删除升降级关系并正确展示。
- 列表左侧类型分类面板计数准确，默认列与筛选可用，导出功能可用。

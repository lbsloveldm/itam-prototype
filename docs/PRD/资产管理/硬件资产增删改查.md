## 2. 需求分析

### 2.1 业务背景

当企业建立了规格模型（规格）之后，需要对与规格对应的实物资产进行创建与管理。硬件资产是 ITAM 的核心资产类型，覆盖计算机、服务器、网络设备、外设等实体设备。系统需支持对硬件资产完整生命周期（采购→入库→在用→维修→退役→处置）的记录与流转，并围绕财务价值管理诉求，联动合同、成本/费用、厂商/组织进行运营管理。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **资产价值跟踪**：跟踪资产生命周期流转对企业财务管理的影响，围绕财务价值管理诉求，联动合同、费用/成本、厂商/组织、运营管理。
- **透明度提升**：建立资产可见性，遏制未知资产扩散，解决费用分配问题。
- **成本控制**：控制资本支出与运营支出，提升已有资产利用率，提供库存监督。
- **风险缓解**：减少重复采购，最小化风险，支持合规，快速定位资产、跟踪转移、明确资产责任人。
- **流程优化**：在规划、获取、接收、替换、转移、退役、处置各环节提升效率、减少错误。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow HAM（硬件 资产 Management）：资产与 CI 一对一关联；资产标签按前缀规则自动生成；列表页支持树形分类与多字段筛选；预留 Overview、资产 tasks 页签。

### 2.3 用户故事

- 作为**资产管理员**，我希望在创建资产时自动/手动关联 CMDB CI，以便资产与配置数据保持一致。
- 作为**IT 运维**，我希望按类型（硬件/耗材/软件/捆绑/托盘/云）快速筛选资产并查看关键字段，以便高效盘查。
- 作为**财务人员**，我希望资产记录完整承载采购、成本、折旧信息，以便进行资产价值核算。

## 3. 需求设计

### 3.1 资产实例化模块

在系统中创建资产的目的，是实现对企业资产全面、系统、科学的管理。通过创建资产记录，可存储序列化设备的详细信息（零件、工具、消耗品、预装件、层次化多组件资产），并捕捉复杂关系、保修、服务合同与租赁条款。

### 3.2 创建资产（两种模式）

#### 3.2.1 涉及到的表

- `asset`（资产主表）
- `规格`（规格模型表，引用）
- `cmdb_ci`（配置项表，引用 `ciId`）
- `location` / `department` / `company` / `vendor`（组织与位置引用表）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建硬件资产-模式1A | 手动创建，创建资产时同步自动创建 CI 并关联 | 发起创建时调用 CMDB API 创建 CI，获得 ciId 回填 资产 的引用字段 |
| 创建硬件资产-模式1B | 手动创建，创建资产时手动选择已有 CI 并关联 | 选入单条 CI 获取 ciId 回填 资产 引用字段 |
| 创建硬件资产-模式2 | 周期性后台任务自动创建 | ITAM 设定固定任务每日执行一次，读取 CMDB CI 库，对当日新增且未绑定资产的 CI 自动创建 资产；需页面配置可选择哪些类型实物可生成资产 |
| 资产标识 生成 | 系统按规则生成资产唯一编码 | 硬件资产 `P+9位数字`（参考 ServiceNow），详见《资产标识配置规则》 |

### 3.5 页面功能与交互逻辑

#### 3.5.1 列表页（资产台账-硬件资产）

- **左侧类型分类面板**：按资产类型（硬件资产/耗材资产/捆绑资产/托盘资产/软件许可/云资产）分类，展示各类型实时数量；点击切换筛选。
- **默认展示列**：名称、规格分类、资产标识、序列号、分配给、公司、状态、子状态；支持将「硬件资产字段说明」表中所有字段加入筛选。
- **展示数量**：顶部显示硬件资产总数。
- **排序**：默认按创建时间倒序，保证新建资产置顶可见。
- **预留 页签**：参考 ServiceNow，预留 Overview 页、资产 tasks 页（暂不展示数据，后续扩展）。
- **操作**：新建、编辑、删除（二次确认 Popconfirm）、批量修改属性（详见《台账管理-批量修改》）、导入、导出。

#### 3.5.2 详情页（新建/编辑）

- 分组展示：**基本信息（General）**、**财务信息（Financials）**、**折旧信息（Depreciation）**、**保修与支持**、**工作笔记**。
- 类型专属字段随资产类型联动显示（硬件资产展示序列号、CPU 核数等）。
- 深链访问不存在的资产 ID 时展示 404 结果页与返回入口。
- 保存时做字段校验（必填/类型/长度），编码字段（资产标识）按规则只读生成或校验唯一。

### 3.6 校验与约束

- 资产标识 全局唯一，硬件资产遵循 `P+9位数字` 规则。
- 状态 与 子状态 需符合状态机约束（如 已退役 才可选退役类 子状态）。
- 资产与 CI 为一对一引用；删除资产进入回收站（详见《查看及恢复已删除资产》）。

## 4. 验收标准

- 硬件资产可完成创建、查看、编辑、删除全流程，字段与字典值符合本文定义。
- 列表左侧类型分类面板计数准确，默认列与筛选可用，默认按创建时间倒序。
- 详情页分组正确、类型专属字段联动、404 守卫生效。
- 资产标识 唯一且符合生成规则；状态机切换符合约束。

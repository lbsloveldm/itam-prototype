### 1.3 名词解释

| 术语 | 含义 |
| --- | --- |
| 维保 | 资产的保修/维护保障期，来源于资产供应商生命周期或维保类合同 |
| Maintenance 合同 | 合同类型为 maintenance 的维保合同，记录维保起止与续保时间 |
| 生命周期阶段 | 资产供应商侧定义的产品生命周期阶段，含 EOL/EOS/EOES/停止销售 |
| 停产（EOL） | 生命周期结束，产品不再获任何官方支持 |
| 停止支持 life（EOS） | 维保生命周期结束，标准支持服务期满 |
| 延长支持结束 life（EOES） | 扩展支持生命周期结束，标准支持期满后额外提供的支持期也即将结束 |
| 停止销售（EOSale） | 销售终止，产品不再由制造商/供应商销售 |
| end_time / renewal_end_time | 合同结束时间 / 合同续保结束时间 |

## 2. 需求分析

### 2.1 业务背景

企业需要及时掌握资产关联的维保合同与维保时间，重点关注即将到期的资产，并按规格分布进行统计，以便提前规划续保、更换或退役。资产维保管理从两种角度展示报表：**合同角度**与**资产供应商角度**。合同角度关注维保合同的 `end_time`（结束时间）与 `renewal_end_time`（续保结束时间）；资产供应商角度关注资产生命周期阶段（生命周期阶段）的 停止销售、停止支持、延长支持结束、停产。

参考 ServiceNow 在资产概览（资产 Overview）中提供的「今年硬件保修到期」展示，说明今年将有多少硬件保修到期。若单独建设 Overview，可考虑增加不同时间维度（本月/本季度/本年/明年）的统计。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **到期可视化**：集中展示即将到期的维保与生命周期资产，避免因维保过期导致的运维风险与非计划停机。
- **续保决策支持**：区分「已到期」与「续保后到期」，帮助管理员判断是否需要再次续保。
- **规格分布洞察**：以饼状图展示今年即将过期资产的规格分布，辅助批量采购/更换决策。
- **成本控制**：提前规划维保与更换，避免临时高价采购与紧急维修。

#### 2.2.2 调研结论及竞品分析

参考竞品（ServiceNow、Globe 等）：产品本身维度展示本月/本季度/本年/明年生命周期结束（停产）、维保生命结束（停止支持 life）、扩展支持结束（延长支持结束 life）、销售终止（停止销售）的设备数量；ServiceNow 视图支持不同时间维度切换。ITAM 采用「产品本身主题 + 合同主题」双主题看板，后续以时间维度扩展柱状图/趋势图。

### 2.3 用户故事

- 作为**资产管理员**，我希望查看今年即将维保到期的资产及其维保时间，以便提前安排续保或更换。
- 作为**IT 运维**，我希望按生命周期阶段（EOL/EOS/EOES/EOSale）分时间维度查看资产数量，以便规划设备替换节奏。
- 作为**采购/财务**，我希望看到今年即将过期资产的规格分布饼图，以便统一预算与批量采购。

## 3. 需求设计

### 3.1 维保看板（资产 Warranty）

#### 3.1.1 涉及到的表

- `asset`（资产主表，读取 保修到期日、生命周期阶段、规格 等字段）
- `规格`（规格模型表，读取生命周期阶段与规格分布维度）
- `contract`（合同表，读取合同类型 maintenance、end_time、renewal_end_time）
- `contract_asset`（合同-资产关联表，用于按合同统计覆盖资产）

#### 3.1.2 功能描述

看板依据 ITAM 表结构设计宽表，围绕「产品本身主题 + 合同主题」组织。

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 生命周期结束（停产）统计 | 分别展示本月、本季度、本年、明年生命周期属于 停产 的资产数量 | 按资产关联规格的 生命周期阶段 = 停产，落在对应时间区间统计 |
| 维保结束（停止支持 life）统计 | 分别展示本月、本季度、本年、明年生命周期属于 停止支持 life 的资产数量 | 生命周期阶段 = 停止支持 life，按时间区间统计 |
| 扩展支持结束（延长支持结束 life）统计 | 分别展示本月、本季度、本年、明年属于 延长支持结束 life 的资产数量 | 生命周期阶段 = 延长支持结束 life，按时间区间统计 |
| 销售终止（停止销售）统计 | 分别展示本月、本季度、本年、明年属于 停止销售 的资产数量 | 生命周期阶段 = 停止销售，按时间区间统计 |
| 维保合同到期统计 | 本月/本季度/本年/明年维保合同（合同类型=maintenance）到期（end_time 到期）的资产数量 | 统计维保合同 end_time 落在对应区间的资产；**需去掉已有续约合同的资产**（避免重复计入） |
| 维保续保到期统计 | 本月/本季度/本年/明年维保合同续保到期（renewal_end_time 到期）的资产数量 | 统计维保合同 renewal_end_time 落在对应区间的资产 |
| 今年过期资产规格分布 | 以饼状图展示今年即将过期资产的规格分布 | 对今年到期资产按 规格/规格 category 聚合，饼图展示占比 |
| 跳转联动 | 点击维保合同到期项可跳转至对应资产/合同列表 | 携带筛选条件跳转台账或合同列表页 |
| 时间维度扩展 | 后续以时间为维度提供柱状图/趋势图 | 设计宽表时预留时间维度字段，支持按时间轴聚合（分阶段实现） |

#### 3.1.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 保修到期日 | DATE | - | 资产保修到期日期，来源于 `asset` 表 |
| 生命周期阶段 | VARCHAR | 40 | 资产供应商侧生命周期阶段（EOL/EOS/EOES/停止销售） |
| 生命周期日期 | DATE | - | 生命周期阶段对应的日期，用于时间区间归类 |
| 合同 type | VARCHAR | 32 | 合同类型，维保统计取 maintenance |
| end_time | DATE | - | 合同结束时间，用于「维保合同到期」统计 |
| renewal_end_time | DATE | - | 合同续保结束时间，用于「续保到期」统计 |
| 规格 | VARCHAR | 32 | 资产规格，用于规格分布饼图聚合 |
| 规格分类 | VARCHAR | 32 | 规格类别，用于规格分布聚合维度 |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 生命周期阶段 | 停产 | 生命周期结束，产品不再获官方更新、修补或技术支持 |
| 生命周期阶段 | 停止支持 life | 维保生命周期结束，标准支持服务期满 |
| 生命周期阶段 | 延长支持结束 life | 扩展支持生命周期结束，标准支持期满后的额外支持期也即将结束 |
| 生命周期阶段 | 停止销售 | 销售终止，产品不再由制造商/供应商销售 |
| 合同 type | maintenance | 维保合同类型，维保看板统计的合同口径 |
| 时间维度 | 本月 / 本季度 / 本年 / 明年 | 四个统计时间区间，各指标均按此四档展示 |

### 3.2 页面功能与交互逻辑

#### 3.2.1 看板布局

- **双主题结构**：上方为「产品本身主题」（EOL/EOS/EOES/停止销售 四组，各含本月/本季度/本年/明年数量卡片）；下方为「合同主题」（维保合同到期、续保到期）。
- **规格分布**：以饼状图展示「今年要过期的资产规格分布」。
- **跳转**：点击维保合同到期数量可跳转至过滤后的资产/合同列表。

#### 3.2.2 丰富组件优化

- **标签 分组**：清晰的分组展示，直接做分组较复杂，优先支持 标签 标签分组。
- **时间组件**：当前缺少时间组件，无法重新选择时间；趋势图基于时间，需具备时间轴调整能力（如拖拽），可分阶段实现。
- **趋势图/柱状图**：后续以时间为维度扩展柱状图/趋势图，宽表设计时预留时间维度。

### 3.3 校验与约束

- 「维保合同到期」统计必须剔除已存在续约合同的资产，避免与「续保到期」重复计入。
- 生命周期阶段统计以资产关联规格的 生命周期阶段 与对应日期为准。
- 时间维度统一为本月/本季度/本年/明年四档，口径需在各指标间保持一致。

## 4. 验收标准

- 维保看板可按合同角度（end_time / renewal_end_time）与供应商角度（EOL/EOS/EOES/停止销售）分别统计并展示。
- 各指标均提供本月/本季度/本年/明年四个时间维度数量，且「维保合同到期」已去除有续约合同的资产。
- 今年过期资产规格分布饼图数据准确，可跳转至对应资产/合同列表。
- 组件优化：支持 标签 分组展示；时间轴/趋势图作为后续分阶段能力预留。

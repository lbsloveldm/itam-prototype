## 2. 需求分析

### 2.1 业务背景

ITAM 移动端需改造为三端融合的独立 App 端。本期先完成登录能力建设，并提供工作台常用能力：随时随地搜索查看资产、现场创建资产、按 PO 收货。移动端让员工在出差、生产现场、客户现场等场景无需依赖电脑即可完成资产相关任务，提高效率、提升数据准确性与协作能力。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **随时随地**：移动端随时查询/创建资产，快速定位与响应故障维护。
- **数据准确**：现场实时采集，扫码/拍照减少手动输入错误。
- **优化管理**：管理者实时掌握资产总体状况，助力盘点核对与跨部门协作。
- **安全登录**：区分本地化/云端部署，支持多种登录方式、找回密码、租户选择与二次认证。

#### 2.2.2 调研结论及竞品分析

主流 ITAM 移动端普遍提供扫码查资产、现场建资产与工单处理能力。本方案对齐并强化多租户登录与二次认证安全体系。

### 2.3 用户故事

- 作为**IT 运维**，我希望在现场扫码即可查到资产详情，以便快速维修。
- 作为**资产管理员**，我希望在现场创建资产记录，以便实时准确入账。
- 作为**多租户用户**，我希望登录后选择租户并完成二次认证，以便安全访问对应组织数据。

## 3. 需求设计

### 3.1 登录

#### 3.1.1 登录方式

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 本地化部署登录 | 直接进入账号密码登录页 | 本地化部署时直接进入账号密码登录页面（图2），不显示「切换登录方式」链接 |
| 云端部署登录 | 提供两种登录认证方式 | 云端部署提供：手机号/邮箱+密码、手机号+验证码（图1），选择后进入对应登录页 |
| 切换登录方式 | 两种方式间切换 | 在任一登录方式下点击「切换登录方式」进入「登录方式选择页面」（图1） |
| 首次登录强制改密 | 首登强制改密 | 首次登录进入强制改密页面；采用手机号+验证码登录时，强制改密页不显示验证码字段；若首登忘记密码并做过找回密码，则不再强制改密 |
| 服务器配置地址 | 配置服务地址 | 提供服务器配置地址页面 |

#### 3.1.2 找回密码

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 找回密码入口 | 登录页「忘记密码」 | 点击后进入找回密码页面，可选手机号验证或邮箱验证并重置密码 |
| 重置成功反馈 | toast + 跳转 | 重置成功后 toast「密码重置成功」，3 秒后自动跳转至登录页且不再显示 toast |

#### 3.1.3 租户选择

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 默认租户 | 跳过选择 | 默认进入上次登录过的未失效租户，跳过租户选择页 |
| 租户列表 | 其余情况展示 | 登录成功后展示账号下的顶级租户列表；数据量大时支持下滑加载更多 |

#### 3.1.4 二次认证

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 触发条件 | 依 PC 端设置 | 仅当 PC 端开启二次认证时拉起，否则直接登录进入资产菜单项 |
| 认证方式 | 与登录方式一致 | 账号(邮箱/手机号)+密码方式需二次认证；手机号+验证码登录无需二次认证；用户用哪种方式登录，二次认证即采用同样方式 |
| 跨账号取号 | 关联信息展示 | 邮箱账号登录且用手机认证时，调取邮箱关联手机号并展示后四位；手机号账号登录且用邮箱认证时，调取关联邮箱并展示（前三字符+***+@example.com） |
| 提示文案 | 未认证提示 | 「您在{租户名}下未认证，为了保障账户安全，请完成以下验证。」；已认证过后续仍需再次认证 |

#### 3.1.5 二次认证-验证逻辑字段字典值说明

| 场景 | 系统行为 | 提示 文案 |
| --- | --- | --- |
| 验证成功 | 后端返回 成功，进入系统 | 「认证成功」 |
| 验证码错误 | 后端返回 错误，保留错误输入 | 「验证码错误，请重试」 |
| 验证码过期 | 后端返回 错误，保留错误输入 | 「验证码已过期，请重新获取验证码」 |
| 重发-倒计时中 | 文案「XXs 后重发」，置灰不可点 | - |
| 重发-倒计时结束 | 文案「重发验证码」，蓝色可点 | - |
| 重发-发送成功 | 重置 60 秒倒计时 | - |
| 重发-发送失败 | 不进入倒计时，保持可点 | 「发送失败，请稍后重试」 |
| 重发-过于频繁 | 依已有频控规则 | 「发送太频繁啦，请X分钟后重试」 |

#### 3.1.6 切换租户

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 查看当前租户 | 「我的」页 | 点击「我的」可看到当前租户及语言页面；语言切换沿用现有功能 |
| 切换租户 | 租户列表 | 点击「切换租户」进入租户列表页，可滑动查看更多，显示租户名称及状态（SAAS 侧提供）；选中后名称后显示「✅」，切换成功后点「<」返回「我的」页 |

### 3.2 搜索查看资产（Assets Lookup）

#### 3.2.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 入口 | 工作台 Assets Lookup | 登录后可见 Assets Lookup 入口，点击进入资产搜索页 |
| 四字段搜索 | 支持以四个字段搜索 | 引用项展示台账中对应项所有结果 |
| 扫码搜索 | 支持扫描二维码搜索 | 扫描二维码后展示对应搜索结果 |
| 仅必填字段 | Only required fields 单选 | 选中后每个模块仅显示必填字段 |
| 搜索结果-有结果 | 展示匹配资产 | 显示资产类型图标 logo、名称；其余三字段随 PC 端配置展示，当前为 规格、状态、子状态 |
| 搜索结果-无结果 | 提示语 | 「This asset doesn't exist in the system！」 |
| 查看/修改详情 | 进入详情页 | 点击资产进入查看详情页，可通过单选项只展示必填字段；有修改权限者可在详情页修改相应字段 |

### 3.3 创建资产（Create Assets）

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 入口与类型选择 | 工作台 Create Assets | 点击后在当前页弹出创建资产类型选择页；移动端去除捆绑资产创建，类型选择页不显示 Bundled assets |
| 字段与 PC 端一致 | 字段相同、顺序一致 | 创建页所有字段与 PC 端相同；手机端展示顺序取 PC 端顺序（从上到下、从左至右） |
| 仅必填字段 | Only required fields 单选 | 选中后每个模块仅显示必填字段 |
| 成本 必填 | 成本改必填 | 硬件、软件、耗材创建页中 成本 字段改为必填，PC 端与手机端同步修改 |
| 引用改下拉 | 减少新页交互 | 将 PC 端之前的引用查看全部改为下拉展示，减少新页面及交互 |
| 创建校验 | PC 端可查 | PC 端搜索移动端新建资产可查看，结果与当前系统一致 |

### 3.4 按 PO 收货（接收 asset from PO）

> 说明：《接收 asset from PO-Workbench for Mobile App》源文档正文内容为 总拥有成本说明，未含收货字段级定义。以下依据操作手册「资产领用/入库」口径与工作台概念描述流程，不杜撰字段。

#### 3.4.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 入口 | 工作台 接收 asset from PO | 登录后工作台可见收货入口 |
| 按 PO 收货 | 依采购订单接收资产 | 依据采购订单（PO）在移动端现场接收资产并入库，生成/更新资产台账记录 |

## 4. 验收标准

- 登录区分本地化/云端部署：本地化直达账密登录，云端提供两种登录方式并可切换。
- 首次登录强制改密逻辑、找回密码（手机/邮箱）与重置成功反馈符合定义。
- 租户选择：默认进入上次未失效租户；否则展示租户列表并支持滑动加载。
- 二次认证按 PC 端开关触发，跨账号取号与各验证/重发场景文案符合字典表。
- 切换租户可查看当前租户、切换并回显选中状态。
- Assets Lookup 支持四字段搜索与扫码搜索，有/无结果展示符合定义，可仅显示必填字段并按权限修改。
- Create Assets 类型选择不含 Bundled；字段与 PC 一致、成本 必填、引用改下拉；补充说明 1~5 均满足。
- PO 收货入口可用，可依 PO 现场接收资产并入库。

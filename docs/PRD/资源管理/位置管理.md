## 2. 需求分析

### 2.1 业务背景

在 ITAM 业务执行层相关模块中，「通用资产事务管理」代表各资产类型（软件、硬件、耗材）通用的管理/操作需求，覆盖 合同/成本/Organization/Reclamation/成功 Management。位置管理隶属成本管理下的通用能力，对实物/资产管理过程中的位置信息进行维护，采用树形结构按层级管理，层级之间通过父关系引用。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **资产价值跟踪**：围绕财务价值管理诉求，联动合同、费用/成本、厂商/组织、运营成功管理。
- **位置主数据统一**：以可扩充的 位置 类型 字典支持灵活地址级别，统一维护位置树，支撑资产、合同、库房的位置关联。

#### 2.2.2 调研结论及竞品分析

| 主题 | 主要结论 |
| --- | --- |
| 国内外友商/大型企业相关产品功能模块调研（IT 资产管理学习与分析） | ITAM 除实物/资产/财务三大核心管理对象外，相关联管理对象还包括合同、位置、组织/人 |
| 系统划分 | 实物系统（CMDB）定期同步 CI 至资产系统；资产系统生成资产卡片并回传实物系统；资产系统与财务系统联动进行成本/费用管理 |

### 2.3 用户故事

| 角色 | 角色说明 | 业务诉求 |
| --- | --- | --- |
| 资产消费者（asset） | 可进行资产查看 | 能够按要求定时导出台账数据生成报告 |
| 系统管理员（user_admin） | 对组织、供应商、位置等企业主数据统一维护管理 | 位置管理（位置 地址等）、组织管理、用户管理等，以确保数据质量 |

## 3. 需求设计

### 3.1 成本管理（成本 Management）—— 位置管理

#### 3.1.1 涉及到的表

- `location`（位置表，含 parent 自引用、location type、fullname 等）
- `location_type`（位置类别数据字典表，含 排序序号）
- `douc_user`（用户表，联系人 外键引用）
- `asset` / `contract` / `stockroom`（引用 location，删除时解除关联）

#### 3.1.2 地址树（层级结构）功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 树展示 | 根据 位置 实例父子关系构建层级树，提供查询、定位、展开、收缩 | 通过主菜单「Locations」进入，标题 统一为「Locations」；默认展示顶级节点，有子节点的节点前展示展开/收缩图标 |
| 树节点搜索定位 | 根据输入框关键字对 位置 的 名称 字段搜索 | 结果以下拉列表展示候选（显示 名称）；点击候选进行树节点定位——逐级展开上游各层级直至选中节点的 父级，并高亮选中候选节点，同时触发右侧 列表 内容变更 |
| 树节点展开 | 对已展开节点，根据下级是否有子节点决定是否显示展开/收缩符号 | 点展开/收缩符号按父子关系展开当前节点，不影响原有选中；点节点则选中并更新右侧 列表，同时展开当前节点 |
| 树节点右键操作 | 节点右侧显示「…」符号，点击弹出操作菜单 | 新增 location、编辑、删除、批量刷新下级所有 fullname |
| 新增区域 | 「New 地区」按钮仅用来创建新的顶级节点 | 新增 location：父级 为空，locationtype='地区' |

#### 3.1.3 位置列表功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 列表入口 | 通过左侧地址树选中节点，右侧打开 位置 列表展示一级子级节点信息 | — |
| 筛选条件 | 默认展示 FullName、名称、位置 类型；通过「更多」添加其他筛选字段 | 支持搜索、已选、清除已选、可选；勾选后自动聚焦并按字段类型下拉（字典多选、引用多选、日期等） |
| 功能按钮-更多/重置 | 更多对应筛选条件；重置去除所有筛选条件值 | — |
| 导出 | 支持当前页面配置列/所有列、当前页/所有页/指定页范围导出 | 导出格式为 Excel |
| 批量删除 | 对未被引用的地址（含各级子地址）进行校验 | 默认对校验通过的地址删除（提示级联删除，确认后批量删除） |
| 列显示设置 | 可设置展示列并支持列顺序调整 | 默认列见字段说明中标注 |
| 行操作-删除 | 右侧固定「删除」，仅对未被引用地址（含各级子地址）级联删除 | 业务逻辑见删除操作 |
| 行操作-Gen-Fullname | 右侧固定「Gen-Fullname」，按当前节点信息批量更新下各级节点全称 | — |

#### 3.1.4 位置 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |

| 国家 | VARCHAR | 32 | 国家，文本，非必填，由 父级 带入 |
| 省份 | VARCHAR | 32 | 州/省，文本，非必填，由 父级 带入 |
| 城市 | VARCHAR | 32 | 城市，文本，非必填，由 父级 带入 |
| Street | VARCHAR | 64 | 路/街，文本，非必填，由 父级 带入 |
| 联系人 | 引用 | 32 | 联系人，外键引用 DOUC 用户 实例 名称 |
| 电话 | VARCHAR | 40 | 联系电话，文本，非必填 |
| 邮编 | VARCHAR | 20 | 邮编，文本，非必填 |

### 3.2 位置详情、新增与删除

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 详情入口 | 位置 列表点击实例行 fullname 超链接，以一级页签展示实例详情 | 每个实例在页签最右侧新开一级页签，位置 列表页签始终第一位；最多打开 10 个页签（除列表页签外），超出提示且不新开 |
| 新增入口 | 位置 列表 New 按钮，弹出一级页签 标题「New 位置」 | 必填字段：名称、父级、位置 类型；其余为非必填（由 父级 带入或手工修改） |
| 保存逻辑 | 由于 Street~国家 等字段依赖 parent 位置，保存时用 父级 对应信息（有值字段）填写实例字段并保存 | 同时自动拼装 Fullname 并保存；新增时这些字段可手工修改 |
| 删除逻辑 | 该地址下有子级地址时弹出级联删除提示 | 提示语「There are descendant locations, do you want to cascade delete all descendants?」；确定后进行地址实例删除，并解除所有资产、合同、库房数据的地址关联关系 |
| 取消 | 取消当前编辑/新增 | — |

### 3.3 页面功能与交互逻辑

- **树 + 列表联动**：左侧地址树选中节点，右侧列表展示其一级子节点；树节点搜索定位联动右侧列表。
- **顶级节点约束**：仅「New 地区」创建顶级节点；locationtype='地区' 时 父级 为空且只读。
- **父带入与全称**：国家/省份/城市/Street 由 父级 带入，可手工修改；Fullname 只读自动拼装，可通过 Gen-Fullname 批量刷新下级。
- **级联删除**：仅未被引用地址（含各级子地址）可删除，删除时级联并解除资产/合同/库房关联。
- **移动端适配**：需考虑移动端适配。

## 4. 验收标准

- 地址树可展示、搜索定位、展开/收缩、右键操作（New/编辑/删除/Gen-Fullname）；「New 地区」仅创建顶级节点。
- 位置 列表默认列（FullName/名称/位置 类型…）、筛选、导出（Excel）、批量删除（仅未被引用、级联）、列显示与顺序均可用。
- 详情/新增字段与 位置 类型 排序序号 字典符合本文定义；父级 带入字段与 Fullname 自动拼装正确。
- 删除有子级地址时级联删除提示生效并解除资产/合同/库房关联；一级页签规则（列表页签置首、最多 10 个实例页签）生效。

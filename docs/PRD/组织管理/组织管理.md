### 1.3 名词解释

| 术语 | 含义 |
| --- | --- |
| 组织 | 广义组织管理涵盖对内（分支机构、部门、员工）与对外（供应商、制造商、客户）资源；本文「组织」仅用于管理外部公司（公司），特别是供应商、制造商、客户 |
| 公司 | 所有外部公司，按与自身的产品/服务供给关系分为 供应商、制造商、Customer；一个公司可同时具备多个标签 |
| 供应商 | 归属 公司 且具备 供应商 标签，直接采购对象（供货商、服务提供商） |
| 制造商 | 归属 公司 且具备 制造商 标签，所购对象的生产企业 |
| 客户 | 归属 公司 且具备 Customer 标签，为其提供产品/服务的对象公司（如我司出租资产给第三方公司，其为 Customer） |
| 规格 / 规格 分类 | ITAM 中 规格 指代规格/型号，一般关联制造商 |
| DOUC 用户 | 用户中心的用户实例，联系人/负责人等字段外键引用其 名称 |

## 2. 需求分析

### 2.1 业务背景

在 ITAM 业务执行层相关模块中，「通用资产事务管理」部分代表各资产类型（软件、硬件、耗材）所具备的通用管理/操作需求，分别与「硬件/软件资产事务管理」组合以覆盖完整资产生命周期（此处仅指管理「动作/任务（Task）」，不含流程）。该公共内容涉及：合同管理、成本管理、组织管理、回收管理、成功管理，根据功能优先级持续演进。组织管理是企业公共主数据管理的主要内容之一。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **资产价值跟踪**：资产生命周期流转对企业财务管理带来影响并进行跟踪，围绕财务价值管理诉求，联动合同、费用/成本、厂商/组织、运营成功管理。
- **主数据统一**：对供应商、制造商、客户等外部公司进行统一维护，保证引用数据质量。

#### 2.2.2 调研结论及竞品分析

| 主题 | 主要结论 |
| --- | --- |
| 国内外友商/大型企业相关产品功能模块调研（IT 资产管理学习与分析） | ITAM 除实物/资产/财务三大核心管理对象外，相关联管理对象还包括合同、位置、组织/人 |
| 系统划分 | 实物管理系统（可理解为 CMDB）定期将实物信息（CI）同步至资产管理系统；资产管理系统按合同/工程规则为实物生成资产卡片并回传实物系统登记；资产管理系统与财务系统联动进行成本/费用管理（折旧、摊分） |

### 2.3 用户故事

| 角色 | 角色说明 | 业务诉求 |
| --- | --- | --- |
| 资产消费者（asset） | 可进行资产查看 | 能够按要求定时导出台账数据生成报告 |
| 系统管理员（user_admin） | 对组织、供应商、位置等企业主数据进行统一维护管理 | 位置管理（位置）、组织管理（供应商/公司/制造商）、用户管理等，以确保数据质量 |

## 3. 需求设计

### 3.1 组织管理（Organization Management）模块

#### 3.1.1 涉及到的表

- `company`（公司主表，含 供应商/制造商/Customer 标签）
- `douc_user`（用户表，联系人、供应商 管理人、业务负责人 外键引用）
- `规格`（规格表，关联制造商，引用）

#### 3.1.2 公司管理（公司）功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 公司 列表入口 | 通过主菜单「Companies」进入列表，以一级页签展示，页签 标题 为「Companies」 | 通过列表方式管理通用外部公司，可赋予不同类型标签 |
| 筛选条件 | 默认展示 名称、Street、城市/District、省份、国家；通过「更多」添加其他筛选字段 | 支持搜索、已选、清除已选、可选；勾选筛选字段后筛选区增加该条件并自动聚焦，按字段类型自动下拉搜索/选择（字典多选、引用多选、日期等） |
| 功能按钮-更多 | 对应筛选条件 | — |
| 功能按钮-重置 | 去除所有筛选条件值 | — |
| 导出 | 支持当前页面配置列/所有列、当前页/所有页/指定页范围导出 | 导出格式为 Excel |
| 批量删除 | 不做额外逻辑及数据同步 | 其他对象若引用被删除实例，则对应引用字段显示「The Object referenced is not available!」 |
| 列显示设置 | 可设置展示列并支持列顺序调整 | 默认展示列见字段说明中带默认标注 |
| 行操作-编辑 | 右侧固定「编辑」操作，打开详情展示模式（一级页签） | 点击 名称 超链接亦可下钻详情 |

### 3.3 页面功能与交互逻辑

- **一级页签管理**：Companies/Vendors/Manufacturers/Customers 列表页签始终位于第一位；每个实例详情在最右侧新开页签，最多同时打开 10 个实例页签，超出提示且不新开。
- **详情编辑态**：Basic 信息 分组固定展示；勾选 供应商 后动态出现 供应商 信息 分组。
- **引用完整性**：删除公司不做级联同步，被引用处显示「The Object referenced is not available!」。
- **类别联动**：从某类别列表新增自动勾选对应标签；编辑中取消标签保存后从该列表移除。

## 4. 验收标准

- Companies 列表默认列、筛选（更多/重置）、导出（Excel，多种范围）、批量删除、列显示与顺序调整均可用。
- 公司 详情/新增字段与字典值符合本文定义；勾选 供应商 出现 供应商 信息 分组并含评级/风险/状态字典。
- Vendors/Manufacturers/Customers 按标签过滤展示，供应商 采用专属默认列；新增自动勾选对应标签，取消标签保存后从列表移除。
- 一级页签规则（列表页签置首、最多 10 个实例页签）与引用不可用提示生效。

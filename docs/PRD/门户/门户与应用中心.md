## 2. 需求分析

### 2.1 业务背景

截图跨多产品家族部署，门户作为产品级落地页，以「常用应用」卡片聚合各产品入口，帮助用户在配置中心、用户中心、资产管理、报告报表、服务管理中心之间快速切换。本模块在同一原型模板中补齐门户/应用中心页面，作为 ITAM 及其关联产品的统一入口。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **统一入口**：一个落地页聚合多产品入口，降低用户在多产品间导航的成本。
- **产品可见性**：以卡片直观呈现各产品及其定位描述，提升产品发现效率。
- **一致体验**：卡片图标、主题色与描述统一风格，形成一致的产品家族视觉。

#### 2.2.2 调研结论及竞品分析

参考企业级平台常见的「应用门户 / App Launcher」（如 ServiceNow 首页应用磁贴、Salesforce App Launcher）：以磁贴/卡片聚合子应用入口并跳转。本原型为静态卡片网格，卡片配置内置于代码，未做后台可配置化（见第 6 节）。

### 2.3 用户故事

- 作为**任一角色用户**，我希望在门户看到所有可用产品卡片，以便一键进入目标产品。
- 作为**资产管理员**，我希望从门户直接进入资产台账，以便快速开展日常工作。

## 3. 需求设计

### 3.1 应用中心（常用应用卡片）

#### 3.1.1 涉及到的表

- 无独立数据表；卡片为页面内静态配置数组（`AppEntry[]`，源自 `AppCenter.tsx`）。跳转目标引用 `ROUTES` 常量。

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 常用应用网格 | 以卡片网格展示常用应用 | 外层「常用应用」Card，内部 行/Col 栅格，每卡 `span=8`（一行三个） |
| 卡片跳转 | 点击卡片进入对应产品首页 | 卡片包裹 `Link`，跳转到卡片配置的 `to`（原型内路由） |
| 卡片展示 | 卡片含图标/标题/描述 | 左侧图标（32px，主题色），右侧标题（加粗）+ 描述（灰色小字），hover 高亮 |

#### 3.1.3 字段说明

字段来源：`AppCenter.tsx` 的 `AppEntry` 类型（静态配置）。

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 标题 | VARCHAR | - | 应用名称，如「配置中心」 |
| 描述 | VARCHAR | - | 应用一句话定位，如「CMDB 配置台账与模型」 |
| 图标 | ReactNode | - | Ant Design 图标组件（以原型为准，非持久化字段） |
| 跳转目标 | VARCHAR | - | 原型内路由，如 `/cmdb/ci` |
| 主题色 | VARCHAR | - | 图标颜色（HEX），如 `#1677ff` |

#### 3.1.4 字段字典值说明（应用卡片清单）

| 卡片标题 | 描述 | 跳转目标（to） | 主题色 |
| --- | --- | --- | --- |
| 配置中心 | CMDB 配置台账与模型 | `/cmdb/ci`（配置台账） | `#1677ff` |
| 用户中心 | 组织机构 / 用户 / 角色 | `/user-center/users`（用户管理） | `#52c41a` |
| 资产管理 | 资产台账与全生命周期 | `/asset/ledger`（资产台账） | `#fa8c16` |
| 报告报表 | 资产洞察与统计分析 | `/insight/dashboard`（资产洞察看板） | `#722ed1` |
| 服务管理中心 | 自服务门户与工单 | `/self-service/portal`（自服务门户） | `#13c2c2` |

### 3.2 页面功能与交互逻辑

#### 3.2.1 应用中心页（`/portal/apps`）

- **标题**：页面标题「应用中心」；卡片区外层为「常用应用」Card。
- **布局**：行/Col 栅格，每卡片 `span=8`（一行三个，自动换行）。
- **卡片交互**：`hoverable`，点击整卡通过 `Link` 跳转到 `to`；图标 32px 主题色，右侧标题加粗、描述灰色小字。
- **跳转目标映射**：报告报表 → 资产洞察看板；服务管理中心 → 自服务门户（均为本原型内最贴近的已实现页面）。

## 4. 验收标准

- 应用中心展示 5 张常用应用卡片，标题/描述/图标/主题色符合本文清单。
- 每张卡片可点击跳转到对应原型路由；hover 有高亮反馈。
- 布局为一行三个卡片，自动换行；页面标题与「常用应用」分组正确。

## 5. 数据来源说明

- **跳转目标映射**：报告报表 → 资产洞察看板；服务管理中心 → 自服务门户（本原型内最贴近的已实现页面）。

## 2. 需求分析

### 2.1 需求背景

企业和组织中的管理者与员工常需向团队或上级展示工作进度和成果，需要将 Dashboard 导出为 PDF 以便在会议、报告或演示中使用；企业也需要对重要数据存档以备未来参考和审计。将 Dashboard 导出为 PDF 是一种有效的数据存档方式，尤其在需要频繁更新和分享数据的情况下——用户可快速生成 PDF，无需手动创建和格式化文档，PDF 还可通过电子邮件发送共享。第一版优先直接支持导出以及邮件发送；后续优化完善模板配置和映射，将 dashboard 转变成 report 并支持周期性配置。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **便于分享**：一键导出 PDF，用于会议、报告、演示。
- **便于存档**：PDF 作为数据存档方式，支持审计与未来参考。
- **高效协作**：生成 PDF 可通过邮件以附件链接形式发送，快速共享。

#### 2.2.2 调研结论及竞品分析

参考 device42：生成的 PDF 在文件上方增加报告名称和生成时间。会议疑问点：生成文件 URL 可能卡顿，可在正文旁增加按钮点击生成；默认不展示 URL，发送时自动带上；URL 作为变量只展示所在位置，发送时再生成。

### 2.3 用户故事

- 作为**管理者**，我希望将看板导出为 PDF，以便在会议/报告中展示与存档。
- 作为**分析人员**，我希望将 PDF 以邮件附件链接发送给相关方，以便快速共享数据。
- 作为**接收方**，我希望即使文件尚在生成也能收到邮件，打开 URL 时得到「文件生成中，请稍后下载」的提示。

## 3. 需求设计

### 3.1 涉及到的表

- `dashboard`（看板视图配置表）
- `report_export`（导出记录表，PDF URL、生成时间、报告名称）
- `notification_log`（邮件发送记录表）

### 3.2 看板导出与邮件发送

#### 3.2.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 导出 PDF | 支持 dashboard 以 PDF 形式导出 | 新增「更多 > 导出 PDF（More > 导出 PDF）」，点击后自动下载该视图的 PDF 文件 |
| PDF 头部信息 | 生成的 PDF 需在上方增加报告名称和生成时间 | 参考 device42 截图 |
| 邮件发送 | 支持生成的 PDF 作为附件链接发送 | 新增「更多 > 邮件发送（More > 导出 邮箱）」，点击后弹窗配置邮件信息，正文自动带上 PDF 的 URL 链接 |
| 邮件配置项 | 邮件需包含收件人、主题、正文 | 见字段说明 |
| 正文默认逻辑 | 正文自动生成含视图名称与 URL | 中文：【视图名称】PDF 下载地址：【URL】；英文：【视图名称】PDF download address：【URL】 |
| 异步生成提示 | 邮件发出时只需给出一个地址；若文件还没生成，打开 URL 时提示「文件在生成中，请稍后下载」 | URL 作为变量，只展示所在位置，发送时再生成 |
| URL 展示策略 | 默认不展示 URL，发送时自动带上；正文旁可增加按钮点击生成 | 应对生成文件 URL 卡顿 |

#### 3.2.2 邮件配置字段说明

| 字段名（中文） | 字段名（英文） | 数据类型 | 备注说明 |
| --- | --- | --- | --- |
| 收件人 | Recipient | 多选 | 邮件收件人，多选 |
| 主题 | Subject | VARCHAR | 邮件主题，长度看 DOUC 限制 |
| 正文 | Body | TEXT | 邮件正文，长度看 DOUC 限制；默认带 PDF URL |
| 发送 | Send | 按钮 | 发送邮件（Send an 邮箱） |

#### 3.2.3 正文默认内容示例

| 语言 | 默认正文模板 | 示例 |
| --- | --- | --- |
| 中文 | 【视图名称】PDF 下载地址：【URL】 | 合同 续约 PDF 下载地址：http://10.0.6.50:32080/#/itam/itam/setting/reminderTemplate |
| 英文 | 【视图名称】PDF download address：【URL】 | 合同 续约 PDF download address：http://10.0.6.50:32080/#/itam/itam/setting/reminderTemplate |

### 3.3 页面功能与交互逻辑

- **入口**：看板视图右上「更多（More）」菜单，含「导出 PDF」「邮件发送」两个操作。
- **导出 PDF**：点击后自动下载当前视图 PDF；PDF 顶部含报告名称 + 生成时间。
- **邮件发送**：点击弹窗，配置收件人（多选）、主题、正文；正文默认带 中英文模板；发送时若文件未生成，接收方打开 URL 提示「文件在生成中，请稍后下载」。
- **URL 变量**：默认不展示 URL，作为变量只展示所在位置，发送时自动生成并带上；正文旁可增加「生成」按钮。
- **移动端适配**：需考虑移动端适配。

## 4. 验收标准

- 看板「更多」菜单提供「导出 PDF」与「邮件发送」；导出 PDF 自动下载且文件顶部含报告名称与生成时间。
- 邮件发送弹窗含收件人（多选）、主题、正文；正文默认按中英文模板带 PDF URL。
- 邮件可在文件未生成时先发送，接收方打开 URL 得到「文件生成中，请稍后下载」提示；URL 默认不展示、发送时自动带上。

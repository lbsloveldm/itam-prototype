## 2. 需求分析

### 2.1 业务背景

发现映射 用于将自动发现的软件信息与手动定义的软件模型进行关联，确保发现的软件信息能正确与企业内部软件资产管理相匹配。它是配置管理资产发现过程中的映射信息：自动扫描网络以识别和收集硬件和软件资产信息（型号、操作系统、安装应用等），并将收集数据与系统现有资产记录关联，以更新或创建资产记录，减少手动录入。

软件 规格 定义软件的标准化属性（理想模型），无法自动关联到真实环境软件实例；发现映射 提供实际扫描规则（探测器）。二者关联的价值在于自动化发现：当 Discovery Probe 扫描服务器时，自动匹配 发现映射 中定义的规则，将发现的软件实例与 软件 规格 关联。

**本期范围界定**：本期完成 发现映射 表管理、软件 Product Definition 引用、软件 规格 增加 发现映射 字段及自动创建 suite component、Suite definition 表预设。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **自动化发现关联**：将扫描发现的软件实例自动匹配到 软件 规格，减少人工。
- **合规计算基础**：软件 Product Definition 通过 发现映射 定位 Entitlement 定义，支撑授权计算。
- **套件自动化**：发现映射 标记 套件定义标记 后，规格 引用时自动生成 suite component，降低套件维护成本。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow：发现映射 定义版本条件、平台、语言、版本条件等匹配规则，通过 DMAP+7 位唯一标识；软件 Product Definition 引用 发现映射 的 Entitlement 定义完成许可计算映射。

### 2.3 用户故事

- 作为**软件资产管理员**，我希望维护 发现映射 匹配规则，以便扫描发现的软件能正确映射到软件产品。
- 作为**软件资产管理员**，我希望创建 软件 规格 时选择 发现映射 自动填充厂商、产品、版本等字段，以便减少录入并保证一致性。
- 作为**软件资产管理员**，我希望将 发现映射 标记为 套件定义标记 后，规格 引用时自动创建 suite component，以便自动维护套件组件关系。

## 3. 需求设计

### 3.1 发现映射表

#### 3.1.1 涉及到的表

- `discovery_map`（发现映射表，含演示数据）
- `software_product`（软件产品，引用）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建 发现映射 表及演示数据 | 定义软件 发现映射 表并管理数据 | 基于要求字段建表并导入演示数据（`samp_sw_entitlement_definition.xlsx`） |
| 创建详情页 | 录入映射匹配规则 | 版本号 condition/版本 condition 选择非 is empty 时显示对应 版本号/版本 字段 |
| 编号 自动生成 | 系统自动生成映射编号 | 规则 `DMAP+7位数字`，唯一（如 DMAP0003791） |
| Entitlement Definition Id 生成 | 唯一标识一个映射 | 7 位数字，系统自动生成，与 编号 后 7 位保持一致 |

#### 3.1.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 版本号 condition | 字符串 | 40 | 软件版本匹配条件；选择非 is empty 时显示 版本号 字段 |
| Product | 引用 | 32 | 引用，软件产品的正式名称；显示系统已有 软件 Product 名称；必填 |
| 软件 title | 字符串 | 1,024 | 软件名称或标题，用于标识和区分不同软件产品；必填 |
| Platform | 字符串 | 40 | 软件运行平台 |
| 编号 | 字符串 | 40 | 记录唯一编号，系统自动生成，规则 `DMAP+7位数字`，唯一 |
| Language | 字符串 | 32 | 软件语言条件，用于匹配特定语言版本 |
| 版本 condition | 字符串 | 40 | 版本类型匹配条件（企业版、标准版等）；选择非 is empty 时显示 版本 字段 |
| Entitlement Definition Id | 整数 | 40 | 唯一标识一个映射，7 位数字，系统自动生成，与 编号 后 7 位一致 |
| 版本 | 字符串 | 40 | 版本号（如家庭版、企业版）；必填 |
| 版本号 | 字符串 | 40 | 具体版本号（如 10.0.1）；必填 |
| 套件定义标记 | 是/否 | 40 | 标记该映射是否用于套件定义（优化新增，见 3.4） |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 版本号 condition | is / is anything / starts with / is empty | 选择非 is empty 时显示 如 starts with + `10.` 匹配 10.0.1、10.1.2 |
| Platform | Anything / Windows / Mac / Unix | 运行平台 |
| Language | Anything / English | 语言条件 |
| 版本 condition | is / is anything / starts with / is empty | 选择非 is empty 时显示 版本 |
| 套件定义标记 | 是 / 否 | 是否用于套件定义 |

### 3.2 软件 Product Definition 引用 发现映射

#### 3.2.1 涉及到的表

- `samp_sw_product_definition`（软件产品定义表）
- `discovery_map` / `license_metric` / `manufacture` / `software_product`（引用）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| Entitlement 引用 | 软件 Product Definition 中 授权定义 / Entitlement Definition Id 引用 发现映射 | 授权定义 取 Discovery Maps 表 编号 字段；Entitlement Definition Id 由创建页选择 授权定义 后在 发现映射 找到唯一记录取值 |
| 后续列表展示优化 | 软件 Product Definition 列表页补充 发布商、Product | 当前未含 发布商、引用型，定义在 发现映射，待完善后补充 |

> 注：软件 Product Definition 完整字段见《License度量与属性》3.4；本文聚焦其与 发现映射 的引用关系。

### 3.3 软件 规格 创建增加 发现映射 字段（优化）

#### 3.3.1 涉及到的表

- `software_model`（软件规格表，新增 发现映射、版本号 condition、版本 condition 字段）
- `discovery_map`（引用）
- `software_product` / `manufacture`（联动填充来源）

#### 3.3.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 增加 发现映射 引用字段 | 创建 软件 规格 时增加 发现映射 引用字段 | 选择 制造商 后 Product 显示该发布商下已有 Product；发现映射 仅显示该 Product 下记录 |
| 反向自动填充 | 未选 制造商/Product 时先选 发现映射 | 以 发现映射 的 Product 填充 规格 的 Product，以 Product 定义的 制造商 填充 规格 的 制造商 |
| 新增条件字段 | 新增 版本号 condition、版本 condition 字段 | 以 发现映射 中对应字段值填充 |
| 版本号/版本 填充 | 版本号 字段调整位置，版本号、版本 值以 发现映射 对应字段填充 | — |
| 填充只读 | 被自动填充的字段在创建页不可人工修改 | 只有当选择其他 发现映射 时才更新对应字段 |

### 3.4 发现映射 的 套件定义标记 与自动创建 优化

#### 3.4.1 涉及到的表

- `discovery_map`（新增 套件定义标记 字段）
- `suite_definition`（套件定义表，预设 suite parent/child）
- `software_model`（自动生成 suite component 页卡）

#### 3.4.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 发现映射 增加 套件定义标记 | 创建页增加 套件定义标记 字段，布尔 型 | 选项值 是/否 |
| 自动创建 suite component | 发现映射 被设为 套件定义标记 且被 规格 创建引用时，自动创建该 规格 关联的 suite component | 创建原则：在 suite definition 中找到该 discovery map 关联的 suite child，找到 suite child 被引用的 软件规格 X，将 X 展示在 suite component 页卡下 |
| 关系层级限制 | 只按 suite parent 直接关联的 suite child 关系生成 | 不存在递归（爸爸-儿子-孙子） |
| 自动创建默认值 | 自动创建时的默认字段值 | Inference mandatory=No，套件父级=当前 软件规格 名称 |

#### 3.4.3 Suite definition 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 启用 | 是/否 | 40 | 默认 True，指配置关系是否生效 |
| 套件父级 | 引用 | 32 | 引用已有的 发现映射 编号 |
| 套件子级 | 引用 | 32 | 引用已有的 发现映射 编号 |
| 内容版本 | 字符串 | 8 | 配置的日期备注，方便识别 |
| 创建时间 | 日期/时间 | 40 | 创建时间 |
| 创建人 | 字符串 | 40 | 创建者 |
| Sys ID | 字符串 | 40 | 自动生成唯一编号 |

#### 3.4.4 Suite definition 配置入口

- 在 许可证 Management 二级菜单最后展示 Suite definition。
- 点击 New 进入新建页面；suite parent、suite child 被选择后显示对应的 编号 字段。
- 初始化系统时，导入附件值 `samp_m2m_suite_entitlement_def.xlsx`。

### 3.5 页面功能与交互逻辑

- **发现映射 入口**：Setting → 许可证 二级导航展示 发现映射；点击对象最右侧展示默认字段及值。
- **列表页**：以 Stage license type、Stage license metric（软件 Product Definition）或映射关键字搜索；引用字段值可点击进入固定对象详情页。
- **创建页联动**：版本号 condition/版本 condition 选择 is empty 时不显示 版本号/版本；选择其他值时显示。
- **软件 规格 创建页**：发现映射 联动填充字段只读，切换 发现映射 才更新。

## 4. 验收标准

- 发现映射 可建表、导入演示数据、创建；编号 按 `DMAP+7位数字` 唯一生成，Entitlement Definition Id 与 编号 后 7 位一致。
- 版本号 condition/版本 condition 选择 is empty 时隐藏 版本号/版本，其余选项显示且必填校验生效。
- 软件 Product Definition 的 授权定义 / Entitlement Definition Id 正确引用 发现映射。
- 软件 规格 创建时选择 制造商 → Product → 发现映射 联动过滤正确；反向选择 发现映射 自动填充 Product、制造商、版本号、版本 且只读，切换才更新。
- 发现映射 标记 套件定义标记 且被 规格 引用时，按 suite definition 直接子关系自动创建 无递归，默认 Inference mandatory=No、套件父级=当前 规格 名称。
- Suite definition 可在 许可证 Management 菜单末尾配置、预设 parent/child 并导入初始数据。
- 字段与字典值符合本文定义。

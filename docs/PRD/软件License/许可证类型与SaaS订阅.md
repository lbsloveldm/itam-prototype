## 2. 需求分析

### 2.1 业务背景

订阅（订阅）软件与非订阅（永久许可）软件在许可证管理上存在差异，系统需区分并分别管理。集中化管理 SaaS 与 SSO 应用的软件订阅，通过为每个用户分配和管理订阅，确保用户有权访问特定软件产品并跟踪使用情况，实现对 SaaS 与 SSO 应用许可证的统一管控，保障合规使用与成本优化。

**订阅型 vs 非订阅型许可证管理差异：**

| 维度 | 订阅软件 | 非订阅（永久许可）软件 |
| --- | --- | --- |
| 许可证有效期 | 明确有效期（如一年/一个月），到期需续订 | 通常永久，无明确过期日期，但可能定期支付维护费 |
| 费用结构 | 基于订阅期限，含初始与续订费用 | 一次性购买，含初始购买与后续维护/支持费用 |
| 灵活性 | 可按业务需求增减订阅数量 | 灵活性低，购买后不易更改 |
| 更新和升级 | 通常含自动更新升级，供应商负责维护 | 可能需手动更新，升级或额外收费 |
| 使用限制 | 可能限制同时连接数、用户数等 | 可能无此限制，但有版本限制 |
| 合规性检查 | 需定期检查合规，确保许可有效 | 合规检查较少，但需确保不违反协议 |
| 管理复杂性 | 更复杂，需跟踪订阅期限和续订 | 更简单，但需确保不违反协议 |

**本期范围界定**：本期完成 软件 Product 管理、软件 规格 增加 Product 字段、软件 订阅 订阅管理。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **区分订阅/永久许可**：通过 软件 Product 的 订阅软件 复选框区分，便于管理与计费。
- **统一 SaaS/SSO 订阅管控**：集中为每个用户分配和管理订阅，跟踪使用情况，保障合规与成本优化。
- **订阅计算准确**：通过 规格 + 版本号 + 软件 Product Definition 唯一定位计算方法，判定订阅相关数量。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow：通过 软件 Product、软件 Product Definition 与订阅工作区管理用户订阅；从 SaaS 与连接的 SSO 应用中提取订阅使用数据，跟踪使用、管理合规并优化许可。参考文档：`view-user-subscription-workspace`（Yokohama IT 资产 Management）。

### 2.3 用户故事

- 作为**软件资产管理员**，我希望创建 软件 Product 并标记是否可订阅，以便系统区分订阅型与一次性购买软件。
- 作为**软件资产管理员**，我希望在 软件 规格 关联 Product，以便基于 规格 + 版本号 唯一定位其许可类型与计算方法。
- 作为**软件资产管理员**，我希望为订阅型实例创建用户订阅记录，以便授权用户使用并跟踪最近活动时间。

## 3. 需求设计

### 3.1 软件产品

#### 3.1.1 涉及到的表

- `software_product`（软件产品表，通过 Class 增加 软件 Product 管理）
- `manufacture`（制造商，引用）
- `software_product_definition`（软件产品定义，引用校验）
- `software_model`（软件规格，引用校验）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建软件产品 | 基于要管理的软件创建软件产品，表明名称、分类、是否可授权、是否可订阅 | 通过 Class 中增加 软件 Product 完成增删改查；入口在 Settings 中增加 软件 Product |
| 修改/删除限制 | 仅可对未被引用的 software product 修改、删除 | 未引用指：未关联到 software product definition、未关联到 软件规格 |
| 创建交互 | New 点击后进入创建 software product 详情页 | 录入字段并保存 |

#### 3.1.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| Product | 字符串 | 100 | 软件产品名称，唯一标识与管理特定软件产品；必填且唯一 |
| 制造商 | 引用 | 32 | 下拉框，开发/提供该产品的公司；展示系统已有 制造商 名称，取 名称 值 |
| 产品类型 | 字符串 | 40 | 下拉框，软件产品类型；见字典值 |
| 产品分类 | 字符串 | 100 | 下拉框，支持模糊搜索；基于 UNSPSC Classification 的全球通用分类，字典值见 `samp_sw_product_classification.xlsx` |
| 订阅软件 | 是/否 | 40 | 复选框，是否为订阅软件；选中表示需按订阅模式管理和授权 |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 产品类型 | Licensable / 子级 / Driver / Not Licensable / Unknown / Patch | 软件产品类型 |
| 订阅软件 | 是 / 否 | 是否订阅软件 |

### 3.2 软件 规格 增加 Product 字段（订阅判定）

#### 3.2.1 涉及到的表

- `software_model`（软件规格表，新增 Product 字段）
- `software_product`（表 A：名称 + 订阅软件）
- `software_product_definition`（表 B：发布商/Product/版本号/许可证 type）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 软件 规格 增加 Product 字段 | 在现有 规格 创建页面增加 Product 字段 | 关联 Product 后，该 规格 是否可被订阅由 Product 的 订阅软件 勾选情况决定 |
| 订阅计算定位 | 基于该 规格 创建的软件实例计算订购时，唯一定位计算方法 | 规格 的 Product + 版本号 + 制造商 可在 软件 Product Definition 中唯一找到一条记录 |
| Product 修改限制 | 未产生实例数据时可修改 Product，否则不可修改 | 在 规格 关联 software subscriptions 产生数据后，不允许修改 Product |

**字段对应关系（表 A software_product → 表 B software_product_definition）：**

| 表 A（软件 规格 / Product） | 表 B（软件 Product Definition） |
| --- | --- |
| 订阅软件 | 许可证 type |
| Product | Product |
| 版本号 | 版本号 |
| 制造商 | 发布商 |

#### 3.2.3 功能校验与交互

- 入口：规格 创建页面。
- 功能：选择已有 Product 列表（支持模糊搜索），完成 软件 规格 与 Product 关联。
- 判定逻辑：step1 从软件 规格 区分产品是否为订阅型（在 软件 Product 定义中勾选 subscription）；step2 通过 规格 的 版本号、制造商、Product 在 软件 Product Definition 表中找到唯一记录，判定订阅与 许可证 metric；step3 软件 license 实例创建时根据引用 规格 判定订阅相关数量。

### 3.3 软件订阅

#### 3.3.1 涉及到的表

- `software_subscription`（软件订阅表，含演示数据）
- `software_model` / `software_license` / `manufacture` / `software_product` / `user`（引用）

#### 3.3.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建 软件 订阅 表及演示数据 | 定义用户的软件订阅权限 | 基于要求字段建表并导入演示数据，将收集数据记录到 软件 订阅 |
| 页卡出现条件 | 只有订阅型实例 许可证 才能看到 Subscriptions 页卡 | 软件 Subscriptions 页卡仅在 规格 为订阅型时出现 |
| 列表查看 | 在软件 许可证 实例下增加 Subscriptions，点击查看列表页 | 点击 名称 进入详情页，点击 New 进入创建页 |
| 创建订阅 | 创建用户使用软件的权利（已授权但未实际完成订阅） | 选择 用户 后以 用户 邮箱自动填充 用户主体名；Last activity 可选填 |
| 保存回填 | 点击 保存 成功新建用户软件订阅 | 以当前实例关联 规格 找到 发布商、Product、版本号、版本、软件 规格 值进行填充 |
| 规格 页卡回显 | 实例增加订阅数据后，通过订阅关联的 规格 在其 software subscriptions 页卡显示订阅记录 | — |

#### 3.3.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 名称 名称 | 字符串 | 255 | 软件订阅显示名称，通常含软件发布商和产品名称（取 软件 规格 名称） |
| 发布商 | 引用 | 32 | 软件订阅的发布商；引用系统已有 制造商 名称 |
| Product | 引用 | 32 | 软件订阅的产品名称；引用系统已有 Product 名称 |
| 版本号 | 字符串 | 255 | 软件产品的版本 |
| 版本 | 字符串 | 255 | 软件产品的版本（用于搜索标准化发现模型） |
| 软件 规格 | 引用 | 32 | 软件订阅的软件模型；引用当前系统软件规格名称 |
| 用户 | 引用 | 32 | 分配此订阅的用户名称；引用当前系统用户名称 |
| 用户主体名 | 字符串 | 255 | 用户电子邮件地址，用于订阅；引用用户名对应的邮箱地址 |
| 最后活动 | 日期 | 40 | 此订阅上次使用日期；通过软件使用事件、自动化脚本等写入；未使用时显示 N/A 或为空 |
| 订阅 type | 字符串 | 40 | 列表页固定显示为 软件 订阅 |

### 3.4 页面功能与交互逻辑

#### 3.4.1 软件 订阅 列表页

- 入口：软件 许可证 实例下的 Subscriptions 页卡（订阅型实例）。
- 展示字段：取 软件 规格 名称、用户、用户主体名、不可修改、固定 软件 订阅。
- 操作：点击 名称 进入详情页；点击 New 进入创建页。

#### 3.4.2 软件 订阅 创建页

- 软件 规格：有默认项，默认展示当前 规格 名称，支持搜索，展示当前所有订阅型 规格 名称。
- 用户：选择用户名，选择后以邮箱自动填充 用户主体名。
- Last activity：记录用户最后一次使用该订阅的日期；未使用可显示 N/A 或为空。
- 保存：以当前实例关联 规格 回填 发布商、Product、版本号、版本、软件 规格。

#### 3.4.3 软件 Product 管理页

- 入口：Settings 中增加 软件 Product 入口。
- 功能：创建 软件 Product；仅对未被引用的产品支持修改、删除。
- 交互：New 进入创建详情页，录入 Product、制造商、产品类型、产品分类、订阅软件 并保存。

## 4. 验收标准

- 软件 Product 可创建，未被引用时可修改/删除，被引用时禁止修改/删除；Product 名称唯一校验生效。
- 软件 规格 可关联 Product；未产生实例数据可改 Product，产生订阅数据后禁止修改。
- 通过 规格 的 Product + 版本号 + 制造商 能在 软件 Product Definition 中唯一定位记录并判定是否订阅、许可证 metric。
- 订阅型实例显示 Subscriptions 页卡，非订阅型不显示；可查看列表、进入详情、新建订阅。
- 新建订阅时选择 用户 自动填充 用户主体名；保存后正确回填 发布商/Product/版本号/版本/软件 规格。
- 实例产生订阅数据后，关联 规格 的 software subscriptions 页卡正确回显订阅记录。
- 字段与字典值符合本文定义。

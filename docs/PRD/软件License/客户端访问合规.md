## 2. 需求分析

### 2.1 业务背景

部分服务器软件（如 SQL 服务器、Citrix、IBM 软件）按客户端访问许可（CAL）计量，需记录哪些用户/设备被授权访问。相比软件安装/使用合规，客户端访问合规更具体：记录授权的成本中心、位置、实际使用用户的 启用 状态，可及时回收僵尸用户，无需等待使用回收规则命中。系统需支持创建 Client 访问 规则、绑定用户/设备，并在合规计算时比对实际访问与台账授权、库存配额。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **CAL 场景覆盖**：支持 用户/Device/用户·Device CAL 及 IBM 系列度量单位。
- **配额管控**：创建规则时校验库存可分配量，防止超配。
- **僵尸清理**：识别 启用=False 用户/设备，及时回收授权。
- **合规闭环**：复用统一 合规状态 calculate 入口，同时计算安装与客户端访问合规。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow SAM 的 用户 subscription / 客户端访问 工作区：以规则维度管理授权配额，按用户/设备绑定声明授权，合规复核比对实际访问与授权，僵尸账号可主动回收。本方案对齐并落地字段与库存校验口径。

### 2.3 用户故事

- 作为**软件资产管理员**，我希望创建 Client 访问 规则并指定配额与组织范围，以便管理 CAL 授权。
- 作为**合规负责人**，我希望绑定用户/设备并在合规计算中识别未授权访问与僵尸账号，以便及时回收。
- 作为**采购/财务**，我希望创建规则时系统校验可分配库存，以便不超配。

## 3. 需求设计

### 3.1 Client 访问 规则

#### 3.1.1 涉及到的表

- `client_access`（客户端访问规则表）
- `client_access_user`（用户绑定表）
- `client_access_device`（设备绑定表）
- `software_license`（软件实例，取有效期 rights 计算可分配量）
- `cmdb_software_product_model`（软件规格，引用）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建规则 | Settings 增加 Client 访问 入口，New 创建规则 | 用户创建实际访问时软件许可合规要求；名称满足唯一性检查，仅唯一时创建成功 |
| 库存校验 | 创建时校验 数量 是否超过可分配量 X | 数量 ≤ X 则创建成功，否则提示"当前仅有 X 数量的权限可分配，不可超过此值。/ Currently, only X number of licenses are available for allocation, and this number must not be exceeded." |
| 绑定用户/设备 | 在规则下添加 Users/Devices 绑定 | 绑定代表企业声明该实体已获授权；未绑定可能被判"未授权使用"触发告警 |
| 动态页卡 | 按 类型 动态展示关联页卡 | 见 3.1.5 |
| 未授权告警 | 检测到未绑定用户/设备访问触发动作 | 发送告警邮件至 IT 管理员；自动生成服务工单要求检查权限或追加采购 |

#### 3.1.3 可分配量 X 计算口径

X = Client 访问 中 软件规格 对应的有效期 license 实例中，位置、成本中心、部门、公司 与 Client 访问 这几个字段值不冲突（值相同、或实例中这几个字段为空）的实例购买 授权数 数量之和。

#### 3.1.4 字段说明（Client 访问 规则）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 名称 | 字符串 | 100 | 客户端访问规则名称，输入框，必填，唯一 |
| 软件 规格 | 引用 | 32 | 引用当前系统规格名称，必填 |
| 类型 | Choice | 40 | 客户端访问类型，下拉字典，必填（无 None 值），见字典 |
| 数量 | 整数 | 40 | 允许使用的许可证数量，即组织按协议拥有的最大使用权数量 |
| 成本 Center | 引用 | 32 | 引用现有成本中心，将访问权限与成本中心关联 |
| 部门 | 引用 | 32 | 引用现有部门，指定访问权限所属部门 |
| 公司 | 引用 | 32 | 引用现有公司实体，多公司/分支环境使用 |
| 位置 | 引用 | 32 | 引用当前系统已有位置，访问的物理/逻辑位置标识 |

#### 3.1.5 字段说明（用户绑定 / 设备绑定 / Devices with installations）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 用户 | 引用 | 32 | 引用当前系统已有用户（用户绑定必填） |
| Device | 引用 | 32 | 引用当前系统已有硬件设备（设备绑定/Devices with installations 必填） |
| 启用 | 布尔 | 10 | 是/否，当前绑定记录是否生效，必填 |
| 来源 | 字符串 | 40 | 固定值"Internal"，表示内部创建管理，默认不可修改，仅展示 |
| 用户 type | 字符串 | 40 | 用户分类（见字典），用于区分可授权/不可授权用户 |

#### 3.1.6 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 类型 | 用户 CAL | 每用户访问服务器需一个许可证，按用户数计量 |
| 类型 | Device CAL | 每设备访问服务器需一个许可证，按设备数计量 |
| 类型 | 用户/Device CAL | 既可按用户数也可按设备数计量 |
| 类型 | Authorized 用户 | 被明确授权使用特定软件的用户（常用于 IBM 软件） |
| 类型 | Authorized 用户 值 单位 | 计量选定用户访问 IBM 软件的数量 |
| 类型 | Employee 用户 值 单位 | 计量组织内所有员工访问 IBM 软件的总数 |
| 类型 | External 用户 值 单位 | 计量组织外用户访问 IBM 软件的总数 |
| 用户 type | None / Licensable / Licensable (Application) / Not Licensable (系统) | 用户是否可授权许可分类 |
| 来源 | Internal | 内部创建管理，固定值 |
| 启用 | 是 / 否 | 绑定记录是否生效 |

#### 3.1.7 关联页卡展示规则（按 类型）

| 类型 选择 | 展示的关联页卡 |
| --- | --- |
| 任意 类型 | 必展示 记录实际动态安装信息 |
| Device CAL | 展示 Devices 页卡（原 Device 改名 Devices） |
| 用户/Device CAL | 展示 Users 与 Devices 页卡（原 用户 改名 Users） |
| 其余（用户 授权类） | 仅展示 Users 页卡 |

### 3.2 客户端访问合规计算（合规状态 of Client 访问）

#### 3.2.1 涉及到的表

- `client_access_calculate_task`（客户端访问计算任务表）
- `client_access_compliance_result`（客户端访问合规结果表）
- `client_access` / `client_access_user` / `client_access_device`（实际访问数据）
- `software_license`（台账授权比对）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 触发计算 | 定时任务 + 前端触发 | 前端复用已有 合规状态 calculate 入口，点击后同时计算安装合规与客户端访问合规 |
| 合规比对 | 实际访问数据与台账比对 | 比较 Client 访问 中实际使用数据（users/devices/devices with installations）与系统台账 |
| 待移除识别 | 识别需移除的两类数据 | 1. 超过授权范围（超过 数量 或超过实例授权）的用户/设备；2. 僵尸（启用=False）用户/设备 |

#### 3.2.3 字段说明（client_access_calculate_task 任务表）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| TaskID | 字符串 | 32 | 任务 ID，系统自动生成，唯一 |
| Taskname | 字符串 | 32 | 任务名称，规则 TaskID + 时间（精确到秒） |
| Unlicensed devices count | 整数 | 10 | 未授权使用设备数量（单条 unlicensed devices=true 加总） |
| 未授权用户 count | 整数 | 10 | 未授权用户数量（单条 unlicensed users=true 加总） |
| 未授权订阅 count | 整数 | 10 | 未授权订阅数量（单条加总） |
| 状态 | 字符串 | 40 | 是否合规，字典值 合规/不合规；有一条不合规即整体不合规 |
| 软件 规格 | 引用 | 32 | 关联台账软件规格 |
| 客户端访问 | 引用 | 32 | 关联引用 客户端访问 已有规则名称 |
| 类型 | 字符串 | 40 | 固定值 客户端访问 |

#### 3.2.4 字段说明（client_access_compliance_result 结果表）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 客户端访问 | 引用 | 32 | 关联引用 客户端访问 已有规则名称 |
| 软件 规格 | 引用 | 32 | 关联台账软件规格 |
| TaskID | 引用 | 32 | 引用计算任务表 TaskID |
| 软件 product | 引用 | 32 | 引用当前系统已有软件产品 |
| Device | 引用 | 32 | 引用当前系统已有设备 |
| 启用 of device | 引用 | 32 | 引用设备 启用 状态，显示 是/否 |
| 未授权设备 | 是/否 | 10 | 是否被授权使用 |
| 用户 | 引用 | 32 | 引用当前系统已有用户 |
| 启用 of user | 引用 | 32 | 引用用户 启用 状态，显示 是/否 |
| 未授权用户 | 是/否 | 10 | 是否被授权用户使用 |
| 状态 | 字符串 | 40 | 合规结果，字典值 合规/不合规 |

### 3.3 页面功能与交互逻辑

#### 3.3.1 Client 访问 规则

- 入口：Settings → Client 访问 → New。
- 创建详情页填写 名称/软件 规格/类型/数量/成本 Center/部门/公司/位置。
- 名称唯一性校验；数量 库存校验（≤ X 才可创建，否则中英文提示）。
- 类型 选择后按 3.1.7 动态展示 Users/Devices/Devices with installations 页卡；在对应页卡添加绑定。

#### 3.3.2 客户端访问合规

- 触发：定时任务或前端 同时计算安装与客户端访问合规。
- 结果：任务表汇总 unlicensed devices/users/subscriptions count 与 状态；结果表逐条记录 启用 状态与是否授权。
- 待移除清单包含超授权与僵尸（启用=False）两类，供后续回收补救。

> 视图展示（近 6 个月趋势、每规则/部门合规看板）本期不做，仅保留数据与列表。

## 4. 验收标准

- Client 访问 规则可创建，类型 字典（7 种 CAL/值 单位）完整，名称唯一性校验生效。
- 数量 库存校验按 X 口径（有效期实例、组织字段不冲突的 授权数 之和）执行，超额时中英文提示阻断。
- 关联页卡按 类型 动态展示：任意 类型 必含 Devices with installations，Device CAL 含 Devices，用户/Device CAL 含 Users+Devices，其余含 Users。
- 用户/设备绑定字段（含 启用/来源/用户 type）符合定义。
- 客户端访问合规可由定时任务与前端 合规状态 calculate 触发，任务表与结果表字段完整，能识别超授权与僵尸（启用=False）两类待移除数据。

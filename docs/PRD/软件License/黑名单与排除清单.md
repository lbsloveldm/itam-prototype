## 2. 需求分析

### 2.1 业务背景

企业存在两类需要"排除/限制"的合规场景：其一，某些软件被企业列为不允许安装使用（安全隐患、许可风险），需识别并移除这些黑名单软件的安装（受限软件 / Blacklisted Installation）；其二，某些硬件资产（测试环境、已退役设备、临时资产）不应计入正式授权统计，否则会导致过度计费或合规风险，需要将其排除在软件许可功能之外（Exclusion list）。两者共同保障合规计算数据的准确性与安全合规。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **安全合规**：识别并移除黑名单软件安装，遏制未授权/高风险软件在企业内扩散。
- **授权口径准确**：排除测试/退役/临时资产，避免其消耗生产 许可证，使审计数据真实反映实际使用。
- **成本控制**：减少不必要的 许可证 消耗与超额采购，降低过度计费风险。
- **闭环处置**：黑名单软件通过 Reclaim 回收卸载流程闭环处理，重新合规计算后可验证结果。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow SAM：软件规格支持"限制/黑名单"标记，合规复核（reconciliation）区分安装/使用/客户端访问/受限软件类型；HAM 支持将资产排除在硬件资产管理许可功能之外（Exclude assets），排除后不消耗许可。本方案对齐上述能力，并沉淀待回收结果表以驱动回收流程。

### 2.3 用户故事

- 作为**软件资产管理员**，我希望把某软件规格标记为黑名单，以便系统自动识别并回收其违规安装。
- 作为**合规负责人**，我希望运行黑名单合规任务并查看受限安装清单，以便发起卸载回收。
- 作为**IT 运维**，我希望把测试/退役设备排除在授权统计外，以便许可数量真实、避免过度计费。

## 3. 需求设计

### 3.1 黑名单软件（受限软件）

#### 3.1.1 涉及到的表

- `cmdb_software_product_model`（软件规格表，新增 `受限软件` 标识）
- `software_installation`（软件安装记录表，引用）
- `restricted_sw_reclamation_candidate`（黑名单待回收结果表，新增）
- `calculate_task`（合规任务表，引用，类型=受限软件）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 设置黑名单软件 | 在软件规格 Details 页增加"受限软件"选项，勾选后该规格进入黑名单 | 通过 class 触发器可对已有 软件规格 更改 受限软件；系统历史数据默认全部未勾选 |
| 黑名单合规任务 | 在导航菜单 Run reconciliation 运行/查看黑名单合规任务 | 运行时可选 发布商、分组、合规类别（含 受限软件）；生成任务并展示于任务列表 |
| 筛选受限安装数据 | 从实际安装数据中筛出已被设为 受限软件 的安装记录 | 结果写入 `restricted_sw_reclamation_candidate` 表 |
| 计算潜在节省 | 每条待回收记录计算潜在节省金额 | 潜在节省 = 固定 许可证 授权给某用户/设备的 rights 单价 × 单条回收 rights 数量 |
| 黑名单回收 | 在 Blacklisted Installation 列表点击 Reclaim 发起卸载回收 | 进入回收卸载权限流程（复用回收流程）；完成后重新 Run reconciliation 展示最新结果 |

#### 3.1.3 字段说明（restricted_sw_reclamation_candidate 待回收结果表）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 硬件 asset | 引用 | 32 | 引用当前系统已有的硬件资产 |
| Product | 引用 | 32 | 引用当前系统已有的产品 |
| 发布商 | 引用 | 32 | 引用当前系统已有的 制造商/发布商 |
| 软件 规格 | 引用 | 32 | 引用当前系统已有的软件规格 |
| 潜在节省 | 币种 | 20 | 潜在节省 = 固定 许可证 授权给某用户/设备的 rights 单价数量 × 单条回收 rights 数 |
| 状态 | 字符串 | 40 | 回收状态，字典值默认"Waiting Revocation" |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 受限软件 | 勾选 / 未勾选 | 勾选则规格进入黑名单；历史数据默认未勾选 |
| 待回收结果 | Waiting Revocation | 待回收（等待撤销授权/卸载） |
| 合规任务 | 客户端访问 / Installation / Usage / 受限软件 | 合规任务类型，黑名单任务取 受限软件 |
| 合规任务 | 合规 / 不合规 | 任务合规结果 |

### 3.2 合规任务列表（Run reconciliation）

#### 3.2.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 历史任务查看 | 在菜单 Run reconciliation 查看所有历史运行过的合规任务 | 列表展示 TaskID、Taskname、状态、类型、Progress |
| 发起任务 | 点击"Run reconciliation"选择 发布商、分组、合规类别后生成任务 | 发布商 默认 All 且支持多选与删除；类型 默认全选；分组 默认选择 部门；生成对应类型任务并展示在列表 |
| 进度展示 | Progress 展示任务进度 | 任务完成显示 100% 或进度条百分比；无法获取实际进度时显示"Not completed" |

#### 3.2.2 字段说明（合规任务列表展示字段）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| TaskID | 字符串 | 32 | 任务唯一 ID，系统自动生成 |
| Taskname | 字符串 | 32 | 任务名称，系统自动生成 |
| 状态 | 字符串 | 40 | 任务合规结果（合规 / 不合规） |
| 类型 | 字符串 | 40 | 任务类型（客户端访问 / Installation / Usage / 受限软件） |
| Progress | 字符串 / 整数 | 40 | 任务进度百分比，完成为 100%，未完成显示进度条或"Not completed" |

### 3.3 排除清单（Exclusion list）

#### 3.3.1 涉及到的表

- `asset`（资产主表，仅硬件资产使用 `Exclude from HAM features` 复选框）
- `software_license`（软件许可实例表，Device Entitlements 授权时排除）

#### 3.3.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| Exclude from HAM | 硬件资产详情页勾选"Exclude from HAM features"复选框排除该资产 | 入口：硬件 asset 详情页；勾选后软件授权时不可再为该硬件授权，不再消耗软件 许可证；系统默认不选中 |
| 授权校验 | 已授权资产不可被排除 | 勾选提交时判定该资产当前是否已有授权；若已授权，当前页给出失败弹窗，提示"You cannot exclude assets with licensed rights." |
| Device 授权默认排除 | 软件 许可证 设备授权时默认排除 Excluded Assets | Device 授权设置无论条件如何，默认排除 Excluded Assets，不能为其授权 |
| Device Entitlements 不可添加 | 软件 Device Entitlements 下不可添加 Excluded Assets | 点击 新增 时，Allocated to 下拉框不展示 Excluded Assets |
| 统计排除 | 后续 许可证 授权使用统计不考虑被排除的资产 | 合规计算/授权统计口径中剔除 Excluded Assets |

#### 3.3.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| Exclude from HAM features | 布尔 | 10 | 硬件资产是否排除在软件许可功能外，是/否，默认 不选中 |

#### 3.3.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| Exclude from HAM features | True | 已排除：不参与软件授权、不消耗 许可证、不计入授权统计 |
| Exclude from HAM features | False | 默认未排除：正常参与授权与统计 |

### 3.4 页面功能与交互逻辑

#### 3.4.1 黑名单软件规格设置

- 入口：软件规格 Details 页新增"受限软件"勾选项；亦可通过 class 触发器批量更改。
- 已有历史软件规格默认未勾选，需管理员显式勾选进入黑名单。

#### 3.4.2 受限安装列表页（Blacklisted Installation）

- 展示所有受限的软件安装列表，字段：硬件 asset、软件 规格、Product、发布商、状态。
- 操作：点击 Reclaim 进入回收卸载权限流程；完成后重新 Run reconciliation 展示最新结果。

#### 3.4.3 硬件资产 Exclude 交互

- 入口：硬件 asset 详情页复选框"Exclude from HAM features"。
- 勾选提交前置校验：若该资产已有授权，给出失败弹窗（"You cannot exclude assets with licensed rights."）并阻断。
- 排除后：软件 许可证 的 Device 授权、Device Entitlements 添加均自动过滤该资产。

## 4. 验收标准

- 软件规格可设置/取消 受限软件，历史数据默认未勾选。
- Run reconciliation 可选 受限软件 类型运行任务，任务列表展示 TaskID/Taskname/状态/类型/Progress。
- 黑名单合规任务筛出受限安装并写入 `restricted_sw_reclamation_candidate`，字段与 潜在节省 计算口径符合本文定义，状态 默认"Waiting Revocation"。
- Blacklisted Installation 列表展示 硬件 asset/软件 规格/Product/发布商/状态，点击 Reclaim 可进入回收流程，回收后重算结果更新。
- 硬件资产可勾选 Exclude from HAM features；已授权资产勾选时报错阻断；排除后不参与 Device 授权、Device Entitlements、授权统计。

## 2. 需求分析

### 2.1 业务背景

软件 Usage 表的核心作用是通过详细记录用户在特定设备上的软件使用情况，帮助企业优化资源分配、控制成本、支持决策，并确保合规性。

- **一、许可证效能监控**：
  - 使用时长计量：总使用分钟数 字段精确记录分钟级使用量（如 Donald Sherretts 使用 InDesign 达 155,160 分钟）；年份/月份 实现分周期统计，支持季度/年度许可证预算编制。
  - 活跃度判断：最后使用时间 time 识别闲置软件（如 Bryan Rovell 的 InDesign 最近使用时间为 0 分钟）；使用次数 统计启动频次（如 Annette Frietas 的 Illustrator 使用 3 次）。
- **二、成本优化支撑**：超额使用预警通过 TS usage count 对比实际用量与许可证配额（示例中 Microsoft Visio 月均使用 9 次）；回收决策依据 回收类型 标注回收类型（如 total_usage 型数据触发批量回收流程）。
- **三、合规审计追踪**：用户-设备绑定验证 配置项 关联物理设备；数据溯源机制 发现来源 标注数据来源。

**本期范围界定**：本期只完成 软件 Usage 的管理，暂不对接采集工具结果（以演示数据导入为准）。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **效能监控**：分钟级使用时长 + 频次统计，识别闲置与超额使用。
- **成本优化**：为回收决策与预算编制提供实证数据。
- **合规审计**：用户-设备-软件绑定与数据溯源，支撑审计追踪。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow：软件使用数据由采集工具（如 SCCM 插件）获取写入 software usage 表，按年月维度统计；本方案对齐其字段结构，SUID 采用 `SU+八位数字` 自动生成。

### 2.3 用户故事

- 作为**软件资产管理员**，我希望查看软件使用记录，以便了解每个用户在每台设备上的使用时长和频次。
- 作为**成本分析师**，我希望按年月维度统计软件使用情况，以便编制许可证预算与回收决策。
- 作为**合规专员**，我希望通过 最后使用时间 time 识别闲置软件，以便触发许可证回收。

## 3. 需求设计

### 3.1 软件使用表

#### 3.1.1 涉及到的表

- `samp_sw_usage`（软件使用表，含演示数据 `samp_sw_usage-2.xlsx`）
- `manufacture`（发布商 引用）
- `software_product`（Product 引用 product 字段）
- `hardware_asset`（硬件 资产 引用 display 名称）
- `user`（用户 引用用户名）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建 软件 Usage 表及演示数据 | 定义用户对软件的使用 | 基于要求字段建表并导入演示数据，将收集数据记录到 软件 usage |
| 入口 | 在 许可证 Management 下增加 软件 usage | 点击后查看列表页 |
| 详情跳转 | 点击 SUID 进入详情页 | — |
| SUID 生成 | 每条记录唯一标识 | 系统自动生成，规则 `SU+八位数字`（如 SU00000001） |

#### 3.1.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 用户 | 引用 | 32 | 使用软件的用户姓名，明确使用主体；引用已有用户名 |
| 邮箱 | 字符串 | 40 | 用户电子邮件地址，用于沟通（更新通知、到期提醒）及身份标识 |
| 发布商 | 引用 | 32 | 软件发行商，明确来源和版权归属；引用当前系统 制造商 |
| Product | 引用 | 32 | 具体软件产品名称，区分不同类型软件；引用 software product 表 product 字段值 |
| 硬件 资产 | 引用 | 32 | 具体硬件资产名称，代表软件在哪台设备上使用；引用 hardware asset 表 display 名称 |
| 回收类型 | Choice | 40 | 回收类型，与许可证回收策略相关；字典值 合计 Usage 时间 / Last Used 日期 |
| 使用类型 | Choice | 40 | 使用类型，描述使用方式/场景（日常办公、开发测试等）；系统默认 desktop |
| 发现来源 | 字符串 | 40 | 发现来源，记录使用数据获取途径（自动发现工具、手动录入等） |
| 最后使用时间 time | 日期/时间 | 40 | 软件最后使用时间，反映活跃度；用于判断是否长期未使用可回收 |
| 月份 | 整数 | 40 | 使用的月份，用于按时间维度统计分析 |
| TS usage count | 整数 | 40 | 特定时间段内的使用计数，统计某时间段使用频率 |
| 总使用分钟数 | 整数 | 40 | 软件总共使用的分钟数，反映使用时长，用于成本核算/资源分配 |
| 总使用秒数 | 整数 | 40 | 软件总共使用的秒数，对使用时长更精确表示 |
| 使用次数 | 整数 | 40 | 使用次数，统计使用频率，评估受欢迎程度和使用需求 |
| 年份 | 字符串 | 4 | 使用的年份，与月份结合提供完整时间维度，便于年度统计 |
| SUID | 字符串 | 40 | 每条记录唯一标识，系统自动生成，规则 `SU+八位数字`（如 SU00000001） |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 回收类型 | 合计 Usage 时间 / Last Used 日期 | 回收类型 |
| 使用类型 | 默认等 | 使用类型；ServiceNow 中该值为空，但字段要求必须有默认值，系统默认 desktop |

### 3.2 页面功能与交互逻辑

#### 3.2.1 列表页（软件 Usage）

- 入口：许可证 Management 下的 软件 usage。
- 展示：软件/设备/用户/最近使用时间/使用频率等字段。
- 操作：搜索、筛选、排序、显示设置等标准操作。

#### 3.2.2 详情页

- 点击 SUID 进入详情页，展示单条使用记录完整字段。

### 3.3 补充说明

- 数据由采集工具（如 SCCM 插件）获取写入，按年份、月份维度统计使用情况。
- 使用类型：ServiceNow 中该值为空，但字段描述要求必须有默认值，故系统默认 desktop。
- 发现来源：ServiceNow 中该值为空，本方案保留记录数据来源。

## 4. 验收标准

- 软件 Usage 可建表并导入演示数据；入口位于 许可证 Management 下。
- SUID 按 `SU+八位数字` 自动生成且唯一；点击 SUID 进入详情页。
- 用户 / 发布商 / Product / 硬件 资产 正确引用系统已有用户、制造商、software product、hardware asset。
- 使用类型 默认 desktop；回收类型 字典值符合定义。
- 支持按 年份 / 月份 维度的使用数据统计展示。
- 字段与字典值符合本文定义。

## 2. 需求分析

### 2.1 业务背景

软件许可（尤其订阅/维护类）具有时效性，过期后不应再计入可用授权。此前软件实例仅有 结束日期，缺少 开始日期 且有效期判定不完整，导致合规计算无法准确区分有效/失效授权。需在软件实例创建/详情页增加 许可证 type、开始日期、结束日期，并明确取值来源、优先级与有效期判定规则。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **合规口径准确**：合规计算仅统计有效期内实例的 rights，避免过期授权虚增可用量。
- **数据自动化**：时间字段可从关联合同自动回填，减少人工录入。
- **灵活覆盖**：人工输入优先，支持特殊情况修正。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow SAM 的软件权利（entitlement）时效管理：区分许可类型，订阅/维护类具有效期，永久类长期有效。本方案对齐并明确 Start/结束日期 取值优先级。

### 2.3 用户故事

- 作为**软件资产管理员**，我希望创建实例时选择 许可证 type 并录入或自动回填有效期，以便实例时效清晰。
- 作为**合规负责人**，我希望合规计算只统计有效期内实例，以便授权总量准确。

## 3. 需求设计

### 3.1 软件实例有效期字段

#### 3.1.1 涉及到的表

- `software_license`（软件实例表，新增 许可证 type、开始日期；已有 结束日期）
- `contract`（合同表，提供 开始日期 / 结束日期 缺省回填值）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 新增字段 | 实例创建页新增 许可证 type、开始日期、结束日期 | 结束日期 已有，本次新增 开始日期；三字段用于有效期管理 |
| 条件展示 | Start/结束日期 出现前置条件 | 当 许可证 type 为 Maintenance、永久+Maintenance、订阅 时才出现 开始日期/结束日期 |
| 取值来源 | 时间值支持人工输入或合同回填 | a. 前端直接输入；b. 未填充时取关联合同的 开始日期/结束日期 回填该实例（不考虑一个实例关联多合同的多值情况） |
| 取值优先级 | 人工输入优先于系统自动赋值 | 应对人工修改情况 |
| 有效期判定 | 实例有效期截止规则 | 许可证 type 为 Maintenance/永久+Maintenance/订阅 时，有效期截止取 结束日期；否则永久有效 |

#### 3.1.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 许可证 type | Choice | 40 | 许可类型，下拉字典（见字典值），决定是否有有效期 |
| 开始日期 | 日期 | - | 有效期开始时间；人工输入优先，缺省取关联合同 开始日期；仅在 许可证 type 为 Maintenance/永久+Maintenance/订阅 时展示 |
| 结束日期 | 日期 | - | 有效期截止时间；人工输入优先，缺省取关联合同 结束日期；仅在 许可证 type 为 Maintenance/永久+Maintenance/订阅 时展示 |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 许可证 type | Maintenance | 维护类，有有效期，截止取 结束日期；展示 Start/结束日期 |
| 许可证 type | 永久 | 永久许可，永久有效；不展示 Start/结束日期 |
| 许可证 type | 订阅 | 订阅类，有有效期，截止取 结束日期；展示 Start/结束日期 |
| 许可证 type | Upgrade | 升级类；不展示 永久有效口径 |
| 许可证 type | 永久+Maintenance | 永久+维护，有有效期，截止取 结束日期；展示 Start/结束日期 |

### 3.2 页面功能与交互逻辑

- **软件实例创建/详情页**：新增 许可证 type 下拉（5 个字典值）；选择 Maintenance/永久+Maintenance/订阅 时联动展示 开始日期、结束日期，其余类型隐藏时间字段。
- **时间回填**：保存时若 Start/结束日期 为空，从关联合同回填对应值；人工已输入值不被覆盖（人工优先）。
- **有效期口径**：Maintenance/永久+Maintenance/订阅 以 结束日期 为有效期截止；永久/Upgrade 视为永久有效。该有效期口径供合规计算统计台账权限总量时判定实例是否参与。

## 4. 验收标准

- 软件实例创建/详情页可选择 许可证 type（Maintenance/永久/订阅/Upgrade/永久+Maintenance）。
- 仅 许可证 type 为 Maintenance/永久+Maintenance/订阅 时展示 开始日期/结束日期。
- 时间字段缺省时自动取关联合同 Start/结束日期 回填，人工输入优先级高于自动赋值。
- 有效期判定：上述三类以 结束日期 为截止，其余永久有效；合规计算据此仅统计有效期内实例。

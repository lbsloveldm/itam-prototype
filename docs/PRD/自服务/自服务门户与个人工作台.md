## 2. 需求分析

### 2.1 业务背景

在 ITAM 中，资产、流程、盘点、维护、合同、库存等能力分散在各功能模块，普通业务用户（资产使用人、资产管理者）需要在多个页面之间切换才能完成与「我」相关的事务。为降低使用门槛、提升一致性体验，需要建立面向个人的**自服务门户 + 个性化工作台**：一方面把最常用的流程发起入口聚合到门户，另一方面把与当前登录用户相关的资产、工单、盘点、维护、合同、库存预警信息集中呈现，使用户「不必进入 ITSM/各专业模块即可完成日常事务」。

《Self Service优化》进一步收敛了范围：自服务门户仅作为**功能菜单快捷入口**（当前仅放流程入口，删除「知识推荐、我的发起」），个性化工作台承载与自己有关的信息。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **一致性体验**：将流程相关内容揉进 ITAM 统一呈现，用户无需切换到 ITSM 即可发起与操作流程。
- **个人视角聚合**：以「我」为中心聚合资产、工单、盘点、维护、合同、库存事务，减少跨模块检索成本。
- **主动提醒**：对今年到期的资产、到期授权、到期合同、库存不足进行前置提醒，并提供一键发起（申领/续签/采购）。
- **管理者赋能**：资产管理者可对到期资产直接发起退役/处置，对不合规软件安装/使用发起处理。
- **可配置门户**：门户区块可按个人喜好配置，持续把 ITAM 独有能力沉淀进门户。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow Service Portal / Employee Center：以卡片式服务目录 + 我的项目（My requests/My assets）组织自助入口；服务推荐区块展示可发起的流程并直达建单页。结论：门户以「快捷入口卡片 + 关键统计 tile」为主体（非列表页），个人事务以列表/表单承载，并保留可配置能力。

### 2.3 用户故事

- 作为**普通业务用户**，我希望在一个门户看到我的资产、进行中工单、待盘点、待审批库存申请数量，并快速进入常用应用，以便高效处理个人事务。
- 作为**资产使用人**，我希望看到今年会到期的设备与软件授权，并对已到期项一键申领新资产/新授权，以便设备与授权不中断。
- 作为**资产管理者**，我希望对我管理且到期的硬件资产直接发起退役、对已退役资产发起处置，以便及时清理台账。
- 作为**合同负责人**，我希望看到我创建的已到期/即将到期合同并直接发起续签，以便合同不失效。
- 作为**盘点/维护执行人**，我希望在桌面端领取并执行分配给我的盘点/维护任务，以便与移动端一致地完成任务。
- 作为**库管/申请人**，我希望在库存不足时直接发起采购/领用申请，以便及时补货。

## 3. 需求设计

### 3.1 自服务门户（Self-Service Portal）

#### 3.1.1 涉及到的表

- `asset`（资产主表，统计我的资产数）
- `my_ticket`（我的工单，统计进行中工单数）
- `my_audit`（我的盘点任务，统计待盘点数）
- `stock_request`（库存申请，统计待审批数）
- `portal_config`（门户区块个性化配置，引用）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 门户导航入口 | 进入资产管理系统后，导航菜单通过 个人工作台进入，显示「自服务门户」菜单 | 门户为落地页（非列表），聚合快捷入口卡片与关键统计 tile |
| 快捷统计 tile | 顶部展示「我的资产 / 进行中工单 / 待盘点任务 / 待审批库存申请」计数 | 我的资产=`assignedTo`==当前用户的资产数；进行中工单=状态非「已完成/已关闭」的工单数；待盘点=状态非 已完成 的盘点数；待审批库存=状态为「待审批」的库存申请数 |
| 常用应用入口 | 卡片式入口：提交工单、我的资产、我的盘点、我的维护、我的合同、库存申请 | 点击卡片跳转对应子页；「提交工单」直达新建工单表单 |
| 服务推荐/流程入口 | 门户可配置各流程发起入口，点击后进入对应流程建单页面 | 展示 ITAM 已有流程名称；《优化》明确当前仅放流程快捷入口，删除「知识推荐、我的发起」 |
| 个性化配置 | 用户可按喜好将功能区块（如「我管理的资产」）添加至门户 | 区块配置持久化到 `portal_config`（以原型为准，原型以固定卡片呈现） |
| 各区块 More 入口 | 区块内数据量有限（如 30 条），点击「More」进入对应完整功能页 | 备注：区块默认显示条数由设计确定（源文档表述）｜以原型为准 |

#### 3.1.3 字段说明（门户统计 tile 与入口卡片）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| tile.title | VARCHAR | 40 | 统计项标题（我的资产/进行中工单/待盘点任务/待审批库存申请） |
| tile.value | INTEGER | - | 统计数值，由对应集合按当前用户实时计算 |
| tile.suffix | VARCHAR | 8 | 单位后缀（项/个） |
| app.title | VARCHAR | 40 | 常用应用卡片标题 |
| app.desc | VARCHAR | 60 | 卡片描述文案 |
| app.to | VARCHAR | 120 | 卡片跳转路由 |

#### 3.1.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 常用应用卡片 | 提交工单 / 我的资产 / 我的盘点 / 我的维护 / 我的合同 / 库存申请 | 门户默认入口卡片集合（以原型为准） |
| 门户内容策略 | 仅流程快捷入口 | 《优化》明确删除「知识推荐、我的发起」，当前仅配置各流程入口 |

### 3.2 我的资产（My Assets）

#### 3.2.1 涉及到的表

- `asset`（资产主表，引用；按 `assignedTo` 过滤）
- 关联跳转：`规格`（资产 规格）、领用流程工单（Request）

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 我使用的资产 | 展示分配给当前用户的所有资产 | 展示 `分配给` 字段值与登录用户相同的资产，覆盖 hardware/software/consumable/bundled 全类型 |
| 跳转一致性 | 与主系统功能一致，点击 名称 进入该资产详情页 | 复用资产台账详情页路由 `/asset/ledger/:id` |
| 今年到期设备提醒 | 展示今年会到达预设退役时间的硬件设备及耗材 | `Scheduled retirement` 在今年；已到达退役时间的记录，该字段值红色显示 |
| 申领新资产 | 对已到达退役时间的设备，Action「Request new asset」进入申领流程 | 未到达退役时间时 Action 灰色不可点击；进入流程带旧工单参数作默认值：资产 规格、Request 数量、位置 名称；找不到旧工单则三字段允许无默认值 |
| 今年到期授权提醒 | 展示今年软件授权会到期的软件 | 数据=（授权给用户的软件实例 + 授权给用户名下设备的软件实例）且 `end time` 在今年到期；已超过 `end time` 时红色显示该字段值 |
| 申请新授权 | 对已到期授权，Action「申请授权」进入申请软件流程 | 未到 `end time` 时 Action 灰色不可点击；进入流程带旧工单参数默认值（同上），捆绑资产不提供快捷入口（含多资产无法确定退役时间） |

#### 3.2.3 字段说明（我的资产列表）

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 资产标识 | VARCHAR | 40 | 资产唯一编码，点击跳资产详情 |
| 名称 | VARCHAR | 100 | 资产显示名称 |
| 类型 | VARCHAR | 20 | 资产类型标签（硬件/耗材/软件/捆绑/云） |
| 状态 | VARCHAR | 40 | 资产状态 |
| 分配给 | VARCHAR | 40 | 过滤条件字段，等于当前登录用户 |
| 预设退役时间 | DATE | - | 硬件/耗材到期提醒依据；已到达红色显示 |
| 授权到期时间 | DATE | - | 软件实例授权到期依据；已超过红色显示 |
| 操作 | VARCHAR | 40 | Request new asset / 申请授权，未到期灰色不可点击 |

> 备注：原型「我的资产」为只读列表，默认展示列为 资产标识 / 名称 / 类型 / 状态；到期提醒与 Action 列以源文档为准，原型未完整落地。

#### 3.2.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 资产类型 | hardware / software / consumable / bundled | 我的资产覆盖的资产类型（源文档明确的全类型） |
| action | Request new asset | 硬件/耗材到期后申领新资产（带旧工单默认值） |
| action | 申请授权 | 软件授权到期后申请新授权（带旧工单默认值） |
| action 可点击态 | 灰色不可点击 / 可点击 | 未到达退役/到期时间灰色不可点击，已到达可点击 |

### 3.3 我管理的资产（Assets I Manage）

#### 3.3.1 涉及到的表

- `asset`（资产主表，按 `managedBy` 过滤）
- `software_installation` / `software_usage` / `blacklist`（我管理软件资产的图表来源，引用）

#### 3.3.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 我管理的硬件资产 | 展示 `managed by`==登录用户且 `scheduled retirement` 在今年的硬件资产 | 供管理者对即将到期资产退役、对已退役资产处置 |
| 退役显示条件 | 当前时间超过 `scheduled retirement` 时，Action 显示 Retire | 条件：`type=hardware` 且（`state=in stock` 且 `substate ∈ {available, Reserved, Defective, Pending repair}`）或（`state=in use` 且 `substate ∈ {none, End of support}`） |
| 处置显示条件 | Action 显示 Dispose | 条件：`type=hardware` 且 `state=Retired` 且 `substate=none` |
| Action 兜底态 | 其他情况 Action 显示 Retire 且灰色不可点击 | 不满足上述条件时置灰 |
| 门户区块化 | 该页可按用户喜好添加至自服务门户 | 门户区块内数据量 30 条，点击更多进入 Assets I Manage 页；显示字段同页面截图 |
| 软件合规图表（优化） | 我管理的软件资产页新增图表「无授权的安装、不合规的使用、黑名单安装」 | 我管理的软件资产=实例「资产管理者」为我；黑名单安装=软件规格「所有者」为我；点击操作进入对应流程 |

#### 3.3.3 字段字典值说明（Action 状态机）

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| Retire 前置（state=in stock） | available / 已预留 / 故障 / 待维修 | 满足即可退役 |
| Retire 前置（state=in use） | none / End of support | 满足即可退役 |
| Dispose 前置 | state=已退役 且 substate=none | 满足即可处置 |
| Action 默认 | 灰色不可点击 | 不满足任一前置条件时的兜底展示 |

> 备注：「我管理的资产」在原型中未单独建页，字段与状态机以源文档《Self Service》《Self Service优化》为准。

#### 3.5.2 功能描述

## 4. 验收标准

- 自服务门户可展示 4 项关键统计 我的资产/进行中工单/待盘点/待审批库存申请与常用应用入口卡片，点击卡片正确跳转对应子页。
- 我的资产按 `assignedTo`==当前用户过滤，覆盖硬件/软件/耗材/捆绑类型；到期设备/授权红色提醒与 Request 入口逻辑符合源文档（原型缺失处以源文档为准）。
- 我管理的资产按 `managedBy` 过滤，Retire/Dispose 的显示条件与状态机符合源文档定义。
- 我的工单可完成新建/查看/编辑/删除，工单号规则 `SR-<年份>-<4位序号>`，类型/状态字典与状态机正确，404 守卫生效。
- 我的盘点/我的维护承接移动端待领取/执行中/已完成视图（Hold 项以原型只读/占位落地），盘点提交必填校验生效。
- 我的合同展示已到期/即将到期视图并支持续签跳转（复用 Renew）。
- 库存不足预警可依据库存规则阈值展示并发起采购/新建申请，申请号规则 `INV-REQ-<年份>-<4位序号>`，状态机正确。

## 2. 需求分析

### 2.1 业务背景

对于资产管理员来讲，需要了解库房的资产金额、数量、状态、风险，回答「有什么」，进而回答「怎么样」「为什么」和「该怎么办」，让「事后救火」变「事前预防」。最终目标是：在保证业务连续性的前提下，最大限度地降低库存资金占用，提升库存效率。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **库存全景**：一屏展示库存资产数量、价值、规格分类分布、状态分布，掌握「有什么」。
- **风险预警**：待退役资产列表、（后续）低库存预警，支撑「事前预防」。
- **流动洞察**：出库/入库/调拨统计与近 12 个月流动趋势，按部门/成本中心/分类多维分析。
- **资金优化**：降低库存资金占用、提升库存效率。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow Inventory Dashboard 与常见库存分析看板：以库存数量/价值/分类/状态为核心概要，并提供出入库流动趋势。本方案在此基础上增加按部门/成本中心的出入库/调拨堆叠统计与出入库分类统计。

### 2.3 用户故事

- 作为**资产管理员**，我希望一屏看到库存资产数量与价值（硬件+耗材），以便掌握库存资金占用。
- 作为**资产管理员**，我希望按库房查看不同规格分类的资产数量与占比，以便了解库存结构。
- 作为**资产管理员**，我希望查看近 12 个月出入库/调拨趋势与按部门/成本中心的统计，以便分析库存流动。
- 作为**资产管理员**，我希望看到待退役资产列表并直接发起退役，以便及时清理。

## 3. 需求设计

### 3.1 设计思路

看板分两大板块：① 所有库存概要数据（全局）；② 展示每个库房状况（按库房维度）。

### 3.2 库存概要报表配置

#### 3.2.1 涉及到的表

- `asset`（资产表，含状态、成本、规格分类、部门、成本中心、位置、责任人、计划退役时间）
- `规格` / `model_category`（规格/规格分类，引用）
- `alm_stockroom`（库房表，按库房筛选）

#### 3.2.2 报表指标说明（展示内容 / 计算逻辑）

| 序号 | 展示内容 | 展示形式 | 计算逻辑 |
| --- | --- | --- | --- |
| 1 | 库存资产数量 | 概要数字 | 状态为在库，统计当前所有库存硬件+耗材总量（耗材台账每条记录数量独立累加，如一条扳手记录 20 个计为 20 而非 1） |
| 2 | 库存资产价值 | 概要数字 | 状态为在库，成本字段求和（硬件+耗材） |
| 3 | 库存规格分类总数及各分类资产数量、占比 | 饼图/柱状图 | 不同规格分类下的资产总数量；不同规格分类下状态为在库的资产数量及占比 |
| 4 | 库存状态 & 资产数量 | 柱状图 | 按状态统计在库相关资产数量 |
| 5 | 不同库房规格分类资产数量及占比 | 饼图 | 每个库房不同规格分类资产数量及占比，支持按库房筛选；默认随机显示某一个库房的资产分布数据 |
| 6 | 低库存预警（本期暂不展示） | 列表 | 按库房筛选，默认显示所有库房低库存预警数据；库存量为 0 显示「紧急」、不为 0 显示「预警」；操作「补货」进入采购流程 |
| 7 | 待退役资产列表 | 列表 | 计划退役时间不为空 且 当前系统时间 ≥ 计划退役时间；操作「退役」发起资产退役流程 |

#### 3.2.3 低库存预警字段字典值说明（本期暂不展示）

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 预警状态 | 紧急 | 库存量为 0 时显示 |
| 预警状态 | 预警 | 库存量不为 0（但达到/低于阈值）时显示 |

### 3.3 出库、入库、调拨统计（11.18 新增）

#### 3.3.1 统计口径（计算逻辑）

| 类型 | 计算逻辑 |
| --- | --- |
| 入库 | 统计所有进入「在库」状态的资产：状态由非在库变为在库（已订购→在库、运输中→在库、在用→在库（硬件）/使用中→在库（耗材）、维护中→在库、缺失→在库） |
| 出库 | 统计所有从「在库」状态离开的资产：状态由在库变为非在库（在库→在用（硬件）/使用中（耗材）、在库→运输中、在库→维护中、在库→已退役、在库→缺失、在库→已消耗（耗材）） |
| 调拨 | 资产的部门、位置、责任人中至少一个发生变化 |

> 计数补充：只要有状态匹配到就计数一次；比如统计周期为一周，若在这一周内状态由运输中变为在库、又由在库变为在用，则入库量为 1，出库量也为 1。

#### 3.3.2 展示说明

| 展示项 | 展示形式 | 说明 |
| --- | --- | --- |
| 时间周期筛选 | 下拉筛选 | 本周/上周/本月/上月/最近 3 个月/本季度/上季度/本年/去年；选择后生效于各统计数据 |
| 调拨/入库/出库数量 | 概要数字 | 展示调拨数量、入库数量、出库数量 |
| 库存流动趋势 | 折线图 | 最近 12 个月出库、入库、调拨数量趋势 |
| 部门维度统计 | 堆叠柱状图 | 调拨统计、部门硬件出库统计、部门入库统计；横轴部门，纵轴堆叠出入库两种数据 |
| 成本中心维度统计 | 堆叠柱状图 | 成本中心调拨/出库/入库统计；横轴成本中心，纵轴堆叠出入库两种数据 |
| 出入库分类统计 | 堆叠柱状图 | 横轴分类，纵轴量，堆叠出入库两种数据（参考截图转 90 度） |

### 3.4 页面功能与交互逻辑

- 顶部概要：库存资产数量、库存资产价值、调拨/入库/出库数量（受时间周期筛选影响）。
- 分类与状态：库存规格分类占比、库存状态分布、按库房的规格分类占比（支持库房筛选，默认随机某库房）。
- 流动分析：库存流动趋势（12 个月）、部门/成本中心/分类的出入库堆叠统计。
- 列表：待退役资产列表（可发起退役）；低库存预警本期暂不展示。

### 3.5 日志审计

对看板内触发的补货、退役等操作记录统一操作日志，格式参考：【操作人】于【时间】对模块【库存管理/库存概况】执行了【补货/退役】操作，操作内容为【资产名称】，操作结果为【成功/失败】。

## 4. 验收标准

- 库存资产数量（硬件按记录、耗材按记录内数量累加）与库存资产价值（在库成本求和）计算准确。
- 规格分类占比、库存状态分布、按库房规格分类占比正确展示，库房筛选生效（默认随机某库房）。
- 出库/入库/调拨按本文口径统计，时间周期筛选（本周~去年）生效于各数据。
- 库存流动趋势（12 个月）、部门/成本中心/分类堆叠统计正确展示。
- 待退役资产列表按「计划退役时间不为空且当前时间≥计划退役时间」筛选，可发起退役；低库存预警本期不展示。

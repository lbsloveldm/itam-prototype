## 2. 需求分析

### 2.1 业务背景

预分配资产通常由供应商拥有，但存放在客户仓库里。主要目的是提高供应链效率、降低客户库存成本、应对需求波动、增强供应商合作关系、财务优化：供应商把库存放在客户仓库可更快响应订单、减少交货时间，客户可按需取货并按实际消耗结算；库存风险仍由供应商承担，客户减少资金占用；客户在收到并使用货物后才支付，改善现金流；同时可减少运输频率、降低物流成本。仅针对硬件可创建预分配资产，消耗品、software license 不允许，预分配资产不能由捆绑包组成。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **供应链效率**：供应商库存前置到客户仓库，客户按需取用，缩短交货时间。
- **资金优化**：客户按实际消耗结算、减少资金占用，库存风险由供应商承担。
- **灵活分配**：预分配资产可逐条分配给固定用户，或分割为多组移动到不同仓库。
- **财务闭环**：分配后在财务产生负债，客户需向供应商采购对应数量资产。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow 的 Pre-allocated assets（`t_CreatingPreAllocatedAssets`）：预分配资产以 在库 + Pre-allocated 子状态表示；可 分配后减少原记录数量、分配完删除原记录与 拆分为多组。本方案对齐其流程与字段置灰规则。

### 2.3 用户故事

- 作为**资产管理员（asset）**，我希望在创建硬件资产时通过 在库 + Pre-allocated 创建预分配资产，以便记录供应商寄存库存。
- 作为**资产管理员**，我希望将预分配资产逐条分配给固定的人使用，且原记录数量自动 -1，分配完自动删除，以便精确管理。
- 作为**资产管理员**，我希望将预分配资产分割为多组以移动到不同仓库，以便灵活调拨。

## 3. 需求设计

### 3.1 创建预分配资产（角色与约束）

- 创建角色：asset。
- 仅针对硬件可创建预分配资产；消耗品、software license 不允许创建预分配资产；预分配的资产不能由捆绑包组成。

#### 3.1.1 涉及到的表

- `asset`（硬件资产表）
- `规格`（规格表，引用，display 名称 = asset tag + 规格）
- `alm_stockroom`（库房表，stockroom 引用）
- `sys_user`（用户表，已预留 for 引用）

### 3.2 Create Pre-allocated assets 创建预分配资产

> 入口：硬件 assets 页，点击 New 即可新增预分配资产。功能：新增硬件资产功能页，状态 设置为 在库，子状态 设置为 Pre-allocated，点击保存即完成创建。

#### 3.2.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| create pre-allocated assets | 为硬件添加预分配资产 | 创建实例化硬件资产时，通过将 state 设置为 在库、substate 设置为 Pre-allocated 即可完成 |

#### 3.2.2 字段说明与置灰规则

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 状态 | VARCHAR | 40 | 设为 在库 |
| 子状态 | VARCHAR | 40 | 设为 Pre-allocated |
| 数量 | INTEGER | 20 | 预分配资产数量 |
| 库房 | VARCHAR | 100 | 存放库房，编辑页可修改 |
| 已预留 for | VARCHAR | 32 | 预留用户，编辑页可修改 |
| 公司 | VARCHAR | 32 | 所属公司，编辑页可修改 |
| 管理人 | VARCHAR | 32 | 管理方，编辑页可修改 |
| 资产标识 | VARCHAR | 40 | 按系统规则生成，不允许编辑（置灰） |
| CI / Auto Create CI | VARCHAR | 40 | 置灰不可操作；不为预分配资产创建 CI |
| 安装时间 / 已分配 time | TIMESTAMP | - | 置灰不可操作 |
| 部门 / 父级 / 归属人 | VARCHAR | 32 | 置灰不可操作 |
| 序列号 | VARCHAR | 40 | 置灰不可操作 |

> 置灰规则（A）：当 状态、子状态 被选定为 在库、Pre-allocated 时，CI、Auto Create CI、安装时间、已分配 time、部门、父级、归属人、资产标识、序列号 字段均置灰不可操作；不会为预分配资产创建 CI。
> 展示规则（B）：创建页面只显示 General 模块对应的字段，字段定义与现有页面相同。
> 详情规则（C）：点击进入已有预分配资产时，仅显示 details 页，无其他关联 tab 页，显示 Allocate、Split 操作；编辑页只允许修改 stockroom、已预留 for、公司、管理人 字段值。
> 资产标识 规则：创建预分配资产时遵循系统规则生成 asset tag，不允许编辑。

### 3.3 Allocate 将预分配资产指定给固定的人使用

> 入口：预分配资产 Details 页，点击 allocate 名称。角色：资产。在当前页弹窗展示分配要填写的字段。

#### 3.3.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| Allocate pre-allocate | 分配预分配资产 | ① 可对已有预分配资产进行分配，每次分配数量为 1 条，预分配资产记录中 quantity 数量相应 -1；② 已被全部分配的预分配资产记录会被删除，在资产列表中无法再看到 |

#### 3.3.2 详细规则

- A. 字段：序列号、已预留 for 与现有系统定义相同；已预留 for 拉取当前已有用户名称展示，支持模糊搜索。
- B. 每次分配生成的独立资产记录：quantity=1，状态=在库，子状态=可用。
- C. 独立资产记录 display 名称 与原预分配资产不同，遵循现有系统规则：asset tag + 规格；asset tag 由系统默认生成一条；除 已预留 for、substate 外，其余字段与现有系统相同，关联 tab 页与现有系统相同。
- D. 该预分配资产数量 -1；当预分配资产数量降至 0 时，删除该条预分配资产，在 hardware 资产列表页无法查找到。
- 财务：预分配资产被分配后在财务中产生负债，客户需向供应商采购对应数量的资产。

#### 3.3.3 分配弹窗字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 资产标识 | VARCHAR | 40 | 系统默认生成一条 |
| 序列号 | VARCHAR | 40 | 与现有系统定义相同 |
| 已预留 for | VARCHAR | 32 | 拉取现有用户名称，支持模糊搜索 |

#### 3.3.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 分配后独立记录 状态 | 在库 | 分配生成的独立资产记录状态 |
| 分配后独立记录 子状态 | 可用 | 分配生成的独立资产记录子状态 |

### 3.4 Split 分割预分配资产

> 入口：预分配资产编辑页，点击 Split 名称。在当前页弹窗展示（如 IBM Power 710 Express 为预分配资产 名称）。可将预分配资产拆分为多组，以便移动到不同仓库。

#### 3.4.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| Split a pre-allocated asset | 分割预分配资产为多组 | ① Split 时除 quantity 数量与原有预分配资产不同外，其余字段与编辑页面均相同（相当于 copy 一份，数量可能不同）；② Split 后原有预分配资产剩余数量 = 原有数量 - 分割出去的数量 |

#### 3.4.2 详细规则

- A. 分割数量需小于预分配资产总数量（如总数 10 时分割数量必须 < 10）；若填写数量大于总数量，弹窗页给出提示。
- B. 当预分配资产数量为 1 时，其资产 details 页不显示 split 按钮。
- C. 当分割数量小于总数量时，预分配资产被分为两组，可在资产列表查看到成功分组的预分配资产；其中 名称 与原预分配资产不同，遵循现有系统规则：asset tag + 规格；展示字段与现有系统相同。
- 被拆分的两组资产，编辑页面可见的属性除 quantity 可能不同外，其余均相同。

#### 3.4.3 分割弹窗字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 分割数量 | INTEGER | 20 | 必填，需小于预分配资产总数量；大于则提示错误 |

### 3.5 页面功能与交互逻辑

- 创建：硬件 assets → New，仅显示 General 字段，置灰字段见 3.2.2。
- 详情：仅 details 页，无关联 tab，展示 Allocate、Split；编辑仅允许改 stockroom/已预留 for/公司/管理人。
- Allocate：Details 页点击 allocate → 弹窗填写 asset tag/序列号/已预留 for → 生成独立资产记录（quantity=1、在库/可用），原记录数量 -1，降至 0 则删除。
- Split：编辑页点击 Split → 弹窗填写分割数量（<总数量）→ 拆为两组；数量为 1 时不显示 Split 按钮。

## 4. 验收标准

- 仅硬件可创建预分配资产（消耗品/软件许可/捆绑包不可）；通过 状态=在库、子状态=Pre-allocated 创建，置灰字段规则生效且不创建 CI。
- 预分配资产详情仅 details 页，展示 Allocate/Split；编辑仅允许改 stockroom/已预留 for/公司/管理人；asset tag 系统生成不可编辑。
- Allocate 每次分配 1 条，生成独立记录（quantity=1、在库/可用、名称=asset tag+规格），原记录 -1，降至 0 删除；分配后产生财务负债。
- Split 分割数量必须 < 总数量（否则提示），拆分为两组且除 quantity 外字段相同；数量为 1 时不显示 Split。

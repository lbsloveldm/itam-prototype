## 2. 需求分析

### 2.1 业务背景

库存规则允许自动化库存管理流程：当库存水平达到或低于预设阈值时，可触发发送通知（向库房经理发邮件提醒补货）、自动补货（创建转移订单从其他库房调拨，或创建采购订单向供应商订购）、任务创建（为库房经理自动创建任务）、避免重复操作（若补货已在进行中，考虑现有转移订单，不重复创建）。创建库存规则是资产管理系统中的关键功能，有助于确保库存水平优化、减少缺货风险、提高整体运营效率。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **缺货防控**：按「库房+规格」设定阈值，达到阈值自动触发补货/通知，减少缺货风险。
- **自动补货**：支持从其他库房转移补货（本期），未来支持向供应商采购。
- **避免重复**：考虑现有转移订单，不重复创建补货单。
- **可控作废**：不提供删除，通过取消激活作废规则，保留可追溯性。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow Inventory Management 的 Stock Rule：以 规格 + 阈值 + 补货选项 + 排序 size 定义补货规则；排序 size 为最小订单倍数，系统计算使库存超过阈值；供应商 补货需采购插件（procurement_user 角色）。本方案对齐其字段，并在本期将 补货选项 固定为 库房。

### 2.3 用户故事

- 作为**库存管理员（inventory_admin）**，我希望为「库房+规格」创建库存规则并设定阈值与订单大小，以便库存不足时自动补货。
- 作为**库存管理员**，我希望在补货已进行时系统不重复创建转移订单，以便避免重复补货。
- 作为**库存管理员**，我希望不需要的规则可以取消激活作废，以便保留历史记录。

## 3. 需求设计

### 3.1 库存规则概念与补货机制

- 阈值触发：某型号在某库房库存量达到阈值时，因存在库存规则，系统自动创建转移订单从另一库房转移一定数量库存过来。
- 两种补货选项：① 发邮件给库房经理（若采购功能激活，自动为库房经理创建采购订单及采购项）；② 自动生成转移订单从另一库房补货。
- 避免重复：若补货已在进行中，库存规则会考虑现有转移订单，不创建额外转移订单。
- 运行器：库存规则运行器每天运行，创建转移订单/采购订单/库存订单，向库房经理发邮件并创建任务。
- 权限：需拥有采购用户角色 procurement_user 才能访问采购订单和采购订单行项。

### 3.2 为库房创建库存规则

> 入口：Product catalog → Inventory Management → Stock rules 列表页。列表无记录时显示「No records to display」。角色要求：inventory_admin。

#### 3.2.1 涉及到的表

| 表名 [Table] | 类型 | 描述/用途 |
| --- | --- | --- |
| Stock Rule（alm_stock_rule） | 实体表 | 存储库存规则 |
| 库房（alm_stockroom） | 实体表 | 存储库房 |

#### 3.2.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 创建库存规则 | 点击 New 进入新增详情页，填写字段后 提交 | 创建成功后可在 Stock rules 列表看到记录 |
| 查看/编辑库存规则 | 列表点击 stockroom 名称进入详情查看/修改 | 修改字段后 提交 保存成功 |
| 作废规则（不提供删除） | 不提供删除功能 | 创建后可通过取消激活（启用=false）使其作废 |
| 补货执行（本期不做） | 触发补货转移单创建、邮件通知 | 本期先不做，后续实现 |

#### 3.2.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 型号/规格 | VARCHAR | 64 | 必填，下拉显示当前所有已有规格，支持模糊搜索，指定规则适用的产品规格 |
| 阈值 | INTEGER | 20 | 必填，触发补货的库存数量 |
| 补货选项 | VARCHAR | 20 | 必填，下拉：库房 / 供应商；本期默认 库房 且不可更改（供应商 需激活采购插件） |
| 库房 | VARCHAR | 100 | 必填，搜索框，指定资产当前物理位置，显示所有 stockroom 名称 |
| 父仓库 | VARCHAR | 100 | 搜索框，指定父级仓库（显示所有 stockroom 名称及 none）；子库存不足时从父库存获取资产 |
| 订单大小 | INTEGER | 20 | 必填，仓库转移或供应商采购的最小订单数量；系统计算最小倍数以使库存超过阈值 |
| 激活 | BOOLEAN | - | 复选框，启用库存规则以实现自动补货 |
| 名称 | VARCHAR | 100 | 留空默认取「库房/规格」 |

#### 3.2.4 字段字典值说明

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 补货选项 | 库房 | 创建转移订单以从另一个仓库获取资产（本期默认且不可更改） |
| 补货选项 | 供应商 | 向仓库经理发邮件向供应商下单，并创建采购订单及采购订单行项（需激活采购插件，本期不可选） |
| 启用 | true | 启用规则，实现自动补货 |
| 启用 | false | 停用规则（用于作废，替代删除） |

#### 3.2.5 排序 size 计算示例

若库存中有 3 台笔记本电脑，阈值设置为 10，选择 库房 选项，排序 size 设置为 4：系统会创建一个转移订单，订购 8 台（排序 size 的倍数）以超过阈值并满足规则（库存 3 + 订购 8 = 11 台）。从供应商补货时，系统向仓库经理发邮件显示需订购的总物品数量（排序 size 的倍数）。

### 3.3 页面功能与交互逻辑

#### 3.3.1 库存规则列表页（`/inventory/stock-rule`）

- 无记录时显示「No records to display」。
- 默认展示列：规格、库房、阈值、排序 size、启用。
- 操作：搜索、新建、编辑（stockroom 名称蓝链进详情）；不提供删除（用取消激活作废）。

#### 3.3.2 库存规则详情页（`/inventory/stock-rule/:id`）

- 表单字段见 3.2.3，规格 支持模糊搜索、补货选项 本期锁定为 库房。
- 深链访问不存在规则 ID 时展示 404 结果页与返回入口。

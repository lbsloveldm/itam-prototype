## 2. 需求分析

### 2.1 业务背景

通过将库房与多个服务地点关联，可有效管理从本地库房消耗的采购请求；通过单个库房服务多个地点，优化借用资产工作流程与自动化资产任务。好处包括：提高效率（集中管理库存与资产分配）、优化工作流程（简化借用资产分配与回收）、自动化任务（自动补货/资产转移，减少人工）、资源优化（集中管理更好预测与规划）。只有当库房被包含在位置覆盖范围内时，才能将其与一个或多个服务地点关联，以确保库房能有效地为指定服务地点提供支持。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **一库多点**：单个库房服务多个地点，减少库房冗余、集中管理库存与资产。
- **工作流优化**：简化借用资产的分配与回收流程。
- **自动化联动**：为自动补货、资产转移等自动化任务提供服务位置基础。
- **资源规划**：集中管理便于预测与规划资源需求，避免资源浪费与因库存不足影响运营。

#### 2.2.2 调研结论及竞品分析

ServiceNow 对于 add service locations 仅有文字描述，未找到可体验的功能及独立表。本方案参考其描述，将服务位置以关联记录形式落地：库房详情下添加/移除服务位置，或以独立列表页管理。

### 2.3 用户故事

- 作为**库存管理员（inventory_admin）**，我希望为某个库房添加多个服务位置（支持多选），以便该库房服务多个地点。
- 作为**库存管理员（inventory_admin）**，我希望在库房未被使用/引用时移除服务位置，并在移除前二次确认，以便安全维护覆盖关系。

## 3. 需求设计

### 3.1 为库房添加服务位置（新增）

> 入口：Product catalog → Inventory Management → All stockrooms 列表页，点击 名称 选择某个库房后，可见 service locations 新增入口。角色要求：inventory_admin。

#### 3.1.1 涉及到的表

- `alm_stockroom`（库房表）
- `cmn_location`（位置表）
- 库房-服务位置关联表（库房 ↔ 服务位置多对多）

#### 3.1.2 功能描述

| 需求点 | 需求描述 | 逻辑描述 | 角色 |
| --- | --- | --- | --- |
| 添加服务位置 | 点击 新增 进入新增详情页，选择位置后 新增 | Locations 为添加过的所有位置列表，显示位置 全称 列值；支持多选；点击 新增 后服务位置添加成功，可在该库房 service locations 列表看到记录 | inventory_admin |
| 计数校验 | 添加后 Locations 数量正确 +1 | Locations 数量从当前值增加，计算正确 | inventory_admin |

#### 3.1.3 字段说明

| 字段名 | 数据类型 | 长度 | 备注说明 |
| --- | --- | --- | --- |
| 库房（库房） | VARCHAR | 100 | 引用库房名称（关联所属库房） |
| 服务覆盖位置（位置 全称） | VARCHAR | 100 | 必填，位置树 如 `Asia/China/BeijingCity`，下拉多选 |
| 创建人 | VARCHAR | 32 | 只读，系统记录 |
| 创建时间 | TIMESTAMP | - | 只读，系统记录 |

### 3.2 移除服务位置（Remove）

> 当库房没有被使用或引用时，可对库房服务位置进行删除操作。角色要求：inventory_admin。

#### 3.2.1 功能描述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 移除服务位置 | 进入 Service locations 详情页，勾选要移除的服务位置后点击 Remove | 成功移除后列表不再显示该记录，locations 总数量减少正确 |
| 批量移除计数 | 勾选 N 个位置时 Remove 按钮显示数量 | 按钮显示 `Remove(N)` |
| 二次确认 | 移除时需二次确认 | 提示标题：Confirmation；提示内容：Are you sure you want to remove this record？ |

#### 3.2.2 交互文案

| 元素 | 文案 |
| --- | --- |
| 提示标题 | Confirmation |
| 提示内容 | Are you sure you want to remove this record？ |
| 批量按钮 | Remove(N)（N 为勾选数量） |

### 3.3 涉及到的表（汇总）

| 表名 [Table] | 类型 | 描述/用途 |
| --- | --- | --- |
| 位置（cmn_location） | 实体表 | 存储位置信息 |
| 库房（alm_stockroom） | 实体表 | 存储库房（关联服务位置） |

> 说明：Service now 中对 add service locations 只有文字描述，没有找到可体验的功能及独立表；本方案以库房-服务位置关联记录落地。

### 3.4 页面功能与交互逻辑

#### 3.4.1 服务位置列表页（`/inventory/service-location`）

- 字段：服务覆盖位置（下拉，位置树 全称）、库房（下拉引用库房名称）、创建人/创建时间（只读）。
- 操作：搜索（覆盖位置）、新建（新增，支持多选位置）、编辑、删除（Remove，二次确认，批量显示 `Remove(N)`）。
- 计数：添加后 +1、移除后相应减少，计算准确。

#### 3.4.2 库房详情「服务位置」页签

- 从库房详情进入，展示该库房已关联的服务位置，可 新增 / Remove。
- 深链访问不存在记录时展示 404 结果页与返回入口。

### 3.5 日志审计

对服务位置的添加、移除操作记录统一操作日志，格式参考：【操作人】于【时间】对模块【库存管理/服务位置】执行了【添加/移除】操作，操作内容为【库房名称-服务位置】，操作结果为【成功/失败】。

## 4. 验收标准

- 可为库房添加一个或多个服务位置（支持多选），添加后 Locations 计数 +1。
- 可勾选并移除服务位置，移除前二次确认（Confirmation / Are you sure you want to remove this record？），批量按钮显示 `Remove(N)`。
- 移除后列表不再显示记录，locations 总数量减少正确。
- 服务位置以「库房名称」交叉引用库房，含 404 守卫。

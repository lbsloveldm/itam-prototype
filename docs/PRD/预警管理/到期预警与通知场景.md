## 2. 需求分析

### 2.1 业务背景

**资产维保（资产 Warranty）**：企业需要关注资产关联的维保合同以及维保时间，查看快要维保到期的资产并给出规格分布。展示分两个角度——合同角度（看 end_time 和 renewal_end_time）与资产供应商角度（看 生命周期阶段 的 停止销售、停止支持、延长支持结束、停产）。参考 ServiceNow 在资产概览（资产 Overview）中有「今年硬件保修到期（硬件 warranty expiration this year）」的展示。

**通知场景梳理**：当前通知功能不够实时、覆盖场景不够全面。需具备两点能力：① 数据表中属性值发生变化时（状态变化、启用禁用变化等）提供实时提醒；② 数据表中记录条数发生变化时（新增、删除）提供实时提醒。若单表无法满足要求，需做索引表或视图完成多表属性选择（应对软件授权即将到期提醒）。

### 2.2 需求价值

#### 2.2.1 模块价值点

- **到期预判**：从生命周期与维保合同双视角，按本月/本季度/本年/明年分档预判即将到期资产数量。
- **规格分布**：今年要过期的资产按规格分布（饼图），辅助采购/替换决策。
- **实时通知**：属性变化、新增、删除即时提醒，让责任人第一时间感知关键数据变动。
- **闭环处置**：到期资产可发起退役流程，维保合同到期可进入续签模块更新。

#### 2.2.2 调研结论及竞品分析

参考 ServiceNow / device42 / globe 等：在资产概览中展示今年硬件保修到期数量，并可按不同时间维度组织。结论：单独做 Overview 时可增加多时间维度（本月/本季度/本年/明年）；趋势图可基于时间做柱状图/趋势图（设计宽表时预留时间维度）。

### 2.3 用户故事

- 作为**资产管理员**，我希望看到本月/本季度/本年/明年即将到期（生命周期/维保合同）的资产数量，以便提前规划替换与续保。
- 作为**合同管理员**，我希望看到维保合同到期与续保到期数量（去除已续约的），以便及时续签。
- 作为**责任人**，我希望在资产状态等关键属性变化、记录新增/删除时收到实时通知并可跳转详情，以便快速处理。

## 3. 需求设计

### 3.3 通知场景梳理（实时通知）

#### 3.3.1 通知能力总述

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 属性变化实时提醒 | 数据表属性值变化时（状态变化、启用禁用等）提供实时提醒 | — |
| 记录变化实时提醒 | 数据表记录条数变化时（新增、删除）提供实时提醒 | — |
| 多表关联 | 单表无法满足时做索引表或视图完成多表属性选择 | 应对软件授权即将到期提醒 |

#### 3.3.2 预设任务扩展（三类新增类型）

| 需求点 | 需求描述 | 逻辑描述 |
| --- | --- | --- |
| 类型新增 | 预设任务类型下拉增加「属性更新通知」「新增记录通知」「删除记录通知」三项 | 不显示执行周期模块，默认实时通知 |
| 动态通知者 | 动态通知者可选项包括所有人员类字段 | — |
| 多表关联对象 | 需要将多表关联为一个对象 | 见筛选项 |
| 默认提醒内容-属性更新 | 「属性名」值由 A 被更新为 B | 举例：「资产状态」值由「在库」被更新为「闲置」，请及时查看 |
| 默认提醒内容-新增 | 「数据表名」中新增了一条数据，请及时查看 | — |
| 默认提醒内容-删除 | 「数据表名」中删除了一条数据，请及时查看 | — |
| 默认提醒链接 | 增加可跳转至具体数据详情页的链接 | 被删除的资产，链接中具体显示为「规格分类、规格、资产全称」，不可跳转 |
| 默认通知标题 | 属性更新→「属性更新通知」；新增→「新增记录通知」；删除→「删除记录通知」 | 按类型默认标题 |

#### 3.3.3 字段字典值说明（通知类型）

| 字段名 | 字典值 | 说明 |
| --- | --- | --- |
| 通知类型（新增） | 属性更新通知 | 属性值变化实时通知，默认标题「属性更新通知」 |
| 通知类型（新增） | 新增记录通知 | 记录新增实时通知，默认标题「新增记录通知」 |
| 通知类型（新增） | 删除记录通知 | 记录删除实时通知，默认标题「删除记录通知」；被删资产链接不可跳转 |

## 4. 验收标准

- 资产 Warranty 按本月/本季度/本年/明年分档展示四类 生命周期阶段 资产数量，及维保合同到期/续保到期数量（去除已续约），今年过期资产规格分布以饼图展示。
- 通知类型支持新增「属性更新/新增记录/删除记录」三类，默认实时通知、默认标题与默认内容符合定义，提醒链接可跳转（被删资产不可跳转）。
- 借用/租赁属性字段按获取方式动态显隐，借用成功回写台账、归还后置「无」并隐藏字段；非硬件资产不回写。
- 预警管理菜单三类待处理列表可发起退役/续签/采购流程并正确带入默认字段。
